## 1. 背景与定位

开源单体计划最后一批。SP1~SP5 已把功能侧备齐（PG 持久化、限频配额、法术清单直查、上标溯源、embedding 双通道）。本批做工程化收尾：让社区用户 clone 后能自助跑起来（Docker 一键 / 本地开发两条路），把许可与数据合规声明立起来，CI 保障质量基线。

现状勘察（k3 亲测）：

- git 跟踪文件 10262 个 / 工作区 166.6MB / `.git` 历史 252MB；最大单文件 7.7MB（远低于 GitHub 100MB 限制）。
- `sk-` 全库扫描命中均为规则文本英文单词片段，**无真实密钥**；无 .env/.pem 等敏感文件入库。
- 向量库产物（`~/.pf_agent/*.json`，~600MB）与 chunks.jsonl 均 gitignored——**Docker 首启需现场建库**（见 §3 D5）。
- 根目录有会话导出文件（`kimi-export-session_*.md`）等本地工作痕迹，公开前需划定排除清单（§3 D4）。

## 2. 目标 / 非目标

**目标**：新 public repo 干净历史发布；许可/声明齐备；Docker compose 一键起（app + Ollama + 可选 PG）；CI（测试 + GHCR 镜像）；README 使新用户可无协助跑通。

**非目标**：不改任何 `src/main/java` 业务逻辑（配置外置若必须小改，限默认值/注释级）；不做微服务拆分（另一阶段）；不做多架构镜像（amd64 先行，arm64 可选）；不发布 Maven 构件；不做 i18n 文档（README 中文为主 + 英文摘要段）。

## 3. 设计决策（D1~D7）

- **D1 新库整形**：`git checkout --orphan` 从 `dev/pf-agent` 切干净历史，单初始 commit「opensource baseline」。新库名建议 `pf-agent`（用户拍板可改）。本地旧库不动，继续作开发库；开发流：旧库开发 → 合并 dev/pf-agent → 定期同步到新库（同步动作另行约定，本批只做首发）。
- **D2 许可与声明三件套**：
  - `LICENSE`（996.ICU 中文版）+ `LICENSE_EN`（996.ICU 英文版）——代码适用；
  - `NOTICE.md`——数据部分单独声明：Paizo Community Use Policy 声明段（"This product uses trademarks and/or copyrights owned by Paizo Inc., used under Paizo's Community Use Policy…"）+ OGL 说明（PF1e SRD 内容）+ 中文社区翻译 credit + 「数据仅供个人学习/非商业社区用途，版权归原作者所有」+ 异议联系方式；
  - README 顶部显著位置放同义免责一段。
- **D3 配置外置收尾**：`.env.example` 列全部环境变量（`DEEPSEEK_PF_API`、`PF_EMBEDDING_CLOUD_API_KEY`、PG 连接、限频/配额开关）；README 配置表覆盖 yml 全键；**三个已知坑必须写进部署文档**：① SP2 虚线属性 env 绑定不一致（多段虚线用 yml/程序参数）；② SP5 `fallback-enabled` yml 显式 false 覆盖 D6 默认（要「cloud 主默认兜底」须删行或覆写）；③ cloud 主通道每次检索每 store 一次 embed 调用（V5② 实测单问 60 次），成本估算注意。
- **D4 公开范围清单**：排除 `kimi-export-session_*.md`（会话导出）、`.claude/`、`.pytest_cache/`、本地 IDE 文件；其余全量公开（docs/handover 过程文档、pf_data 全部、qa 评测集——过程透明即项目信誉）。排除清单写进方案即定稿，执行方照单执行。
- **D5 Docker**：multi-stage `pf_agent/agent/Dockerfile`（Maven 构建 → JRE 运行，eclipse-temurin 21）；根 `docker-compose.yml`：`app`（镜像 GHCR 或本地 build）+ `ollama`（首启 entrypoint 拉 bge-m3）+ 可选 `pg` profile；卷挂 `~/.pf_agent` 等价物持久化向量库。**首启建库**：向量库文件缺失时应用自行从 chunks.jsonl 构建（既有行为），README 写明首启耗时与「Release 附预构建向量库包可加速」（包由本批 T6 上传一次）。`.dockerignore` 排除 target/qa 输出。
- **D6 CI（GitHub Actions）**：`ci.yml`——push/PR 跑 `mvn test`（247 基线）；`docker.yml`——tag `v*` 或手动触发构建并推 GHCR（`ghcr.io/<owner>/pf-agent`），GITHUB_TOKEN 权限内完成，无需额外密钥。issue 模板（bug/功能/数据纠错三类）+ PR 模板 + `CONTRIBUTING.md`（红线摘要 + 提交流程 + 评测要求）。
- **D7 发布路径**：T6 用 `gh` 以 **private** 建新库 → 推送 → CI 跑绿 → GHCR 镜像可拉 → k3 验收 → **用户本人翻转 public**。公开前最后一道：k3 跑 secrets 扫描 + 排除清单核对。
