# 迁移难点：dnd5e → PF 1e 无法准确映射的题

本文件记录 56 题迁移中**无法准确映射**的题目：6 个 X 题（放弃映射，不进评测集）+ 所有「勉强 R 但语义有偏差」的题。
原因集中在四类：**怪物 stat block 缺失**、**Adv/Disadv 与附赠动作机制差异**、**短休/统一施法位表等 5e 独有机制**、**子职业（Subclass）结构与 PF 不同**。

## 三、计划内 X → 实查 R 的偏差说明

- **medium-1**：计划决策表标注为 X（红龙吐息 stat block 依赖）。实查发现种族/职业模块存在足量火焰抗力数据（术士龙脉血统、精灵元素抗力），改判为 R 并保留「全量枚举」维度，让 56 题中少一个放弃题。注：实查阶段曾将「神裔能力变体」列入锚点，因该 chunk 位于未整理目录（BoA 天界血脉）且核心神裔 book='?'，自审时移除，锚点收敛为 龙脉血统 + 精灵元素抗力。若后续数据核实该 R 题锚点不稳，可降级回 X 并移入本文档。
- **medium-21**：计划决策表标注为 D（直接迁移）。实查阶段以「水栖精灵免疫」承载标准精灵免疫（免疫睡眠 + 惑控豁免 +2），但该 chunk 位于未整理目录（BotS），自审时替换为 CRB 心灵屏障（免疫影响心灵），锚点收敛为 防护邪恶（CRB）+ 心灵屏障（CRB）+ 仿生人（COMP），题面「抵抗魅惑途径」不变。
