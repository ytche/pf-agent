# J7 keywordSearch 实测探针报告

- 日期：2026-09-18
- 方案依据：`docs/design/方案_Agent检索工具增强_20260917.md`「J7 keywordSearch」节「第一步：实测探针」
- 探针脚本：`pf_agent/agent/qa/keyword_gap_probe.py`
- 明细数据：`pf_agent/agent/qa/keyword_gap_results.json`

## 方法

1. **术语集**：200 条确切中文条目名，全量自动生成 + 确定性等距抽样：
   - 法术 100 条：来自 `pf_data/phase1/vectorizer/output/法术/spell_lists.json`（26 个职业法术列表的 `cn` 名，按 chunk_id 去重，等距抽取 100）。
   - 专长 50 条：来自 `专长/chunks.jsonl` 中 `component_type == "feat"` 的 title（去重后等距抽 50）。
   - 装备 50 条：来自 `装备/chunks.jsonl` 中 `component_type ∈ {gear, weapon, armor}` 的 title（去重后等距抽 50）。
   - 人工抽检样例（均为真实条目名）：
     - 法术：一窥真实、不屈之心、乙太凝聚场、亵渎抵抗、伦理印记、侦测魅惑、催眠术、光亮术
     - 专长：业余剑客、伊利森冰霜法师、偏好法术、内在之光、制造权杖、化形猛击
     - 装备：乖乖水、健体香脂、冰纹钢、刺矛、双刃剑
2. **vectorSearch 侧（近似复现）**：直接读 `~/.pf_agent/vector_store_{spells,feats,equipment}.json`（SimpleVectorStore JSON），术语经 Ollama `bge-m3` embed（`localhost:11434/api/embed`，失败重试 2 次）后与全量 chunk 向量算余弦相似度，取 topK=8（对齐应用侧默认）。**失败 = 目标 chunk_id/title 未出现在 top8**。
   - ⚠️ 近似口径声明：这是裸余弦 topK，**未复刻** SearchService 的相似度阈值、加权、RRF 等逻辑，用于探测「确切术语能否被语义召回」的缺口，不等同生产检索的精确行为。
3. **对照组（子串原型）**：同一批术语在 store metadata 的 `title` 与 `aliases` 上做不区分大小写的双向子串匹配（`term in title/alias` 或 `title in term`，偏宽松口径）。
4. **判定线**：vectorSearch 失败率 >15% 且子串原型失败率 <5% → 确认缺口（进 Lucene 选型）。

## 结果

| 模块 | 术语数 | vectorSearch 失败 | vectorSearch 失败率 | 子串原型失败 | 子串原型失败率 |
|---|---|---|---|---|---|
| spells | 100 | 0 | 0.0% | 5 | 5.0% |
| feats | 50 | 26 | 52.0% | 0 | 0.0% |
| equipment | 50 | 7 | 14.0% | 0 | 0.0% |
| **合计** | **200** | **33** | **16.5%** | **5** | **2.5%** |

vectorSearch 命中的 167 条中 rank 分布：rank1=145，rank2=4，rank3=7，rank4=6，rank6=2，rank7=2，rank8=1（无 rank5）。即语义检索对「能命中」的条目几乎总是排第 1，但约 1/6 的确切条目名完全召不回。

## 判定结论

**缺口成立**：vectorSearch 失败率 16.5% > 15%，且子串原型失败率 2.5% < 5%，满足判定线两侧条件 → J7 进入 Lucene（倒排关键词）选型阶段。缺口集中在专长模块（52% 失败率），法术模块语义检索表现完美（0/100 失败）。

## 工具/数据异常说明

1. **术语集质量瑕疵（抽样副产品，不影响判定）**：
   - feats 术语 `? 尘埃`（chunk `feat_page_820_*`）title 含残留问号，疑似数据清洗缺陷，建议另案排查。
   - equipment 术语中混有非具体物品名：`住宿与服务`、`医生`、`AMP`、`冰纹钢`（疑似章节/材料类 chunk 混入 gear/weapon/armor 类型）。这类词子串原型仍可命中，但语义检索失败部分由术语本身非「确切条目名」导致。
   - feats 术语 `岳峙巅` 与库中 `岳峙渊渟` 疑似译名不一致（或 alias 覆盖），属别名问题而非检索问题。
2. **法术子串原型 5 条失败**（不屈之心、乙太凝聚场、幻灵重塑术、月狂病、连接遗赠）：这些术语在 spell_lists.json 中存在但按 chunk_id 未在 store metadata 的 title/aliases 中子串命中，疑似对应 chunk title 带后缀（如「（拟像）」类括号说明）或 spell_lists 与 store 之间存在条目漂移，建议另案核对。
3. store 文件实际名为 `vector_store_equipment.json`（非 `equipments`），探针已按实际文件名适配。
4. Ollama bge-m3 embed 200 条全部一次成功（含重试机制未触发），单次约 0.4s，总耗时约 97s。
5. 探针未调用 8080 应用 API（无裸检索端点），与方案一致直接读 store JSON 复现。
