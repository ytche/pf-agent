## 方案设计

### R1/R2：新后处理步骤 `ApplyFeatMetamagicIndexJoin`

- **位置**：feat_chain.py 新步骤类，`FeatProcessor.POSTPROCESSORS` 第 3 位（ApplyFeatCreationSourcePromote 之后、BackfillChmTocPath 之前）。理由：必须在步骤 1/2 完成全部 doc 的 book 定稿后 join（否则同名词条本身还是 '?' 无可 join）；在 backfill 两步骤前无损（它们只填 toc/source 缺失字段，与 book 无耦合）。顺序插入属「新增不重排」，不触犯 B1 禁令。
- **join 构建（每次 run 内现场构建，不落盘中间表）**：
  1. 遍历全库 chunks（sorted(chunk_id) 保证确定性），取 `book_abbreviation != "?"` 且 `component_type ∈ {feat, feat_index}` 且 **doc_id ≠ page_1367**（仅排除索引页自身防自引用——⚠️ 勘误：原写「排除 feat_index 行」，与拍板探针/实施不符，见文末「实测订正」）的 chunk。
  2. 匹配键：中文 `title` 归一（去空白）+ 英文别名归一（strip + lower + 剥 `【…】` 后缀 + 压单空格）。每个键 → `set(book_abbreviation)`（同书多键/重复条目天然去重）。
- **回填规则（仅 page_1367 且 book=="?" 的 chunk）**：
  - 键命中且 set 大小 == 1 → 回填三书字段，取该 abbr 对应 chunk 的 cn/en 名；`source_confidence = 55`（低于引用块显式标记 65、高于纯正文提及 50，介于 KN137 先例区间内），provider 证据写入 metadata：`metadata["source_backfill"] = {"method": "feat_metamagic_index_join", "matched_key": <键>, "matched_chunk_id": <源 chunk_id>}`。
  - 键未命中（set 为空）→ 不动，保持 "?"（27 条）。
  - 键命中多书 → 默认不动、记入报告；**唯一例外**：`水生法术`（Aquatic Spell）→ UW（R2 特判，模块级常量 `CONFLICT_OVERRIDES = {"水生法术": "UW"}`，注释写依据：UW 主题原书 + 决策 2 拍板；从库内 UW 条目取 cn/en 名）。
  - 幂等硬契约：只改 book=="?" 的 page_1367 chunk，重跑 diff 为空（对齐 feat_chain.py:16 契约 + test_postprocess 幂等测试模式）。
- **不在批准范围的护栏（白名单方案 a，已拍板）**：join 产生的可回填集合若超出探针 64+1 条（例如某键探针判无命中但 join 命中），**超出部分一律不回填**：仅当命中 title ∈ 白名单清单（65 条 title 常量入代码）才执行回填，清单外命中 → 跳过 + 报告并停下报用户——"探针之外新发现能配上"被红线结构性拦住。**白名单清单由 coder 实施时重跑探针导出**（探针逻辑已验证：中文 title + 英文别名剥【书】后缀、大小写不敏感、排除 page_1367 自身与 book="?"、唯一命中才收；冲突条目水生法术以 override 单独登记，不入白名单）。

## 备选方案与取舍

- **B1：源 md 给 82 条表行逐条补【书】**：信息最权威但触碰红线（不改源 md）且 27 条库外条目仍需外部考据。不选。
- **B2：权威表/MAPPING 层把 page_1367 整页归一本书**：跨 ≥6 本书混排，无单一书可整页归（KN228 原始定性）。不选。
- **B3：join 做成独立一次性脚本，不进 pipeline**：实现快但产物不可复现（重跑 build 后回填丢失），违反"build 重跑产物一致"要求。不选。
- **B4：processor 内 resolve_source 阶段做 join**：processor 逐文件执行，无法看到其他文档已解析条目（跨文档依赖不满足）。不选，必须放 finalize 后处理（与造物专长一览 promote 先例一致）。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 同名不同条目误配（尤其仅中文名的速查表行命中别书同名 feat） | 唯一命中才回填；中文键命中多书即不动（除已裁水生法术）；白名单护栏使超出探针的命中自动停报；逐条对账验证 64 条与探针证据一致 |

| 翻译名漂移漏配 | 双键匹配（中文 title + 英文别名小写剥【】）；漏配结果 = 保持 "?"（安全方向），不会错配 |
| `feat_index` 行被当 join 源造成自引用/扩散 | ~~join 源排除 component_type=feat_index~~（勘误：实际口径含 feat_index，见文末实测订正）；join 源排除 page_1367 自身（防自引用）；且 join 源排除 book=="?" 的所有 chunk |
