# docs/design — 方案文档

收录 architect 产出的方案文档（"讨论阶段不动手"的载体）。

## 收录规则

- 仅收录**标准任务与大工程**的方案；轻量任务方案口头过，不留档。
- 命名：`方案_<主题>_<日期>.md`（日期 YYYYMMDD），如 `方案_法术检索优化_20260916.md`。
- 文档结构见 `.kimi-code/agents/architect.md` 的模板（背景与目标 / 现状分析 / 方案设计 / 备选方案与取舍 / 风险与缓解 / 验收标准草案 / 实施步骤建议）。
- 方案须经用户拍板后才进入编码；修订时编辑原文档并记录修订说明，不新建文件。
- 与 `docs/superpowers/specs/` 的分工：本目录是日常开发的轻量方案；`specs/` 是 brainstorming 流程产出的正式设计 spec。

流程详见 `docs/WORKFLOW.md`。
