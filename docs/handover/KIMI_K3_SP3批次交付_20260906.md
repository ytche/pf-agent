## 2. 实现要点（对照方案 D1~D7）

### T1 · `spell_list_export.py`（数据侧，幂等）

- **复用**：`verify_spell_list_recall.py` 的 27 路径注册表 + `ENTRY` 中英配对正则；`scan_spell_lists_20260729.py` 的 `normalize()` 译名变体归一表 / `CLASS_ALIASES` / `SOURCE_BOOKS` / 抽名与单元格切分函数。
- **新增环级分段**：环级头正则覆盖 5 种词形（`X级法术`/`X环法术`/`X环公式`(炼金术师)/`X环`(秘学士)/`X级`(异能者)），按页结构分派 3 种格式（A 4 列表格 / B 加粗标题段落 / C 按学派 2 列表格）。
- **交叉补 chunk_id**：按 `title`（过 normalize）+ `aliases[0]` + `book_abbreviation` 对撞法术 chunks.jsonl，tie-break「书名匹配优先、否则 CRB 优先」；对不上置 null 不阻塞（报告统计 null 率）。
- **溯源字段**（用户 2026-09-06 拍板：数据侧嵌入摘要+路径，Java 零额外 IO）：每职业带 `source_toc_path`（列表页 CHM 目录路径）+ `source_excerpt`（列表页标题行 + 条目数概述，截断 ~500 字符）+ `list_chunk_id`（对得上职业库就填，9/27 命中）。
- **脏页处理**：`唤魂师/page_272.md` 纯英文受限列表（`ENTRY` 抽不到）→ 改用规范中文列表页 `page_1037.md`，issues 记录不硬编正则兜底（红线 5）。
- **产出**：`spell_lists.json`（D3 schema：`version`/`generated_from`/`classes`，levels 键 "0"~"9"，entry 带 cross_book/cross_score 交叉旁注）+ `spell_list_export_report.json`。脚本内「条目数 == 页面解析数」全量断言自校验。**产物 gitignored，由脚本再生（F-012）**。

### T2 · SpellListService + getSpellList（Agent 侧）

- **`SpellListService`**（`@Component`，`rag/` 包）：
  - `@Value("${pf.spell-lists.file-path:../../pf_data/phase1/vectorizer/output/法术/spell_lists.json}") String filePath`；`private final ObjectMapper objectMapper = new ObjectMapper()`（工程先例，非 @Autowired）。
  - `@PostConstruct void load()`：`Files.exists` 判缺失 → `log.warn` + 内部 `classes` Map 置空（`available=false`），不炸启动；存在 → 读 JSON 建 `Map<String,SpellList>` + 别名索引 `aliasIndex`（规范名自身 + 每职业 aliases 变体）。
  - 公开方法：`isAvailable()` / `knownClasses()`（Unicode 码点序）/ `resolve(className)`（trim + aliasIndex，未知 null）/ `levelOverview(className)`（各环级条目数 + 提示指定 0~9 环，示例用首个非空环）/ `formatLevel(className, level, maxChars)`（`序号. 中文名（English） [书]` 紧凑行，超 maxChars 截断并提示，复用 metadata-result-chars 护栏语义）/ `listPageDocument(className)`（构造溯源 Document）。
  - 数据模型 record：`SpellListFile`/`SpellList`/`SpellListEntry`，`@JsonProperty` snake_case→camelCase 映射 + `@JsonIgnoreProperties(ignoreUnknown = true)`（忽略 cross_book/cross_score 旁注）。
  - 溯源 Document metadata 对齐统一键：`title`/`book_name_cn`/`doc_id`(=sourcePage)/`chunk_id`(仅 list_chunk_id 非 null)/`tocPath`(=sourceTocPath)；text = source_excerpt。
- **`getSpellList` @Tool**（插在 reportDataGap 之后、formatCompact 之前，保 public→private 序）：
  - `className` 别名归一；未知职业 → 可读提示 + 26 合法职业清单 + 别名示例（对齐 searchByMetadata 自纠风格）；`level` 为 null → 各环级概览；越界（<0 / >9）→ 提示 + 概览；合法 → `formatLevel(canonical, level, metadataResultChars)`。
  - 命中后 `collector.add(List.of(listPageDocument(canonical)))` 挂溯源——**单个法术不逐条挂溯源，列表页即权威出处**（D5/V3）。
  - 工具不可用（文件缺失加载失败）→ 返回「清单暂不可用，请改用 searchByMetadata」，零查询零收集。
