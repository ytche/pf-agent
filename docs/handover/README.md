# 交接 / 交付文档目录

> **定位**：pf_agent 仓库所有交接文档、交付文档的统一存放目录（2026-08-26 起）。
> **规则**：**所有 pf_agent 的交接文档 / 交付文档一律放本目录**，禁止放仓库根目录或其他模块 docs 目录。

---

## 放置规则

1. **必须放这里**：跨批次/跨角色（kimi-k3 等）的交接文档、交付文档——含「交付」「交接」「移交」「接手」等字样的文档。
2. **禁止放仓库根目录**：根目录只留 README.md / CLAUDE.md / PROJECT_HANDOVER.md 等顶层常驻文件，批次交付文档不再散落根目录。
3. **例外**：
   - `PROJECT_HANDOVER.md`（项目总交接，顶层常驻，被 CLAUDE.md 与多模块文档引用）**保留仓库根目录**，不迁入本目录；
   - kimi 会话导出（`kimi-export-session_*.md`）为历史记录非交付文档，保留原位置；
   - 各模块的实施方案 / 方案文档归 `pf_agent/agent/docs/`（或数据侧对应 docs），与「交付文档」区分——交付文档是**结果收口**，方案文档是**执行蓝图**。
4. **命名**：沿用 `KIMI_K3_<批次>交付_<YYYYMMDD>.md` 风格，日期用文档交付日期。
