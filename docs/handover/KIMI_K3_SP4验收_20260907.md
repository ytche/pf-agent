## 三、发现的问题 / 观察项（均不阻塞）

1. **V5 失分归因（k3 运行 52/50/2.887 的完整解释）**：
   - `medium-1`（火焰抗力）三维 0：**DeepSeek API 连接重置导致 HTTP 500**（应用日志 `SocketException: Connection reset`，Spring AI 重试 1 次后失败），空 answer 拖垮三维。单题复测正常作答（102 来源、gap=false）。**基础设施瞬时故障，非 SP4**。剔除后结构分 153/52=2.94 回到带内。
   - `easy-2`（虹光法墙）：**历史抖动题第 5 次失分**（12 次运行 5 败，横跨 SP3 之前基线），gap=true 但答案缺诚实短语触发评分规则。非 SP4 因果。
   - `medium-0`（兼职法术位+5e 合并表）：12 次运行首次诚实失分。该题含「PF 是否有 5e 式合并表」子问（无数据），LLM 本轮调用 reportDataGap（行为合理）但答案未含评测脚本的固定诚实短语 → 0。单题复测 gap=false 应得 1 分。**LLM 非确定性 + 评测短语刚性**，非 SP4 因果。
   - 综合：质量门槛实质满足（交付方运行 53/53/53/53 与 k3 运行剔除瞬时故障后等价）；波动带语义是「防下穿回退」，本轮无 SP4 归因的下降。
2. **交付方上报「结构 2.962 越波动带上沿 +0.002」的裁定**：**接受**。越的是质量更好侧（三题 2→3 顶格、零下降），波动带用于防回退，上沿越界不构成问题。交付方不自行裁定、如实上报的做法正确，提出肯定。
3. **【观察】宽过滤响应体积**：兼职题收集 552 个来源（响应 1.1MB）。宽过滤结果全量进收集器是 v1.5 B2 既有语义（F-002 护栏只截 LLM 侧文本），非 SP4 引入，但编号机制使其显性化。**建议后续批次考虑 sources 条数/体积上限**（不进 SP4）。
4. **【观察】评测脚本诚实短语的刚性**：gap=true + 答案实质诚实但不含固定短语即判 0（medium-0 首现）。可作评测口径优化议题，不进 SP4。
5. **【观察】交付方披露的既有语义**：未闭合 `"[#"` 按普通文本保留、正文罕见 `[#N]` 字样会被替换——设计 §5 已登记，维持。
