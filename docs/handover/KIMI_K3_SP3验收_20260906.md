## 三、发现的问题 / 观察项（均不阻塞）

1. **【观察】easy-2（虹光法墙）诚实性抖动**：历史 11 次运行中 4 次失分（stage2_r2、SP1 验收、SP3 r1、本次），横跨 SP3 之前的基线运行，确认为 LLM 非确定性老抖动，**非 SP3 回归**，基线口径（≥47/50）满足。
2. **【观察】list_chunk_id 命中 9/26**：职业库 chunks.jsonl 仅 9 个职业的列表页 doc_id 匹配成功（术士/女巫/审判者/反圣武士/战斗祭司/血脉狂怒者/秘学士/异能者/催眠师），其余 chunkId 为空、走 doc_id 兜底——真机实测 sources 展示正常（tocPath 正确）。设计上已允许（D3「对不上置 null 不阻塞」），登记为已知现状，如需提升命中率属数据侧 doc_id 规整议题，不在 SP3 范围。
3. **【观察】SpellListService 的 objectMapper 用字段初始化**（`private final ObjectMapper = new ObjectMapper()`）而非 @Autowired：交付注释称对齐工程先例，功能无影响，不追究。
4. **【观察】「防护混乱/邪恶/善良/守序」等合并条目**：列表页把四个阵营法术合并为单条导出（与源页排版一致），枚举计数与源页逐条比对一致，属如实反映源数据。
