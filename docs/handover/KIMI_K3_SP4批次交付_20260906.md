## 2. 实现要点（对照方案 D1~D7）

### T1 · SourceCollector（`rag/SourceCollector.java`）

- 存储：`ThreadLocal<LinkedHashMap<String, Document>> current`（键 = `dedupKey`，见下）+ `ThreadLocal<Boolean> gapReported`。
- `add(List<Document>) → List<Integer>`：未 begin / 空入参 / null → 返回 `List.of()`；新键 `map.put(key, doc); ids.add(map.size())`（1-based 递增）；重复键 `ids.add(numberOf(map, key))`（查既有编号）。
- `numberOf(map, key)`：遍历 keySet 计数（注释说明：来源数小用遍历，换取单结构存储，避免「编号表与去重 map 双结构不同步」腐化）。
- `drain()`：返回 `new ArrayList<>(map.values())`（插入序 = 编号序，编号不再二次计算），随后清空 current/gapReported。
- `dedupKey`：`chunk_id`，缺省 `"doc:" + doc_id`——与 AKN-008 定稿去重语义**逐字一致**（设计 D1 要求）。
- 类 Javadoc 说明编号机制 + 语义保留。

### T2 · RetrievalTools 三处注入（`rag/RetrievalTools.java`）

- `searchByMetadata`：`formatCompact(docs, ids)` 每条紧凑行末尾 `+ " [#" + ids.get(i-1) + "]\n"`；**截断 break 时被截断条目不标注**（防半截行标错号）。
- `vectorSearch`：每个命中片段头 `[#N] --- 片段 N ---`（编号**前缀**，保留既有 `--- 片段 N ---` 子串形态）。
- `getSpellList`：命中后 `collector.add(List.of(listPageDocument))` 取回编号，三个 return 分支末尾统一加 `\n\n本清单来源 [#N]`（单来源不逐条挂号，D2 语义）。
- 三处 add 均改为 `List<Integer> ids = collector.add(docs)`，编号与 add 同轮分配，天然与 sources 对齐。

### T3 · PromptBuilder 增量 + ChatService 剥离

- **PromptBuilder（D4）**：PROMPT text block 末尾追加一条 bullet——「引用检索结果的句子末尾标注来源编号 `[#N]`（SP4 D3）：N 只能取自工具返回文本中的 `[#N]` 标记；多个依据连写 `[#1][#2]`；禁止编造编号；无检索依据的推断内容不标注；reportDataGap 路径回答无编号」。既有条目零改动。
- **ChatService（D5）**：
  - `CITATION_MARK = Pattern.compile("\\[#([^\\]]*)]")`（只匹配闭合形态；未闭合 `"[#"` 按普通文本保留，登记已知语义 §8）。
  - `finish()` → `buildResponse(answer, cid, question)`；drain 后调 `stripInvalidCitations(answer, sources, question)` 再构造 ChatResponse。
  - 合法性判定：`body.matches("\\d+") && body.length() <= 9`（防溢出）且 `1 <= parseInt <= sources.size()`；合法原样保留，非法从正文移除、保留句子本身，累计后记一条 WARN（含剥离的标记 + 来源上限 + question 摘要 30 字截断）。
  - **不重排、不补插、不改 sources 顺序**——LLM 漏标后端不替它补号（非目标）。

### T4 · 前端（`src/main/resources/static/index.html`，D6）

- 全局 CSS：`.source-head` flex 行（`.source-badge` `[N]` 徽标 + `.source-book` 书名同行）、`sup.cite` 样式、`@keyframes cite-flash` 高亮动画；dark 色板下上标/徽标可读色 `#58a6ff`。
- `renderSources`：`items.map((s,i))`，`n=i+1`，每项头行加 `<span class="source-badge" id="src-N">[N]</span>`。
- `render()`：`marked.parse(escapeHtml(answer))` 之后 `html = html.replace(/\[#(\d+)\]/g, '<sup class="cite" data-n="$1">[$1]</sup>')`——`[#N]` 经转义与 marked 处理形态不变，替换产物为固定模板串无注入面。
- 点击事件委托（`resultEl` 上，`closest('sup.cite')`）：无上标不拦截；`querySelector('#src-'+data-n)` + `details.source` 缺任一 return（防御）；展开 details → `scrollIntoView smooth center` → 移除/重排/添加 `cite-flash` 重启动画。
- 越界编号已被后端 D5 剥离，前端遇到的 `[#N]` 必合法；防御分支保证 N 无对应来源项时按纯文本、不报错。
