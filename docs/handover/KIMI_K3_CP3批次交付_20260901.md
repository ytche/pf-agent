## 四、CP3-2 cicd 装配

```python
"profession": {
    "output_dir": "vectorizer/output/职业",
    "verify_module": "vectorizer.verify.verify_profession",
    "invariants": [
        "verify_data_invariants.py",
        "--chunks", "vectorizer/output/职业/chunks.jsonl",
        "--max-empty", "0",          # 实测空 text 0
        "--oversize-limit", "5000",
        "--max-oversize", "15",      # 实测 15：全定性合法大块
        "--min-total", "12500",      # 现量 13922，-10% 余量
        "--main-component", "class_feature",
        "--min-main-count", "9500",  # class_feature 现量 10572，-10% 余量
        "--max-book-unknown", "0",   # 实测 book '?' 0，顶格不预放（棘轮设计）
        "--max-toc-empty", "0",
    ],
    "tests": [
        "test_category_*", "test_verify_base.py", "test_cicd.py",
        "test_profession_*",
    ],
},
```

`collect_test_files` 每个 glob 模式至少命中 1 文件（拼写错误收集期 raise，防静默漏测）。
