## 三、发现的问题 / 观察项（均不阻塞）

1. **【观察·部署注意】虚线属性的环境变量绑定坑**（Spring 6.2.6 实测）：`PF_RATELIMIT_PER_MINUTE` **不生效**（静默回落默认 20），去虚线形式 `PF_RATELIMIT_PERMINUTE` 生效；而单段虚线的 `PF_QUOTA_ANONYMOUS_ROUNDS` 按松散绑定生效。多段虚线属性 env 绑定行为不一致——**部署文档（SP6）应写明：含虚线的配置项以 yml 或程序参数（`--pf.rate-limit.per-minute=N`，执行方冒烟即用的这种）为准**。功能本身无缺陷（yml/程序参数绑定精确）。
2. **【观察】限频计数对「被拒请求」也计数**（`compute` 先自增后判断）：滥用 IP 在窗口内持续被拒，符合成本控制取向，登记为已知语义。
3. **【观察】被拒路径响应极快**（429 约 3~30ms，配额 429 约 5~30ms）：fail-fast 设计目标达成，超限零 LLM 成本实测成立。
