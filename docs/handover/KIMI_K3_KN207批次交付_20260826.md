## 2. 改动明细

### 2.1 TextSanitizer（新增，`pf_agent/agent/src/main/java/com/pfagent/agent/rag/TextSanitizer.java`）

`public static String stripInternalSourceLine(String text)`，静态工具方法，`private` 构造器防实例化，非 Spring bean。

- **匹配规则（宁漏勿错）**：逐行处理，**仅当一行同时满足** ① `trim()` 后以 `> 来源：` 开头、② 含 `未整理 →` 或 `未整理→`——删除该行；不含标记的 `> 来源：` 行保留，普通内容行一律不动。
- **空行坍缩**：剥离后把因此产生的连续空行坍缩为一个、文末空行直接去掉；删除行前后原本相邻的行不凭空插入空行。
- **原样短路**：整段文本无匹配行时直接返回原值（不重建，严格保证无匹配文本原样返回）；`null`/空串安全。
- **CRLF 兼容**：按 `\n` 分割、`trim()`/`isBlank()` 天然吞掉 `\r`，数据侧 CRLF 行尾不影响判断。

### 2.2 出口接入

1. **LLM 侧** `RetrievalTools.formatFragments()`：`truncate(doc.getText(), vectorResultChars)` → `truncate(TextSanitizer.stripInternalSourceLine(doc.getText()), vectorResultChars)`——**先剥再截**，避免截断后残留「未整理 →」半行。`formatCompact()` 只输出 metadata 不含正文，未动。
2. **前端侧** `ChatService.toSourceRef()`：`SourceRef.content` 由 `doc.getText()` 改为 `TextSanitizer.stripInternalSourceLine(doc.getText())`。

### 2.3 不改的地方

`Document.text` 本体、SourceCollector、embedding、chunks.jsonl、`evaluate.py` 判分（判分走 chunkId/tocPath/book，不依赖该行）——全部不动。toc 回填链路（`BackfillChmTocPath`）零风险。
