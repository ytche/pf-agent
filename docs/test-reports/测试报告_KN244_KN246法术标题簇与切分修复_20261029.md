## 白盒审计与返工记录

### 1. 标题归一顺序

修复点放在 `_pre_unify_text` 快照和 `split_into_items` 之前，保留单一切分器。覆盖学派标题、粗体标题、带链接标题和紧凑正文标题的跨行/同行变体。

### 2. 既有后缀规则误删正文

`_strip_title_suffixes` 原将正文破折号当成种族后缀，从章节正文一路删到下一法术。已排除句读和学派标记，并补真实破折号回归。

### 3. 译者注两种写法

“译文引自”与“译文来自”均可剥离；无右括号的译者名也可处理。含 `【学派】` 的行不再按纯注释整行删除。

### 4. 紧凑罗马标题

同行和跨行都保留完整中文基名；注记括号不再被吞入标题。rescue 捕获窗增加正文和裸字段终止边界，不读后续法术的等级行。

### 5. chunk_id 顺移

A 桶白名单和 KN245 裁除集原按旧 ID 查表，导致错挂和失效。实现旧 ID 顺移区间映射；裁除判断使用“旧 ID + 标题”双键，避免新同号条目被误裁。

### 6. 旧估计基线

全量测试 initially 为 1758 通过、1 失败。page_1141 从 2 增至 4 是恢复密语术和隐藏知识，已回源确认并更新勘探估计；最终复跑后 **1769 全绿**。

### 7. 独立评审返工

- 白名单回退增加标题校验，阻断藏密箱/秘藏柜旧 ID 错挂。
- 裁除测试改用修复后的真实 ID，并直接断言双键命中；18 条裁除在最终 metadata 写入前统一生效。
- 增加 ID 区间与 state map 全量对齐测试、真实 page_1166 源文件测试和章节负例。
- 修复环级续行截断，狩猎大师之矛 10 个职业值完整；手舞足蹈复用 KN019 已批准译名恢复。
- 最终 chunk 数 4206、新增 34、环级变化 116、空值 381/4205、union 23010。
