- **默认路径零变化（结构保证）**：`formatLevel(c,l,m)` 委托 `(c,l,m,null,null)`；paged=false 时窗口=[0,total) 与旧循环等价；全量未截断时 `!paged && !hasMore` 提前返回、footer 零变化（新单测 defaultNoPaginationKeepsLegacyOutput 断言 doesNotContain has_more/续取/已翻完 ✅）。注意：默认路径**被截断时** footer 话术从旧「仅展示前 N 条」改为「真实总数/返回区间/has_more/续取 offset」——此为本次功能的预期变更（原截断话术无续取路径），旧用例已同步更新断言并有注释说明；coder「默认行为不变」的准确含义 = 未截断全量输出不变。
- **窗口边界**：offset≥total（total>0）→ 可读越界提示（含真实总数，不假值）✅；offset 负 → 钳 0 ✅；首条超字符预算 → shown==0 分支不给续取 offset（对齐 AKN015-T2，防死循环）✅；footer 总数 = levelTotal 口径（官方+派生）✅；派生条目全局编号 = 官方数+派生序，窗口切片 `max(off-官方数,0)` 起、`官方数+i < winEnd` 止，跨段续接正确 ✅；部分截断（字符预算 mid-window break）时 nextOffset=off+shown 计数正确 ✅。
- **5 条新单测质量**：全部真断言——分页三页拼接拿全 5 条且逐页 footer 值精确（第 1~2/3~4 条、offset=2/4）、末页 doesNotContain has_more（无假 has_more）、越界提示三要素、负 offset 钳制结果、levelTotal==5 与 footer 一致、默认路径无翻页话术。无假测试。既有截断用例同步更新并注释口径 ✅。
