## 缺陷清单

| 编号 | 级别 | 描述 | 复现 |
|---|---|---|---|
| B4-QA-1 | Minor | `hasPrerequisites` 接受非布尔值（如 "yes"/"1"/"是"）时静默落入 false 分支（按无前置匹配），不报错也不提示可用值；LLM 传值手滑时结果集静默错误（4080-3386=694 条假命中） | `filters={hasPrerequisites:"yes"}` → total=694，与 "false" 相同 |
| B4-QA-2 | Minor | 过滤值为空串时静默匹配空字段：race `size=""` 命中 74 条 size 为空的条目（空串等于空串）。语义上或为可接受（如实匹配），但 LLM 传空值时无任何提示 | `filters={size:""}` → total=74 |
| B4-QA-3 | Minor（观测） | 方案验收标准要求"limit>200 或 <1 钳制并在返回头部注明"，实现满足；但工具层 offset 为负时钳制为 0 无任何注明（listDataGaps 先例是注明的）。行为安全，仅信息性 | `offset=-5` → 正常返回第 1 页，无注记 |

无 Major/Blocker 缺陷。
