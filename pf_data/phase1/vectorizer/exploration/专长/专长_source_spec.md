# 专长模块源文件规范化建议（source_spec）

> 产出日期：2026-08-01 | 数据基础：`专长_per_file.jsonl`（189 文件逐文件勘探）+ 五合一扫描聚合
>
> 分类原则（与法术 `法术_source_spec.md` 一致）：**格式缺陷** = 源文件本身格式需要改动才能被解析器统一处理；**非条目陷阱** = 文件中混入的不应被当作专长条目的内容，需解析器识别过滤或预处理剥离。
>
> 判别器 `fc_match.py`（30+ 簇 + 六放行形态）已吸收其中大部分形态作为合法放行；本规格的读者是 **formats/feat.py 解析器** 与 **补丁包执行方**。

## 第一部分：格式缺陷源文件

### A. 断行英文名（104 文件，最高频）

英文名换行断裂是**最普遍的格式问题**，覆盖 104/189 文件（55%）。断裂使基于行的正则匹配无法获得完整英文名，需跨行合并（判别器已用跨行窗口处理，解析器需同样支持）。

| 文件 | 断裂示例 | 修改建议 |
|---|---|---|
| `专长.md` | `**邪恶领导力（Vile\nleadership）**` | 合并括号内跨行 |
| `专长11.md` | `**突袭警惕（Ambush\nAwareness）**` | 合并括号内跨行 |
| `专长10.md` | `不屈坐骑(战斗) Indomitable Mount (Combat) 出自 格拉利昂的城市（Cities of\nGolarion）` | 合并括号内跨行 |
| `专长55.md` | `Apparent\nDescriptor` | 合并 |
| `专长32.md` | `**矢志不移（Sheltering\nStubborness）**` | 合并 |

**批量修复建议**：
```
模式：中文（[^）)]*\n[^）)]*）
替换：同一行内用空格拼接
```
> 与法术 KN006 同款。判别器 FC-1 系列已按跨行窗口计数，本项修复只影响 titles 完整性与元数据抽取，不改变条目总数。

### 与 format_cluster 六放行形态的对应

| 源数据缺陷 | 判别器形态 | 解析器行为 |
|---|---|---|
| 断行英文名 / 括号前空格 | whitespace | 归一化空格 |
| 半角/全角括号混用 | punct | 归一化括号 |

| 出处/来源尾注行 | annotation | 不产条目，记录 source |

### 红线

1. **改源数据不改脚本**（质量攻坚决议）：P0 修复走清洗层，不手改 189 个源文件。
2. **判别器改动须以 `fc_deviation_matrix.json` 为回归基准**（format_clusters §五）。
3. **file 字段口径**：29/189 份带 `pf_rules_md_organized/` 前缀，统一为 `专长/xxx.md` 相对路径。
