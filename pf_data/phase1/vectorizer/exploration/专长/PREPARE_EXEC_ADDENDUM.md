# 专长 Prepare Phase 执行补充说明（试点后追加）

> 本文件是《docs/专长/Prepare_Phase_交接文档.md》的**执行补充**，由 k3 在 Wave 0 试点（B01/B04/B07）后追加。
> 交接文档仍是权威；本文件只收紧字段要求、记录试点实测结论。**两份都要读。**

## 一、新增硬要求：title_forms[].raw_example（校验脚本强制）

`title_forms[].pattern` 只写"逻辑形态"（如 `**中文名（English）**`）是**不合格交付**——拿去写正则会全军覆没。

试点实锤（`专长/page_196.md`，APG）：标题真实形态是

```
L191: **额外背景（****Additional
L192: Traits****）******
```

即 ① 中文名后是 `（****`（四个星号）不是 `（`；② 英文名含空格时 **100% 断成两行**，`〔类型〕` 落在第二行；③ 行尾有 `******` 噪声。

因此每个 `title_forms[]` 项**必须**含：

| 字段 | 要求 |
|---|---|
| `pattern` | 反映真实字符：星号个数、括号是全角（）还是 ASCII、英文名在粗体内还是外、是否跨行、行尾噪声。能落地成正则。 |
| `raw_example` | **从源文件逐字复制**的原始行，带行号；跨行的给全部行（数组或 `\n` 连接）。**禁止手写还原、禁止美化。** |
| `count` | 该形态的条目数 |

**同一文件里"断行"与"不断行"是两个不同的 title_form，必须分开列**（page_196 实测：断行 143 / 单行 19，触发条件是英文名是否含空格）。

## 二、试点实测结论（推翻/补充交接文档 §3.2 假设）

1. **标题不一定加粗、不一定有全角括号**。`专长1.md` 实测形态为 `**生物专攻**Creature Focus`——只有中文名加粗、英文名裸在粗体外、无（）。机检 `title_candidates=0` 在这类文件上**全盲**，机检为 0 不代表无条目。
2. **`（****` 四星形态普遍存在**（CHM 转 md 时粗体标记与括号交错），不要假设 `（English）`。
3. **feat_type 至少 7 种风格共存**：`〔战斗〕`、`【战斗】`全角方括号、`(战斗)`、`(战斗专长)`、`(团队)` 与 `〔团队〕` 混排、`〔战斗，团队〕`复合、`****战斗`粘连、以及**大量条目根本不标**（page_196 实测覆盖率仅 58.6%）。不要假设人人有标签。
4. **裸 CR 会把英文单词内部切开**，必须 `open(..., newline="")` + `prepare_scan.py::read_logical_lines()` 重组逻辑行，否则条目数、表格行全错。
5. **"单专长 + 多变体子描述"是高频形态**（父专长下 4~9 个 `**中文名（English）**` 子项，如 page_196 的化兽态、专长14 的古老传统）。子项**不是**顶级专长，`estimated_count` 要说明你是否计入，并在 notes 说明父子关系。
6. **表格双语有两种**：page_276 是英文一行中文下一行（分行），page_196 是同行内英文+中文（同行）。两者陷阱不同，分别定性。
7. **表格可能无 `| --- |` 分隔行**，且子表头（如 `专长名称/超魔专长/团队专长`）是分类边界不是条目。
8. **跨书合订**：单个 md 内合订多本书的专长，中间用外站链接（如 `[godnessfantasy.net](...)`）作分隔。影响 source_book 归属，务必在 notes 记录。
9. **同文件重复条目真实存在**（专长11.md「突袭警惕」两次：无标签版 + 〔战斗〕版，旧/新版残留）。

## 三、trap kind 词表（校验脚本卡）

只允许：`断行英文名` / `链接陷阱` / `表格双语分行` / `译者行` / `PFS图标` / `重复条目` / `非条目表格` / `无标题正文`。

**任何新类型必须以 `其他：` 开头**（例：`其他：裸CR断裂`、`其他：删除线条目`、`其他：表格双语同行`）。词表内的词不能自行改写（写 `表格双语同行` 会被判越界，应写 `其他：表格双语同行`）。

每个 trap 必须有非空 `risk`（说明**会怎么坑解析器**，不是描述现象）与 `example_line`。触发过 HTML 回溯的加 `"html_consulted": true`。
