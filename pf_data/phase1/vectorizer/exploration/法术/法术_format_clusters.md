## 二、格式聚类

### Cluster 1：管道表格（Pipe Table）

| 属性 | 描述 |
|------|------|
| **标题模式** | `**中文 (English)**` 加粗，半角括号 |
| **字段布局** | Markdown 管道表格：`| 字段 | 值 |`，闭合行 `| --- |` |
| **特有异常** | 说明文字中也有加粗；字段值跨行（隐式拼接）；24 个字母分段标题 **A**~**Z**；末尾有大量非法术叙述文本 |
| **风险等级** | **高** |
| **文件数** | 1（Spell CRB.md） |
| **估算条目** | 623 |
| **代表文件** | `Spell CRB.md` |
| **关键陷阱** | 管道表格格式与其他所有文件完全不同，需专用解析器；`**小型生物**` 是正文描述而非标题；字段值跨行且无续行标记 |

### Cluster 2：APG 混合双格式

| 属性 | 描述 |
|------|------|
| **标题模式** | 前 63 条 `**中文 (English)**`（加粗），后续 198 条 `中文 (English)`（无加粗） |
| **字段布局** | 前 63 条：管道表格（同 CRB）；后续：`**字段**` 独占一行 + `**值**` 续行 |
| **特有异常** | **同一文件两种格式，在 D 段中间无缝切换（无过渡标记）**；后续格式字段值跨行 |
| **风险等级** | **极高** — 格式切换无标记，需运行时检测管道表格 `\|` 确定当前格式；标题加粗状态突变 |

| **代表文件** | `Spell APG.md` |
| **关键陷阱** | 需在读取过程中动态检测格式切换点；前 63 条和外部分开，各需不同解析策略 |

### Cluster 3：加粗值续行（Bold Continuation）

| 属性 | 描述 |
|------|------|
| **标题模式** | `中文 (English)` 无加粗（仅首条有加粗） |
| **字段布局** | `**字段**` 独占一行，`**值**` 在下一行以加粗续接 |
| **特有异常** | 英文名占位行提前 2-5 行出现（`Age\nResistance`）；部分标题有 `~~删除线~~`；字段值跨行；字母分段标题 |
| **风险等级** | **中** |
| **文件数** | 3（Spell UM.md / UC.md / ARG.md） |
| **估算条目** | 231 + 145 + 92 = 468 |
| **代表文件** | `Spell UM.md` — 删除线标记典型；`Spell UC.md` — 缩略条目（Communal 变体）缺少学派字段，需降级以 `**环位` 检测 |

**子变体 3a — UC 缩略条目**

`Spell UC.md` 中的 Communal 共用变体采用缩略格式，缺 `**学派` 字段。需以 `**环位` 行数作为更完整的条目计数依据（`**环位` 145 行 vs `**学派` 119 行）。

### Cluster 4：同行内联（Inline Concatenated）

| 属性 | 描述 |
|------|------|
| **标题模式** | `**中文（English）**` 加粗，全角括号 |
| **字段布局** | `**字段**：值` 同行冒号分隔，所有字段连续，无换行 |
| **特有异常** | 全角 vs 半角括号混用；部分字段值跨行续接（跨行时无续行标记）；OA 有降阶施法系列（Ego Whip I~V, Tower of Iron Will I~V） |
| **风险等级** | **中**（OA/UI 含前言混淆为**高**） |
| **文件数** | 3（Spell ACG.md / OA.md / UI.md） |
| **估算条目** | 134 + 142 + 89 = 365 |
| **代表文件** | `Spell OA.md` — 内联格式字段间无分隔，需正则连续解析；长篇前言 ~30 行混淆标题检测 |

**子变体 4a — OA/UI 全内联**

`Spell OA.md` 和 `Spell UI.md` 的字段在同一段落内完全连续，无换行。OA 还有 `~~删除线~~` 标题和表格（梦境旅行百分骰表）。

**子变体 4b — ACG 同行冒号**

`Spell ACG.md` 使用 `**字段**：值` 格式，全角括号 `（）`，跨行续接时行首无续行标记。

### Cluster 5：【学派】加粗字段大族群（The Largest Family）

这是最大、最复杂的格式家族，约 **65 个文件**，全部使用 `【学派】` 中文括号标记标题，字段以 `**字段名**：` 加粗标签引导。根据字段排布密度分为 4 个子变体。

#### 5a：字段稀疏空行

| 属性 | 描述 |
|------|------|
| **标题模式** | `【学派】(子学派)中文（English\nEnglish）[描述符]` |
| **字段布局** | `**等级**`、`**施放时间**` 等加粗标签各占多行，字段间有大量空白行间隔 |
| **特有异常** | 英文名跨行断裂；分组标题（"新法术"、"XX 法术"）混入；字段大段空白；图片标记 `![[图片]]`；译注 |
| **风险等级** | **中** |
| **文件数** | ~15（page_1007~1013, 1035, 1048, 1106~1107, Spell AArch, FoP, MTT） |
| **估算条目** | ~200 |
| **代表文件** | `page_1013.md`（龙类描述符 `[龙类/善良]` 在标题行 + d% 行为表）、`Spell FoP.md`（标题末尾 `/神祇名`） |

关键风险：英文名跨行使正则匹配不完整；分组标题伪条目易被误识别；部分字段顺序不固定。

#### 5b：字段内联紧凑

| 属性 | 描述 |
|------|------|
| **标题模式** | `【学派】(子学派)中文（English\nEnglish）` |
| **字段布局** | 加粗标签内联拼接，全部字段在一个段落内，空格分隔 |
| **特有异常** | 英文名跨行断裂；无换行；字段标签引用其他法术（`***召唤怪物 I***`） |
| **风险等级** | **中偏上** — 全部字段在一段内，行级解析无效，需段级分割 |
| **文件数** | ~23（page_1108, 1155~1177） |
| **估算条目** | ~180 |
| **代表文件** | `page_1155.md`（内联拼接典型，`**法术`/`**介绍` 等非条目加粗干扰）、`page_1168.md`（35 条目，密集） |

#### 5c：混合排布（稀疏 + 紧凑混杂）

| 属性 | 描述 |
|------|------|
| **标题模式** | `【学派】(子学派)中文（English\nEnglish）[描述符]` |
| **字段布局** | 同一文件内混合稀疏空行和内联紧凑两种布局，切换无规律 |
| **特有异常** | 英文名跨行；分组标题；译注；字段名拼写不一致（"施放时间" vs "施法时间"）；引用其他法术 |
| **风险等级** | **中偏上** — 布局不一致增加了分割难度 |
| **文件数** | ~12（page_853, 854, 1141~1153, 669, 693, 717~720, 805, 852, 883, 886） |
| **估算条目** | ~130 |
| **代表文件** | `page_1143.md`（紧凑与空行混合无规律）、`page_1145.md`（标题末尾 `─ 种族名`） |

#### 5d：格式突变

| 属性 | 描述 |
|------|------|
| **特征** | 同一文件内从一种格式突然切换到另一种格式 |
| **风险等级** | **极高** |
| **文件数** | 2 |
| **代表文件** | `page_1034.md` — 前半部分字段分行（稀疏空行）→ 后半部分全内联（"间谍法术"段切换）；`page_1146.md` — 前半部分 `**等级**：` + 空行 → 后半部分 `**学派**：...；**等级**：...` 紧凑内联 |
| **估算条目** | 14 + 6 = 20 |

需要运行时检测布局变化。建议在解析过程中跟踪字段间距特征，检测到突变时切换解析策略。

### Cluster 9：超紧凑内联格式（Ultra-Compact Inline）

| 属性 | 描述 |
