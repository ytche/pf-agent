# 召唤师（Summoner）职业变体


** ****进化论者****（Evolutionist）**





幻灵的演化通常是一个缓慢的过程。随着召唤师逐渐的成长，他对幻灵的控制能力也同样的上升。但进化论者对幻灵型态的控制力则更加的强大，他可以控制幻灵的演化，以对付任何的威胁或挑战。





**幻灵突变（****Mutate 
Eidolon, Su****）**：6级时，进化论者平日可以像升级时一般改变他幻灵的进化。要使用此能力，他得进行一项耗时一整天、并消耗每召唤师等级200gp。此能力取代主宰呼唤。


【PFS】此能力只能在两次战役之间使用





**型态演化（****Evolve 
Base Form, Su****）**：8级时，当进化论者升级时，他可以重新选择幻灵的基本型态。一旦他选定了幻灵的型态，那么直到他下次升级之前都无法更改。此能力取代位置转换。





**幻灵重塑（****Transmogrify, 
Sp****）**：12级时，进化论者可以每天以类法术能力施展一次“幻灵重塑术（Transmogrify, 
APG）”，以此方式施展的“幻灵重塑术”需要消耗1分钟的施法时间，且不需要任何材料成分。此能力取代高等幻灵护体。








**自然学家 
Naturalist**





比起其他研究异界存在的召唤师，自然学家的幻灵更接近于自然界中常见的动物。这些召唤师学习了一些猎人的驯兽技巧而更少涉足奥术知识，模拟熊，狼，猫咪等强大的掠食动物，将自己的幻灵塑造的更为凶残，野性和隐秘。这些野兽的特征，反过来，也会在幻灵逐渐变形时影响自然学家自己。





**自然呼唤**** 
Nature`s Call****（****Sp****）：**在1级时，召唤师可以以类法术能力的形式施放法术一级召唤自然盟友，每天可以使用此能力的次数等同于3+自然学家的魅力调整值。除此之外，本能力和召唤师原本的一级召唤怪物能力相同（包括环数提升和类似的限制）。本能力取代召唤怪物。





**动物之力（****Su****）：**在4级时，以一个迅捷动作，自然学家可以赋予自己的幻灵以野兽的力量。每当使用本能力时，自然学家都可以选择一个猎人的动物之力，将他的召唤师等级－2视为有效猎人等级。在这个等级，自然学家无法为自己同时添加动物之力。这个效果持续到幻灵被驱离或是返回原位面为止。





当动物之力被激活时，自然学家的幻灵也会暂时获得该种动物的一些特征——使用蝙蝠动物之力的幻灵会有宽阔的耳廓和大眼睛，在爪子和肢体间长出皮膜；使用雄鹿动物之力的幻灵会长出蹄子和角，但这些外形变化并不会真的改变幻灵但天生与魔法能力。本能力取代幻灵护体和高等幻灵护体。





**第二动物之力（****Su****）：**在10级时，每当自然学家为幻灵加持动物之力时，他都可以同时选择两个不同的动物之力同时影响他的幻灵。本能力取代异界形态能力。





**分享动物之力**** 
Shared Focus****（****Su****）：**在14级时，自然学家能够将获得自己幻灵的野性力量。每当自然学家为幻灵添加动物之力，他自己就会获得相同的动物之力效果，直到他的幻灵被驱离或返回原位面为止。但是，无论他的幻灵获得多少种动物之力，自然学家只能获得其中之一。本能力取代生命链接。





**第三动物之力（****Su****）：**在18级时，每当自然学家为幻灵加持动物之力时，他都可以同时选择三个不同的动物之力同时影响他的幻灵（直到他本人更换不同的动物之力为止）。本能力取代高等异界形态能力。








##  原初之民（First 
Worlder）【召唤师变体】
大部分召唤师跟那些来自位面最遥远之处的生物有着紧密的联系。只有少数召唤师与自然有着原始的联系，而他们的力量则与原初世界（First 
World）紧密相连。这些召唤师与德鲁伊合作的不在少数，因为他们就跟德鲁伊一样，与自然世界有着强大的连结。有些原初之民因为奇特的能量与智慧浸入身心而近乎疯狂，这些可悲的灵魂多半会对伐木工人、德鲁伊或无辜的过路人发动袭击，丝毫不顾他们是否真会带来威胁。原初之民的幻灵通常看上去像是精类生物或植物怪物，但也有一些是带有夸张特征的怪奇动物。

召唤自然盟友（Summon Nature’s 
Ally，Sp）：从1级开始，原初之民可以施展召唤自然盟友，每天的次数为3+他的魅力调整值。在召唤师会获得更强力的召唤怪物法术的那些等级上，他改为获得环数相同的召唤自然盟友法术（19级时，他可以使用召唤自然盟友Ⅸ或异界之门）。当原初之民获得类法术能力形式的召唤自然盟友时，他将其加入他的职业法术列表中（如果他想以真正的法术形式来施展该法术的话，还是必须选择它作为已知法术）。

　　这种被成为精类的古怪生物遍布世界各地，无论是自然界还是别的位面领域都漫山遍野。精类召唤师就是那种深入精类领域召唤精类的召唤师。与精类接触使得他们与一般召唤师格外不同起来。

　　本职技能：精类召唤师将唬骗、交涉、易容、自然知识、位面知识、生存加入本职技能列表，取代其他所有知识。该能力修改了unchained召唤师的本职技能。

　　自然的呼声Nature's 
Call：取代从召唤生物列表中召唤生物，他们的召唤怪物类法术从召唤自然盟友列表中召唤同环的生物。其它方面依然遵循召唤师的召唤怪物类法术能力限制。该能力调整了召唤师的召唤怪物类法术能力。

精类幻灵Fey 
Eidolons

　　精类是古怪而神奇的生物，倾向于通过幻象、幻惑、异族幽默来战斗。来自妖精王庭的一些精类有着不同寻常的外形，但能成为幻灵的精类多半接近过人类的心灵，因此看起来也会如同人类一般，只是会拥有一些微妙的特征，比如尖耳朵或者蝶翼之类。
　　根据幻灵性格不同，他们与凡人召唤师缔结契约的理由也千奇百怪；间或，他们的需求也很突然，比如因为伴生树死去因为不想变为其它东西而立刻和人类缔结契约的树妖等等。另一方面，嗜血渴望的红帽子就会想和同样暴虐的召唤师联系。无论理由是什么，它们与召唤师之间纠缠不清的不仅仅只是契约，还有情感，这种强烈的情绪联系就算是邪恶精类幻灵亦不遑多让。

　　阵营：任意。精类幻灵没有阵营亚种。
　　基础形态：二足型（肢体[臂]，肢体[腿]）
　　基础进化：1级时，精类幻灵获得特技、交涉、易容、逃脱、自然知识、表演、巧手、使用魔法装置作为本职技能。它获得低光视力进化，技能精通（选择一个技能）进化，和将舞光术、侦测魔法、幻音术、魔法伎俩之一作为类法术随意使用的能力。一旦选择好所施展的类法术，就无法再改变。
　　4级时，精类幻灵获得穿林步德鲁伊职业能力。
　　8级时，精类幻灵可将魅惑人类、纠缠术、油腻术、无声幻影、隐雾术、渐隐术之一作为类法术每日可使用三次，并可在1级可选类法术中再选择一个。
　　12级时，精类幻灵获得DR5/寒铁。她们长出蝶翼，获得飞行进化。
　　16级时，精类幻灵可将目盲术/耳聋术、侦测思想、闪光尘、狂笑术、隐形术（限自身）、弱效幻影、镜影术、巧言术之一作为类法术每日可使用三次。并可在1级可选类法术或8级可选类法术中再选择一个。
　　20级时，精类幻灵的DR增加为10/寒铁。可将群体暗示术、假象术、预置幻影、隐匿之纱之一作为类法术每日使用一次。并可在1级可选类法术或8级可选类法术或16级类法术中再选择一个。
