## 异能选集PA 催眠师变体
> 来源：异能选集（Psychic Anthology），页码见原书，未整理 → 异能选集PA → 职业选项 → 催眠师 → 变体
催眠师变体研究过奥利瓦罗小品曲集的催眠师将其中的技术用于各种各样的成就上，如下列的变体所示。自我催眠者（Autohypnotist）自我催眠者具有强大的异能力量，甚至于自己无法完全掌握。因此，在对抗敌人时控制自我的力量，对他而言和敌人一样麻烦。自我催眠（Autohypnosis，Su）：在1级时，自我催眠者掌握了令他的催眠注视更为强力的方法，这也伴随着一个可怕的代价——自我催眠者在他使用自己的力量时，会被自己的力量压垮。当自我催眠者将他的注视聚焦到一个目标上时，目标从催眠注视中得到的减值——以及任何自我催眠者具有的深邃注视（Bold 
Stare）增强项目或者注视专长（Stare 
Feats）——增加1。然而，在聚焦注视时，自我催眠者会与他的目标承受相同的减值，包括任何他所具有的深邃注视增强项目。自我催眠者可以减少或者取消他通过催眠注视在自己身上施加的减值，但是如此做会令他的目标有机会脱离注视的效果。自我催眠者可以通过一个迅捷动作来令他从催眠注视中承受的减值减半，持续1轮。若他如此做，催眠注视有25%的概率同时结束。除此之外，他可以选择取消他从催眠注视中承受的减值，持续1轮。但催眠注视会有50%的概率结束。该能力改变了催眠注视（Hypnotic 
Stare）职业能力。广域注视（Wide Stare，Su）：在5级时，当自我催眠者将他的注视聚焦到一个敌人上时，他可以通过一个标准动作，扩展自己的催眠注视。当他如此做时，所有在他的目标10尺范围内的生物均会承受催眠师的催眠注视，以及深邃注视带来的减值，如同他对这些生物的每一个维持催眠注视一般，除了对于这些生物，他的催眠注视减值视为减少2。当自我催眠者使用该能力时，他无法排除盟友或者其他生物。如果对于自我催眠者所聚焦的敌人的催眠注视结束，该效果结束。该能力取代心智潜能（Mental 
Potency）职业能力。形态塑造师（Material Manipulator）形态塑造师使自己沉迷于现实，使用他的魔法力量，令周围的存在顺从他的指令，而不是在支配精神这种事儿上浪费时间。操纵法术（Maipulator Spells）：形态塑造师可以从催眠师法术列表，以及一个调整后的术士/法师法术列表中施放异能法术。所有6环，以及以下的幻术（五官幻觉），幻术（幽影幻觉），以及变化系法术视为形态塑造师法术列表的一部分。这些是异能法术。该能力改变了催眠师的法术能力，并代替精湛骗术（Consummate 
Liar），2级获得的催眠师诡计（Mesmerist Tricks），以及多重诡计（Manifold Tricks）职业能力。形态修正（Revision，Su）：3级时，形态塑造师可以修改一个生物的身体，来改变它的外观。每日，他可以进行3+它的魅力调整值次数的修改。使用形态修正是一个标准动作（或者一个迅捷动作，如果他对自己使用），并且形态塑造师必须能够接触到他的目标。不自愿的目标必须通过一个强韧豁免（DC等于10+形态塑造师的催眠师等级的一半+他的魅力调整值）来取消该效果。3级时，形态塑造师可以调整目标的身高和重量，可以在目标生物的类型和体型范围内（核心规则书CRB 
P169），以及该生物标准身高体重范围内，增加或者减少目标的身高和体重。6级时，他可以调整目标的性别，物理特性（例如鼻子的大小，指甲的长度，脚形），色素分布（包括眼睛，头发以及皮肤颜色）到任何目标所属的生物类型（如可能，包括其后代类型）的自然可能状态。在10级时，他可以调整目标的年龄，回退目标的年龄最年轻到刚刚结束幼年（对于人类约为8岁），最老到达暮年（venerable）。这会导致目标获得老化效果加值与减值，但是不会影响其他从年龄中获得的能力（例如额外种族HD，超自然能力等）。在14级时，他可以调整目标的类型或者子类型，如同变形术（Polymorph）。在20级是，他改为如同高等变形术（Greater 
Polymorph）调整目标的类型。该能力是一个变形效果，并且受到调整的目标不会被任何方式提前结束效果，除非形态塑造师允许。形态塑造师可以用本能力叠加多个调整到同一个变形效果中——例如，一个14级形态塑造师可以把自己调整为兽人，减少年龄到刚成年，给自己一双大脚和圆头鼻，并改变他的性别。该效果持续每催眠师等级10分钟。在10级时，该效果持续每催眠师等级1小时，或者每等级1分钟，如果他如变形术使用该能力。在20级时，该能力持续时间无限，或者10分钟每等级，如果他如同高等变形术使用该能力，并将目标变为与原本形态的类型不同的形态。催眠师可以通过一个自由动作取消该效果。目标穿戴的装备或者不会受到该效果影响——装备不会调整尺寸以适合佩戴者的新形态，也不会融入她的身体。因为该能力的效果而无法佩戴和持用的装备会掉落在地。该能力替换接触疗法（Touch 
Treatment）和精神支配（Rule Minds）职业能力。投影学者（Projectionist）投影学者不满足于仅仅从远处命令他人，他们能够使用自己催眠师的力量，通过从将自己身体中灵魂投影出去，来完全支配其他生物和物体。法术（Spells）：投影学者的异能能力表现出一种可以预见的形式，这令他们与其他施法者相比较为弱势。在每个所示的等级，投影学者必须学者所示的法术来学习，他不能选择其他的法术。投影学者必须学习的法术（以及必须选择它们的等级）为意识投影（Enter 
Image；APG；4级），次等物体占据术（Lesser Object Possession；OA；7级），驾行占据术（Riding 
Possession；OA；10级），物体占据术（Object Possession；OA；13级），高等物体占据术（Greater Object 
Possession；OA；16级）。投影学者将高等物体占据术作为6环法术加入到法术列表中。该能力改变了催眠师的施法能力。植入意识（Implant Consciousness，Su）：在4级时，投影学者可以使用一次他的催眠师诡计使用次数来在他和一个与他相似的物体——例如一副画或者一个雕塑——间建立一个异能链接。该能力在各个方面如同在一个生物中植入一个催眠师诡计，除了目标是一个物体。投影学者可以在任何时候通过标准动作激活诡计，在他如此做时，他的意识会离开他的身体并进入目标物体，如同意识投影法术（Enter 
Image；APG 
P219）中的描述“选择其中一个特定的人像将你的意识投射其中”。使用投影学者的催眠师等级作为法术的施法者等级。当用自己的意识投射到一个形象中时，投影学者可以对敌人使用和维持自己的催眠注视能力，并且可以触发他的痛苦注视。在8级时，他也可以在用意识投射到形象中时使用任何纯粹精神的能力（包括异能法术）。一旦他在一个物体中植入了诡计，投影学者可以在任何需要的时候将自己的意识投射到目标中，无论距离远近以及是否与目标在同一位面。一旦他停止维持意识投影法术的专注，他的意识会回到他的身体，并且他无法再次投影目标物体，除非他在该物体中再次植入另一个催眠师诡计。该能力取代在4级和8级获得的催眠师诡计（Mesmerist 
Trick）。隐藏者（Hidden Presence）：在5级时，投影学者获得隐藏者（Hidden 
Presence；OA）作为奖励专长。他不需要满足专长的先决条件。他在占据物体（如同物体占据术），将意识投射到物体中（如同意识投影的描述），以及占据其他生物时，获得隐藏者以及其他以隐藏者为先决条件的专长的效果。例如，窃心者（Intrusive 
Presence）无法用来阅读一个未被活化的，通过意识投影或者物体占据术所占据的物体的意识，因为物体不具有可以阅读的精神。该能力取代催眠师的心智潜能（Mental 
Potency）职业能力。欺诈怪客（Vexing Tricster）尽管大多数催眠师沉迷于欺骗的技巧，使用他们的精神相关能力令对手相信最为反常的现象真实存在，也有其他的催眠师满足自己能力能够实现的各种奇妙现象。这些催眠师被称为欺诈怪客。完美骗局（Consummate Trickster，Ex）：欺诈怪客在唬骗，易容，巧手，隐匿检定上获得+1加值。这个加值在4级以及之后的每3个催眠师等级增加1（最大+6）。该能力取代精湛骗术（Consummate 
Liar）职业能力。骗徒自我（Trickster's Ego，Ex）：在2级时，欺诈怪客获得寓守于攻作为奖励专长。如果他的智力属性低于13，在判断满足战斗专长的先决条件时，他的智力视为13。该能力取代强大自我（Towering 
Ego）职业能力。奖励专长（Bonus Feats，Ex）：在3级时，欺诈怪客获得一个诡计专长（见P16-17）作为奖励专长。他必须满足专长的前置条件。在10级时，他再次获得一个诡计专长作为奖励专长。该能力取代接触疗法（次级）（Touch 
Treatment, Minor）和接触疗法（高级）（Touch Treatment, Greater）职业能力。多重诡计（Manifold Hijinks，Su）：在6级时，欺诈怪客学会了在他的目标中同时植入多个被诡计专长调整的催眠师诡计（即调整诡计）的能力。在6级时，欺诈贵客可以在单个目标中同时植入两个调整催眠师诡计。在14级时，他可以在一个目标中同时植入最多三个调整催眠师诡计。该能力不会令催眠师能够在单个催眠师诡计上应用多个诡计专长。该能力取代接触疗法（中级）（Touch 
Treatment, Moderate）和接触疗法（破除结界）（Touch Treatment, Break Enchantment）职业能力。
