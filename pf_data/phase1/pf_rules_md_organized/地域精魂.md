**异能之地（Occult 
Locations）

**当进行异能冒险时，冒险的地点本身可以是活的东西，并成为为超自然故事中的活跃参与者。

**地域精魂（Loci 
Spirits）**

当过量的精神能量被强大的正面情感共鸣所饱和时，地域精魂就会形成。地域精魂通常成形于那些与下述地点产生联系的地点：曾出现过神迹的地点、曾出现过强大守护灵的地点、或是曾出现过善良阵营的神袛的地点。地域精魂可注入特定地域；它们的精神能量可增强在那里能体验到的正面情绪，创造了一种平和与守护的情绪。一种地域精魂也能表现出一种独特的典仪之力，且该力量与孕育该精魂的情感能量紧密相关。除非是极少数的特例，一处特定区域最多可以容纳一个地域精魂。





**地域精魂规则（Loci Spirit 
Rules）

**地区所散发出来的平和与守护的温暖，使处于该地区的人们明显感受到了一种地域精魂的存在。地域精魂的阵营总是秩序善良（LG）、中立善良（NG）、或混乱善良（CG）的，并在侦测善良（detect 
good）及类似魔法的效果下，总是拥有善良异界生物的灵光。

地域精魂可以注入到一处最大半径为5英尺×该地域精魂CR的区域，但实际区域通常受到与该地域精魂起源相关的区域的大小和形状限制。

**永久效果（Permanent 
Effects）**：地域精魂可在其寄住的区域内产生以下三种永久效果之一。地域精魂可能具有额外的持续中的永久效果，每超过第一个效果外的每一个效果，都会使该地域精魂的CR增加1。

*能量（Energized）*：，抵抗在地域精魂的范围内被引导的正能量（resist 
positive channeled energy）的DC获得+4神圣加值（sacred 
bonus），而抵抗负能量的DC减少4。法术抗力不适用于此效果。

*守护（Protective）*：地域精魂的范围内，被一道反邪恶法阵（magic circle 
against evil）效果守护。

*神圣（Sacred）*：每个进入地域精魂的范围内的不死生物，在其攻击骰、伤害骰、和豁免骰上都会受到-1罚值。

除了永久效果外，每个地域精魂都拥有一种典仪效果，使其他生物可以通过进行特定的典仪活动来激活这种效果。了解适用于激活一个地域精魂典仪效果的典仪的知识，不仅是珍贵的，而且本身就是一种奖励，但GM视情况而定，可以允许一个生物通过尝试知识（位面）或知识（宗教）检定，其DC等于20+该地域精魂的CR，以获得相关典仪内容的线索，甚至可以完全确定典仪的内容。

使地域精魂典仪效果显形的典仪，需要司仪进行地域精魂数据中所列的每一项必要的技能检定。当司仪圆满完成典仪时，地域精魂就会立即其显形效果。

**显形类别（Manifestation 
Type）**：每一个地域精魂的典仪效果都有以下显形类别之一。

*单人（Singular）*：该效果的目标或影响仅能针对其司仪。

*团体（Coterie）*：该效果可针对该地域精魂所在区域内的所有生物，或者可能对除司仪之外的该地域精魂所在区域内的生物起效（例如，创造出某些任何人都可以使用的东西，就是一种团体的表现形式）。

*赐福（Boon）*：该效果以该地域精魂所在区域内的所有生物为目标，并提供一种赐福，该赐福允许受其影响的角色在接下来的24小时内，以一个直觉动作使用其效果。一个生物在同一时间，只能从一个地域精魂那里得到一种赐福。

在一个地域精魂表现出其典仪效果后，或者在一次失败的典仪后，该精魂在接下来的24小时内不能再次显现其效果。






**腐化一个地域精魂（Corrupting a Loci 
Spirit）**

地域精魂通常不会受到伤害，但如果在其所在区域内发生某类行为的话，则该精魂容易受其腐化。每个精魂都有相当于其CR两倍的生命值，用于抵抗腐化。某些特别恶劣的行为会降低地域精魂的生命值，使其更接近腐化，而某些善意的行为可以恢复其生命值，并保护该地域精魂免受腐化。

如果一个地域精魂的生命值被降至0的话，就会被腐化；此后，它成为了一个同CR的作祟（haunt），并失去了任何地域精魂的永久效果。一旦地域精魂被腐化的化，其效果被替换为影响心灵的恐惧效果。这些新的效果应该具备与先前地域精魂显形出的典仪效果相似的力量级别。在侦测善良（detect 
evil）及类似效果下，一个被腐化的地域精魂总是拥有邪恶异界生物的灵光。与作祟（haunt）不同的是，一个被腐化的地域精魂不能被亡灵无视术（hide from 
undead）骗过，但只要其CR保持不变，它可以受到大多数其他作祟（haunt）的修正。该作祟（haunt）的生命值与地域精魂最初的生命值相同；这是与地域精魂的生命值分离计算的另一管生命值，在该地域精魂被净化之前，这些地域精魂最初的生命值一直保持在0点。

被腐化的地域精魂可以像作祟（haunt）一样被中和（neutralized）或摧毁。当一个被腐化的地域精魂因为被中和而陷入蛰伏时，角色可以使用恢复精魂生命值的效果来尝试净化它（见表格）。在净化的时，增加该精魂的生命值并不会恢复其作祟（haunt）的生命值。如果一个角色成功地恢复了该地域精魂未被腐化时的全部生命值的话，那么这个角色已经彻底清除了腐化，而该地域精魂也会恢复曾经的仁爱。这可以分批发生在多次遭遇被腐化的精魂的过程中。在那之前，该作祟（haunt）会不断再起（reset）。


| 行为（Act） | 效果（Effect） |
| --- | --- |
| 实施暴力行为（Committing a violent act） | 降低1点生命值 |
| 实施谋杀（Committing murder） | 受害者每3个生命骰降低1点生命值（最低1点生命值） |
| 施放操纵死尸（Casting animate dead） | 每个不死生物降低1点生命值 |
| 施放唤起死灵或唤起高等死灵（Casting create undead or create greater undead） | 每环施放的法术环级降低1点生命值 |
| 召唤一个邪恶异界生物（Summoning an evil outsider） | 每个被召唤的邪恶异界生物降低1点生命值 |
| 呼唤一个邪恶异界生物（Calling an evil outsider） | 每环施放的法术环级降低1点生命值 |

**地域精魂特性（Elements of a Loci 
Spirit）
**地域精魂拥有如下这些基本属性。

**地域精魂名称（Loci Spirit 
Name）**：地域精魂的名称，及其挑战等级。

**经验值（XP）**：如果PC角色成功的从被腐化地域精魂的影响下幸存，他们可以获得这些经验值（XP）奖励。奖励的经验值（XP）取决于该地域精魂的挑战等级（CR）。由GM判断，为了追求某些目的，从而要蓄意腐化地域精魂的角色，也可能会因此获得该经验值（XP）。

**阵营、永久效果、显形类别、与影响范围（Alignment, Permanent 
Effects, Manifestation Type, and 
Area）**：此条目给出了地域精魂的阵营、其永久效果、以及其显形类别，另外还有注入地域精魂后其影响范围的大小（至多每施法者等级5尺）

**施法者等级（Caster 
Level）**：地域精魂拥有自己的有效施法者等级来决定其创造的等效法术效果，以及用解除（dispel 
magic）解除这些效果所需的施法者等级。

**生命值（HP）**：该条目是地域精魂在解除其腐化的有效生命值。一个地域精魂的生命值数等同于其挑战等级（CR）的2倍。

**弱点（Weakness）**：该条目是地域精魂所拥有的任何弱点，比如易于腐化或难以治愈。

**典仪（Ceremony）**：该条目是要使地域精魂显现其典仪效果，所必须进行的技能检定。

**效果（Effect）**：本条目详述了地域精魂的典仪效果，并包括了地域精魂会是如何显现的。

**腐化效果（Corruption 
Effect）**：本条目简要描述了如果地域精魂被腐化的话，其效果会变成什么样子。











**创造一个地域精魂（Creating a Loci 
Spirit）

**若创造一个如同下文范例中地域精魂，应当遵循以下步骤进行。

**第一步——设定基础挑战等级**：地域精魂的基础挑战等级等同于1+该地域精魂所复制的法术环级。

**第二步——决定实际挑战等级**：选择你希望该地域精魂将具有的要素，并将其CR修正逐一相加，以得出地域精魂的最终CR（见表6-1：地域精魂的CR修正）。

**第三步——决定施法者等级**：地域精魂的施法者等级等同于其挑战等级（CR）。

**第四步——决定生命值**：地域精魂的生命值等同于其挑战等级（CR）的2倍。

**第五步——决定典仪DC**：典仪检定的DC等同于20+该地域精魂的挑战等级（CR）。

**第六步——豁免DC**：如果一个地域精魂的典仪效果允许通过一次豁免骰来抵抗或无效该效果的话，那么其豁免DC等同于10+该法术环级+施放出该环级法术所需的最低属性的属性修正。正常来说，典仪的效果是无害的，因此该豁免DC只有当生物自愿抵抗或无效其典仪效果时才适用。

**第七步——决定腐化后的效果、攻击、和豁免DC**：一个被腐化的地域精魂所显形的效果，等同于一种与其独特效果（unique 
effect）相同法术环级的影响心灵的恐惧效果。一个被腐化的地域精魂的攻击加值（如果需要的话）通常等同于其挑战等级（CR）。

**表6-1：地域精魂的CR修正（CR 
Modifiers for Loci Spirits）**


| 地域精魂特性（Feature Type） | 对地域精魂CR修正（CR Modifiers for Loci Spirits） |
| --- | --- |
| 典仪需要超过1种以上的技能检定 | 每种额外的技能检定+1 |
| 永久效果 | 每超过第一个永久效果外的每一个永久效果+1 |
| 显形类别-单人 | -1 |
| 显形类别-团体 | 0 |
| 显形类别-赐福 | +1 |
| 难以治愈（Hard to heal）注1 | -1 |
| 易于腐化（Susceptible to corruption）注2 | -1 |

**注1**：难以治愈的地域精魂，在可恢复其生命值的效果中，仅可获得正常值一半的生命值。
**注2**：易于腐化的地域精魂，会因致其腐化行为中，失去正常值两倍的生命值。
