**官方术士血统全表**


术士血统，首次出现于CRB。术士须在她获得第一个术士等级时选定一种血统；一旦确定，不可更改。
在3级以及之后每2级，术士从自身血统的奖励法术列表中获得一个奖励法术，奖励法术不计入术士已知列表也不能在更高等级时替换为其他法术。
在7级以及之后每6级，术士从自身血统的奖励专长列表中获得一个奖励专长，她须满足该奖励专长的前提条件。

**狂野血统****（****Wildblooded, Archetype****）**：狂野血统是一般血统的突变，其血统奥秘与至少一个血统力量和未突变之前不同。要创建一个狂野血统术士，你必须选择一个现有的血统，然后从以下的突变血脉中选取一个与之相关的，取代血统奥秘和一部分的血统力量。在职业技能、奖励法术、奖励专长方面，异变后血统和原本的血脉相同。









**异怪血统（****Aberrant****）【****CRB****】******





在你的血统中，有一个外来和怪异的污点。你趋向于使用奇怪的方式思考，从大多数人所不希望的角度接近问题。随着时间的推移，这个污点在你的外形上得以显现。





**本职技能**：知识（地城）。





| 异怪血统奖励法术 |
| --- |
| 3级 | 人类变巨术（enlarge person） | 13级 | 隐匿之纱（veil） |
| 5级 | 侦测隐形（see invisibility） | 15级 | 异界传送（plane shift） |
| 7级 | 巧言术（tongues） | 17级 | 心灵屏障（mind blank） |
| 9级 | 黑触手（black tentacles） | 19级 | 形体变化（shapechang） |
| 11级 | 弱智术（feeblemind） |  |  |





**奖励专长**：战斗施法，精通卸除武器，精通擒抱，精通先攻，精通徒手打击，钢铁意志，法术默发，技能专攻（知识：地城）。





**血统奥秘**：当你施展一个“变形”子学派的法术，该法术延续时间增加50%（至少为1轮）。这项奖励不能与“法术延时”专长叠加。





**血统力量**：异怪术士升级时展现出越来越多他们污染遗传的迹象。尽管它们只有在被使用时才能被看见。


**酸性射线（****Acidic Ray, Sp****）**：1级开始，你能用标准动作发出一道酸性射线。通过一个远程接触攻击任何30尺以内的敌人。酸性射线造成“1d6+1/2术士等级”的强酸伤害。你每天可以使用此能力次数为“3+魅力修正”。


**肢体增长（****Long Limbs, Ex****）**：3级开始，当你使用近战接触攻击时，你的触及范围增加5尺。此能力并不增加你的威胁范围。在11级时，这项奖励增加为10尺。在17级时，增加为15尺。


**异常构造（****Unusual Anatomy, Ex****）**：9级开始，你的内在构造发生改变，你获得25%的机率忽略重击或者偷袭伤害。13级时此机率增加为50%。


**异型抗力（****Alien Resistance, Su****）**：15级开始，你获得等于“术士等级+10”的法术抗力。


**异怪形态（****Aberrant Form, Ex****）**：20级开始，你的身体变得完全异常。你免疫重击和偷袭。另外，你获得60尺盲视和伤害减免“5/-”。








**狂野血统：异变（****Warped****）******





异界污染在你的血脉中造成变形和基因突变。





**关联血脉**：异怪血统。





**血统奥秘**：每当你施展变化系法术的时候，你选择其中一个法术目标得到随机的异变增益。只要此法术持续存在增益就持续保留（见下表）。





**血统力量**：你强大的血液影响他人。


**异变之触（****Warp Touch, Sp****）**：1级时，你在别人身上制造了简单却混乱的改变。此能力作用在一个30尺之内的目标上，使之晕眩1轮。通过DC为“10+1/2术士等级+魅力修正”的强韧豁免可以避免此效果。你每日可以使用此能力次数为“3+魅力修正”。此能力取代酸性射线。

**深渊血统（****Abyssal****）【****CRB****】******





数代前，一个恶魔在你的遗传中散播它的污秽。虽然它并没有在你所有的亲属身上得到显现，不过在你身上尤为强势。你有时会有邪恶和无序的冲动。不过命运（和阵营）依然掌握在你手中。





**本职技能**：知识（位面）。





| 深渊血统奖励法术 |
| --- |
| 3级 | 惊恐术（cause fear） | 13级 | 转变术（transformation） |
| 5级 | 公牛之力（bull's strength） | 15级 | 高等传送（greater teleport） |
| 7级 | 狂暴术（rage） | 17级 | 不洁灵光（unholy aura） |
| 9级 | 石肤术（stoneskin） | 19级 | 怪物召唤IX（summon monster IX） |
| 11级 | 驱逐术（dismissal） |  |  |





**奖励专长**：强效召唤，顺势斩，法术强效，强韧加强，精通冲撞，精通击破武器，猛力攻击，技能专攻（知识：位面）。





**血统奥秘**：当你施展一个“召唤”子学派的法术，召唤生物获得伤害减免“1/2术士等级（最小为1）/善良”。这项奖励不能与召唤生物的任何原有伤害减免叠加。





**血统力量**：你变得更为强大，即使有人说你是疯了。恶魔的污秽在你血液中成长——如同你日益增长的力量。


**魔爪（****Claws, Su****）**：1级开始，你通过一个自由动作长出爪子。这些爪视为天生武器，并允许你使用全部攻击加值作出2次爪抓。每次攻击造成1d4伤害（小体型1d3），并附加全部力量加值。5级开始，这些爪在击破伤害减免时视为魔法武器。7级开始，伤害增加至1d6（小体型1d4）。11级开始，这些爪成为炽炎武器，成功命中时造成额外1d6火焰伤害。这是一个超自然能力。每天你能使用爪抓的轮数为“3+魅力修正”。


**恶魔抗力（****Demon Resistances, Ex****）**：3级开始，你获得5点电抗性，对毒素豁免+2加值。9级开始，增加为10点电抗性和对毒素豁免+4加值。


**深渊强壮（****Strength of the Abyss, Ex****）**：9级开始，你的力量获得+2内在加值。此奖励13级增长为+4，17级为+6。


**加强召唤（****Added Summonings, Su****）**：15级开始，当你使用怪物召唤法术召唤恶魔或者炼狱生物时，额外召唤来一个同种生物。


**恶魔之力（****Demonic Might, Su****）**：20级开始，深渊的力量在你全身奔流。你免疫电击与毒素。你同样获得火焰，寒冷，强酸抗性各10点。并且获得60尺心灵感应（允许你与任何能说一种语言的生物交流）。








**狂野血统：残暴（****Brutal****）******





来自深渊的力量可以彻底改变一个人，使其接近恶魔。





**关联血脉**：深渊血统。





**血统奥秘**：每当你施展造成生命值伤害的法术时，你可以指定一个目标使其额外受到2点伤害。此能力对不造成生命伤害的法术（例如属性伤害）无效。





**血统力量**：奋战是生存的关键。


**深渊之翼（****Wings of the Abyss, Su****）**：9级时，你可以长出翅膀每日飞行相当于你术士等级的分钟数，这对翅膀的飞行速度是60尺，且具有良好的机动力。此能力的使用时间不须连续，不过每次使用必须消耗1分钟的使用时间。此能力取代深渊强壮。











**奥秘血统（****Arcane****）【****CRB****】******





你的家族一向擅长于诡异的魔法艺术。你的许多亲戚都已经成为了法师，然而开发你的力量并不需要研究和实践。





**本职技能**：知识（任一）。





| 奥秘血统奖励法术 |
| --- |
| 3级 | 鉴定术（identify） | 13级 | 真视术（true seeing） |
| 5级 | 隐形术（invisibility） | 15级 | 高等传送（greater teleport） |
| 7级 | 解除魔法（dispel magic） | 17级 | 真言：震（power word stun） |
| 9级 | 任意门（dimension door） | 19级 | 许愿术（wish） |
| 11级 | 翱翔天际（overland flight） |  |  |





**奖励专长**：战斗施法，精通法术反制，精通先攻，钢铁意志，抄写卷轴，法术专攻，法术定发，技能专攻（知识：奥秘）。





**血统奥秘**：当你使用一个使所需法术位至少提高1级的超魔专长时，法术DC增加1。这项奖励不能与其自身叠加，也不能用于“法术升阶”专长。





**血统力量**：对你而言，魔法顺其自然。但当你升级时，你必须小心防止其压倒性的力量。


**奥术联结（****Arcane Bond, Su****）**：1级开始，你获得一个奥术联结，等同于同级的法师。你的术士等级与你的法师等级累加来决定魔宠或者联结物品的能力。该能力不允许你同时拥有魔宠和联结物品。每日1次，联结物品允许你额外施放一个已知法术。（与法师的联结物品不同，法师的能够施放法师法术书中的任一法术。）


**超魔专擅（****Metamagic Adept, Ex****）**：3级开始，你能使用超魔专长强化法术而无需额外时间。你仍然需要付出高级的法术位。你能够在3级时每天使用此能力1次，之后每4级增加1次。19级时每天5次。在20级时，此能力被“奥术颠峰”所取代。


**新奥术（****New Arcana, Ex****）**：9级时，你能添加一个术士/法师法术列表中的法术到你的已知法术列表。该法术必须是你能够施展的环位。你能够在13级和17级各获得一个额外法术。


**学派力量（****School Power, Ex****）**：15级时，选择一个法术学派，任何你施展的此学派的法术DC+2。此奖励与法术专攻叠加。


**奥术颠峰（****Arcane Apotheosis, Ex****）**：在20级时，你的身体充斥着奥术力量。你能使用任何超魔专长而不需要增加施法时间，尽管你仍然要付出高级法术位。当你使用任何具有充能次数的魔法物品时，你可以消耗法术位来驱动该物品。你每支付3个法术等级的法术位，则可以减少魔法物品的1发充能消耗。








**狂野血统：先贤（****Sage****）******





奥术学者们总是能为魔法找到新的用法。





**关联血脉**：奥秘血统。





**血统奥秘**：和大多数依赖人格之力的术士不同，你使用你的才智学会法术并强化其力量。你使用你的智力取代魅力以决定所有术士职业相关能力，包括额外法数量、最高可施展法术等级、法术的豁免DC。你在奥术知识和法术辨识上得到+2的加值。





**血统力量**：你的天赋攻击是纺锤型的魔法箭矢。


**奥术箭（****Arcane Bolt, Sp****）**：1级时，你可以用一个标准动作对30尺内的一个目标进行远程接触攻击，造成“1d4+1/2术士等级”的力场伤害。此法术的法术等级被视为你术士等级的一半，你能够每天使用此能力次数为“3 +魅力修正”。此能力取代奥术联结。











**天界血统（****Celestial****）【****CRB****】******





你的血统被天界力量祝福，不是来自你的天界祖先就是通过神力的直接干涉。尽管这力量将你导向善良之路，你的命运（和阵营）依然由你自己决定。





**本职技能**：医疗。





| 天界血统奖励法术 |
| --- |
| 3级 | 祝福术（bless） | 13级 | 高等解除魔法（greater dispel magic） |
| 5级 | 抵抗能量（resist energy） | 15级 | 放逐术（banishment） |
| 7级 | 反邪恶法阵（magic circle against evil） | 17级 | 阳炎爆（sunburst） |
| 9级 | 移除诅咒（remove curse） | 19级 | 异界之门（gate） |
| 11级 | 焰击术（flame strike） |  |  |





**奖励专长**：闪避，法术延时，钢铁意志，灵活移动，骑乘战斗，走马掠击，技能专攻（知识：宗教），武器娴熟。
