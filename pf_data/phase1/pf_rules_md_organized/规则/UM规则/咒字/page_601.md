**效果咒字 (Effect Words)******





效果咒字用于确立咒字法术的整体效果。咒字法术能够包含多个效果咒字，并且各自的效果可能会相互阻碍。效果咒字使用以下格式。





**名称 (Name)**: 
这是效果咒字的名称。每个咒字都属于一类咒字的群组，群组名称被标记在括号中。除非另有说明，单个咒字法术无法包含两个来自同一群组的效果咒字。


**学派 (School)**: 
此项列出了效果咒字所述的学派。


**环位 (Level)**: 
此项列出了能够学习该效果咒字，以及该咒字对于该职业来说为几级。请注意单个咒字法术无法包含等级高于它的咒字。


**持续时间 (Duration)**: 
此处标明了效果咒字的持续时间。


**豁免 (Saving Throw)**: 
如果效果允许进行豁免，则会将豁免成功后的效果标注于此。


**法术抗力 (Spell Resistance)**: 
如果效果咒字允许法术抗力影响，那么会标注于此。


**目标限制 (Target Restrictions)**: 
部分效果咒字只能在组合咒字法术时与特定的目标咒字进行联结。如果是这种情况，那么这些特定的目标咒字会被标注于此。


**描述 (Description)**: 
这部分描述了咒字被组合进咒字法术中所能产生的效果。


**增强 (Boost)**: 
如果效果咒字能够被增强超魔咒字强化，那么强化后的效果被注明于此。更多的细节请见超魔咒字的部分。

**强酸 (Acid Words)**





这些咒字会创造强腐蚀性的酸液，灼烧所有接触到它的物体。





**酸性燃烧 (强酸) Acid Burn 
(Acid)**


| 学派 咒法系 (创造) [酸]        环位 德鲁伊 0, 审判者 0, 魔战士         0, 术士/法师 0,         召唤师 0        持续时间 立即        豁免 反射, 通过则减半        法术抗力 否 |
| --- |


带有此效果咒字的咒字法术造成1d3点强酸伤害。如果此咒字法术只有一个目标，则需要一个近战或远程接触攻击且不允许豁免。





**酸蚀箭 (强酸) Corrosive Bolt 
(Acid)**


| 学派 咒法系 (创造) [酸]        环位 魔战士 2, 术士/法师         2        持续时间 1轮/等级 (见下文)        豁免 无        法术抗力 否        目标限制 选择 |
| --- |


带有此效果咒字的咒字法术造成每CL 1d4点强酸伤害 (最多5d4)。在下一轮时目标再次受到此伤害。以带有此效果咒字的咒字法术命中目标需要一次远程接触攻击。





**酸液冲击 (强酸) Acid Wave 
(Acid)**


| 学派 咒法系 (创造) [酸]        环位 魔战士 4, 术士/法师         4        持续时间 1轮/等级 (见下文)        豁免 反射, 通过则减半或部分生效 (见下文)        法术抗力 否 |
| --- |


带有此效果咒字的咒字法术造成每CL 1d6点强酸伤害 (最多10d6)。被此法术伤害的目标若未通过反射豁免则会恶心每CL 
1轮，成功则减少为1轮。





**腐蚀云雾 (强酸) Caustic Cloud 
(Acid)**


| 学派 咒法系 (创造) [酸]        环位 术士/法师 7, 女巫         6        持续时间 1轮/等级        豁免 强韧, 通过则减半        法术抗力 否        目标限制 爆发 |
| --- |


带有此效果咒字的咒字法术创造出一片遮挡视线的绿色剧毒云雾。所有范围内的生物受到每CL 1d6点强酸伤害 (最多20d6) 
且疲乏。在范围内的生物获得一次强韧检定来使伤害减半并免受疲乏效果。呆在法术范围内的生物每轮在此豁免上得到叠加的-2减值，但是离开范围1轮后此减值便会重置。在范围内已经疲乏的生物若不通过强韧检定则会力竭。强风 (strong 
wind)，例如‘造风术 (gust of wind)’所制造的风会立即驱散云雾。





**阵营 (Alignment Words)**





该组咒字专门用于处理阵营，它们基于生物自身的阵营进行侦测、伤害或防护。





**阵营护盾 (阵营) Alignment Shield 
(Alignment)**


| 学派 防护系        环位 牧师 1, 审判者 1, 圣武士         1, 术士/法师         1        持续时间 1分钟/等级 (可解消)        豁免 意志, 通过则无效 (无害)        法术抗力 可 (无害)        目标限制 选择 |
| --- |


施放时选择一个阵营：善良、邪恶、混乱、秩序。目标获得反该阵营保护，在对抗来自该阵营生物的攻击时得到+2AC偏斜加值，以及来自该阵营生物的法术或效果时豁免得到+2抗力加值。用一个直觉动作，目标可结束此效果来对一次来自该阵营的法术或效果重骰豁免，但是必须使用重骰结果。





**阵营打击 (阵营) Alignment Assault 
(Alignment)**


| 学派 塑能系        环位 牧师 5, 审判者 5, 圣武士         4        持续时间 立即, 见下文        豁免 意志, 通过则部分生效        法术抗力 可        目标限制 爆发，锥，线 |
| --- |


施放时选择一个阵营：善良，邪恶，混乱，秩序。所有区域内该阵营的目标受到每两个CL1d8点伤害 (最高8d8)。该阵营的异界生物受到每CL1d6点伤害 (最高15d6)。此外，所有被影响的生物若未通过意志豁免则恍惚 (staggered) 1轮/每CL。





**阵营光环 (阵营) Alignment Aura 
(Alignment)**


| 学派 防护系        环位 牧师 8        持续时间 1轮/等级 (可解消)        豁免 意志, 通过则无效 (无害)        法术抗力 可 (无害)        目标限制 选择 |
| --- |


与阵营护盾效果相同，但是AC和豁免加值提升到+4。此外，目标对该阵营生物施放的法术获得SR 25。最后，目标的碰触对该阵营生物来说极为痛苦，每次成功的近战武器或天生武器攻击伤害加2d6点。





**动物 (Animal Words)**





该组咒字能够用于与野生动物对话，安抚并对他们加以控制。





**自然抚慰 (动物) Nature's Calm 
(Animal)**


| 学派 惑控系 (魅惑) [影响心灵]        环位 德鲁伊 1, 游侠 1, 女巫         1        持续时间 1分钟/等级        豁免 意志, 通过则无效        法术抗力 可        目标限制 选择 |
| --- |


目标变得冷静且被驯服。虽然在持续时间内目标不会进行攻击，但如果目标受到攻击，法术效果自动结束。被此法术影响的生物不会逃跑，但也不是无助状态。此效果咒字仅能影响动物和魔法兽，不过魔法兽在豁免上得到+4无名加值。





**野性引诱 (动物) Wild Lure 
(Animal)**


| 学派 惑控系 (魅惑) [影响心灵]        环位 德鲁伊 2, 游侠 2, 女巫         2        持续时间 1分钟/等级        豁免 意志, 通过则无效        法术抗力 可        目标限制 选择 |
| --- |


目标将施法者看作可信任的盟友。在持续时间内目标生物会保护施法者，并不会攻击施法者的盟友。如果目标被施法者或其盟友攻击，此效果立即结束。带有此效果咒字的咒字法术仅能影响动物和魔法兽，不过魔法兽在豁免上得到+4无名加值。





**自然命令 (动物) Nature's Command

**束缚 (Binding Words)**





该组咒字能够固定物体或者麻痹生物。





**锁闭结界 (束缚) Lock Ward 
(Binding)**


| 学派 防护系        环位 术士/法师 1        持续时间 永久        豁免 意志, 通过则无效 (无害)        法术抗力 可 (无害)        目标限制 选择 |
| --- |


此效果咒字让一个无人持用的物品闭合，比如门、箱子、或者书本。如果物品本身带有锁，那么该物品还会被锁上。如果咒字法术中带有其他效果咒字，所有其他效果咒字的效果都被暂停，直到一个施法者以外的生物打开物品为止。目标成为所有其他效果咒字的目标，如同他们带有选择目标咒字一般。在决定此后续效果的持续时间时，只考虑其他效果咒字。

| 学派 咒法系 (创造)        环位 德鲁伊 3, 魔战士 3, 术士/法师 3, 女巫         3        持续时间 1分钟/等级 (可解消)        豁免 无        法术抗力 否        目标限制 爆发 (发散) |
| --- |


这个效果咒字会使效果影响的区域下起大雪。它会如同‘雾障’一般提供隐蔽，不过它无法被风力所移除。此外，效果影响区域中的地面会在持续时间内被视为困难地形，并且在判断特技以及攀爬技能检定时视为非常滑溜 (very slippery)。


**增强**：效果范围内的每名生物都会在其每轮结束时受到2d6点寒冷伤害。增强该效果咒字会使其提高1个环位。





**掌控风暴 (气象) Storm Master 
(Weather)**


| 学派 变化系        环位 牧师 7, 德鲁伊 7, 术士/法师 7, 女巫         7        持续时间 1小时/等级 (可解消)        豁免 无        法术抗力 否        目标限制 个人 |
| --- |


带有该效果咒字的咒字法术会赋予目标一种能力，使其能够改变围绕她半径1英里范围内的天气。目标能够通过逐一调整天气的等级来增减天气效果的程度，以此改变周遭环境。等级如下所示：严寒，暴风雪，降雪，冻雨，寒风，无风，暖风，暖雨，雷暴，龙卷风，酷热。每次改变都需要10分钟才能完全生效。因此，如果当前天气为暖风，并且施法者希望将其转变为寒风，她需要通过第一次转变将天气变为无风，然后才是寒风。目标无法控制天气的细节，只能确定当前为何种类型的天气 (目标不能做到如使闪电轰击房屋这种事，不过她可以使闪电落在一片区域之中)。


**增强**：每次转变只需要花费5分钟。
