## 魔裔亚种（Tiefling Heritages）
> 来源：炼狱血脉（Blood of Fiends）BoF，页码见原书，未整理 → 炼狱血脉BoF → 种族替换特性
魔裔亚种（Tiefling Heritages）无论他们的炼狱之血来自何处，大多数魔裔都表现出了类似的特征与能力。何种炼狱本质会与凡人的灵魂相结合的方式无法被预测，这使得让普通人仅仅通过外观来识别魔裔的血脉成为近乎不可能的任务。然而有少数魔裔与某种特定类型的炼狱血脉有着更多明显的联系，而这种类型就是赋予你腐化之血的罪魁祸首。玩家可以为了自己的魔裔角色选取后述10种血脉之一来代替标准的魔裔种族特性。每种血脉都提供了新的属性调整、类法术能力以及技能加值，此外还有两个专用背景元素。每一类都描述了相应血脉中最常见（尽管这并非意味着随处都可以见到）的人格特征，体貌特征以及属于特定血脉的魔裔的起源之地。
|  | 阿修罗后裔（咎恶族裔）咎恶族裔没有任何同情心或怜悯之情，并且憎恶一切自身之外的生命形式。他们将强烈的精神压力以及肉体的疼痛加诸于他人，不停地撕裂他人的心理疮疤。祖先：阿修罗（Asura）典型阵营：守序邪恶替换属性调整：+2敏捷，+2感知，-2智力替换技能加值：估价，知识（地方）替换类法术能力：咎恶族裔获得狂笑术（Hideous 
       Laughter）作为类法术能力。    
       与他们的阿修罗祖先一样，对于与咎恶族裔观点相悖的信仰，他们会醉心于神祇与其信众的失败，并乐于看到这些人的教堂与圣地遭到破坏与摧毁。这与生俱来的讥讽欲望以及对敌人信仰的嘲笑，往往超出单纯欺凌的范畴，经常扩展至表现伤人致残之艺以及完全毁灭他们敌人的珍爱之物之上。咎恶族裔盗窃或肆意破坏他人的宝物，并且以往受害者的创口上撒盐为乐。  
         
       咎恶族裔的身体往往同时拥有男性与女性的特质，其双性化证实了毁灭和欺骗并不受限于性别。甚至有相当数量的咎恶族裔天生就是雌雄同体。  
         
       咎恶族裔在乌笃剌（Vudra）最为常见，不过在奥罗登（Aroden）死亡之后，有相当数量的阿修罗踏上了充满破坏性的朝圣之旅，向着那些奥罗登曾经降临并愚弄凡人的地区，或者能够见证到奥罗登陨落的地方。世界之伤（Worldwound）的阿修罗后裔则从摧毁邻国蒙蒂维（Mendev）的狂热十字军（zealous 
       crusaders）中享乐，不过更多的咎恶族裔出生在拉哈多姆（Rahadoum），这里的人们与其一起分享着对神祇的憎恶。背景元素咎恶族裔可以选择以下种族背景元素武器大师（Arms 
       Master）：你祖先具有的传奇战斗武艺使得你获得一定程度的天生武器技能。当你使用不擅长的武器进行攻击检定时，受到-2减值取代正常的-4减值。祷告破坏者（Prayer 
       Breaker）：你有一种天生的资质，能够对那些信徒造成伤害，短时间内切断他们与其信仰神祇的联系。当一名神术施法者由于你造成的伤害而需要进行专注检定，以避免失去法术时，该检定的DC提高2点。 |

|  | 邪魔后裔（残忍族裔）阴沉而又厌世的残忍族裔对死亡、疾病与破败是如此地着迷，以至于他们经常将自己奉献给那些在幕后毁灭生灵的可怖破坏者们。祖先：邪魔（Daemon）典型阵营：中立邪恶替换属性调整：+2敏捷，+2智力，-2感知替换技能加值：解除装置，巧手替换类法术能力：残忍族裔获得死亡丧钟（Death 
       Knell）作为类法术能力。    
       残忍族裔与他们的邪魔祖先一样，着魔于疾病、腐朽以及任何能够使凡人死亡的方式。然而同样作为凡人，他们无奈地意识到他们自己也会受到这些能够取人性命的灾祸影响。为了远离这种让人愤怒的想法，残忍族裔赌上自己的生命去成为他人的灾难，如果没有能够使他们欢愉的灾祸的话，他们会很乐意去创造一个。  
         
       残忍族裔通常看起来虚弱并且不太健康。但是实际上他们并不会比普通人更虚弱，残忍族裔经常表现出各种疾病的症状，比如干咳、发烧或者异常苍白的肤色，无论他们吃多少食物，所有的残忍族裔都看起来病态般地消瘦。  
         
       残忍族裔经常出现在遭受疾病、饥荒、内乱或战争的地区。令人绝望的是，这些土地上的人们为了补充他们的人数并且忘记过去的恐怖遭遇。那些看起来遭受病痛之苦的孩子的父母都会竭尽全力让他们生存下去，而全然不知这些孩子受到邪魔的污染。当这些炼狱之子成长到成年，许多父母都会因他们过去的努力而感到悔恨。背景元素残忍族裔可以选择以下种族背景元素死亡代理人（Death's 
       Deputy）：当你把敌人送入鬼门关时，你通常会一脚将其尸体踢过门槛。你对任何并非由于该背景元素的效果而使生命降至负值的生物进行攻击时，伤害获得+2背景加值。噬魂者（Soul 
       Eater）：谋杀行为使你从那些消散的灵魂中吸取活力。每当你使用致命一击（CDG）动作杀死一个生物（无论是通过伤害杀死还是由于对方没有通过强韧豁免），你都会获得等同于你人物等级一半的暂时生命（最低为1），持续1分钟。这些暂时生命不会通过多次致命一击而叠加。 |

|  | 魔孽后裔（污秽族裔）粗鲁笨拙的污秽族裔特别乐于冒犯或者诽谤上流社会。他们对违反禁忌的喜爱甚于违反法律，尤其当他们的行为能够使无辜者受辱或者遭到排斥时。祖先：魔孽（Demodand）典型阵营：混乱邪恶替换属性调整：+2体质，+2感知，-2智力替换技能加值：威吓，知识（宗教）替换类法术能力：污秽族裔获得熊之坚韧（Bear's 
       Endurance）作为类法术能力。

       野兽之子通常会在孩童时代结束之后长出自身独特的体征，这通常发生在青春期。这些特征通常暗示着一种兽性本质，包括狭长的瞳孔，尖牙或者覆盖皮肤的毛发。与大多数魔裔不同，野兽之子很少会感到被孤立。即使他们野兽般的外貌，也通常光滑整齐，这非但不会引起他人的厌恶，反而能赋予他们野性的魅力。  
         
       野兽之子在乌笃剌（Vudra）最为常见——在这里罗刹是普遍存在的——不过其中有许多人都会尽快离开家园去异乡寻找更好的前景。乌笃剌人的民间传说中有太多故事是关于罗刹放任这些半血子嗣实现他们所追求的奢靡生活，大多数乌笃剌人会在发现野兽之子后将其放逐。而在其他国家，他们仅仅被视为异常之人而非文化中的妖魔鬼怪，野兽之子发现在这些地方更容易获取他们所渴望的财富。背景元素野兽之子可以选择以下种族背景元素弯曲的身体（Bent
