**剪影人（****Wayangs****）******





剪影人是一群有着超自然能力的小体型类人生物，他们的祖先可以追溯到阴影位面。剪影人形容枯槁，有着皮克精那样的身形和深黯的肤色。他们在内心奉行被称为“大溶影（The 
Dissolution）”的观念。这使他们相信在死后可以重新融合到阴影当中。剪影人乐于通过献祭仪式和白色绚丽的几何或者螺旋纹身来表达他们的信仰，胆怯而且避世的他们生活在小小的互助村落中，几乎不与外界接触。








**剪影人种族特性（****Wayang 
Racial Traits****）******





**+2****敏捷，****+2****智力，****-2****感知**：剪影人灵活而又谨慎，但是他们对世界的认知只是一团阴影。





**生物类型**：剪影人属于类人生物，剪影人子类。





**小型体型**：剪影人是小体型生物。他们的AC获得+1体型加值，攻击检定获得+1体型加值，CMB和CMD受到-1减值，并且隐匿检定获得+4体型加值。





**缓慢速度**：剪影人的基本速度为20尺。





**黑暗视觉（****Darkvision****）**：剪影人能够在黑暗中看到60尺远。





**光与暗（****Light 
and Dark, Su****）**：每天1次以一个直觉动作，剪影人能够如同不死生物一样受到正能量伤害并且被负能量治愈。该能力一旦启动则持续1分钟。





**潜伏者（****Lurker****）**：剪影人的察觉和隐匿检定获得+2种族加值。





**暗影魔法（****Shadow 
Magic****）**：剪影人所施放的任何幻术系（幽影幻觉子学派）法术的豁免DC+1。拥有11或更高魅力属性的剪影人获得以下类法术能力：每天1次－‘幻音术’，‘行踪无迹’以及‘腹语术’。施法者等级等同于剪影人的角色等级。这些法术的豁免DC等同于“10+法术环级+魅力修正”。


【法术速查】**幻音术****（****Ghost 
Sound****）**：发出虚幻的声音。


【法术速查】**行踪无迹（****Pass 
without Trace****）**：每等级可以使一个受术者不留下任何足迹。


【法术速查】**腹语术（****Ventriloquism****）**：腹语，持续1分钟/每等级。





**暗影抗力（****Shadow 
Resistance****）**：剪影人在对抗任何幻术学派（幽影幻觉子学派）的法术时，豁免检定获得+2种族加值。





**起始语言**：通用语以及剪影人语（Wayang）。拥有足够智力的剪影人可以选择下列语言作为额外语言：任何人类语言，深渊语，邪灵语，龙语，地精语，炼狱语，娜迦裔语（Nagaji），轮回语（Samsaran）以及天狗语（Tengu）。

**溶****影儿（****Dissolution****’****s 
Child****）**：每天1次，你能够改变你的容貌，就好像4英尺高的一片阴影一般。你的实体依旧存在，你并非成为虚体——只有你的外观变化而已。该能力如同‘隐形术’一般运作，不过只持续每角色等级1轮（最高5轮）。这是一个超自然能力。该特性取代暗影魔法。





**可选天赋职业奖励（****Favored 
Class Options****）******





**吟游诗人**：将法师法术列表中的一个幻术系法术加入到已知法术中。该必须比吟游诗人可以施放的最高环级法术低一环。并且该法术视为比原先高一环，除非它同样也在吟游诗人的法术列表中。





**先知**：将法师幻术系法术列表中的一个法术加入到已知法术中。该必须比先知可以施放的最高环级法术低一环。并且该法术视为比正常高一环，除非它同样也在先知的法术列表中。





**术士**：术士所施放的任何幻术系（幽影幻觉子学派）的法术所造成的伤害+1/2点。





**召唤师**：幻灵技能点+1。

**阴影操偶师（****Shadow 
Puppeteer****，****吟游诗人****变体）******





阴影操偶师借助神奇而又可怕的皮影戏，通过创造并操纵阴影产生超自然效果。





**吟游表演**：阴影操偶师获得下列吟游表演。为了使用这些能力，角色必须能够表演皮影戏。皮影戏使用表演（演剧）技能，并且还需要光源。这些能力取代所有级别的激发勇气以及提振技能。





**影之仆役（****Shadow 
Servant, ****Sp****）**：1级起，阴影操偶师能够创造影之仆役来执行简单的工作。影之仆役与‘隐形仆役（Unseen 
Servant）’类似（施法者等级等同于阴影操偶师的吟游诗人等级），不过它呈现为一团不定型的阴影。影之仆役具有视觉成分。





**皮影戏（****Shadow 
Puppets, ****Sp****）**：1级起，阴影操偶师能够通过吟游表演创造近乎真实的阴影生物，它类似于‘召唤怪物I’法术列表中的怪物。这些阴影生物在其他方面运作如同‘幽影咒法术（Shadow 
Conjuration）’一般，与这些生物有互动的目标需要进行一次DC为“10+1/2吟游诗人等级+魅力修正”的意志豁免，它们对成功豁免的人来说只有20%的真实度。4级以及之后的每3个等级，该能力如同更高1环的‘召唤怪物’法术一般运作（4级时作为‘召唤怪物II’，以此类推）。

***在昏暗的光线中，你看起来比影子更加难以辨认。*********

**专长效果**：当你处于昏暗或黑暗的区域中，你能够以全速潜行，而不会在这么做时隐匿检定受到正常的-5减值。

**影云袋****（****Bag 
of Shadow Clouds****）******


**灵光**：中等幻术系；**施法者等级**：7级；


**位置**：无；**价格**：30240gp；**重量**：1磅。


任何人如果往这个深灰色的布袋里观察，只能看到虚无的黑暗。袋子内存在着与阴影位面相连接跨位面空间。每天3次，以一个移动动作，持用者能够从袋内取出1d4块半固态的暗影碎片。袋子的持用者能够将这些碎片分别作为投掷武器使用，每块能够命中1个5尺方格。当它命中时，它会如同‘黑暗术’一般运作，但是只影响5尺方格。以一个移动动作，袋子的持用者能够将影云向任何方向移动10尺。无论碎片是否被掷出，碎片以及影云会在消散前存在10分钟。


**制造条件**：“制造奇物”；‘黑暗术’，‘幽影咒法术（Shadow 
Conjuration）’。


**制造成本**：15120gp。

**影锚术（****Shadow 
Anchor****）******


| 学派 |  | 幻术系（幽影幻觉）〔阴影〕 |
| --- | --- | --- |
| 环级 |  | 吟游诗人2，术士/法师2，女巫2 |
| 施放时间 |  | 标准动作 |
| 成分 |  | 姿势 |
| 范围 |  | 接触 |
| 效果 |  | 一条模糊的影绳 |
| 目标 |  | 接触到的生物 |
| 持续时间 |  | 1轮/等级（可解消）；见下文 |
| 豁免 |  | 意志，通过则无效 |
| 法术抗力 |  | 可 |


目标的影子化为柔韧的绳索拴在在他当前的方格内。生物能够离开该方格5尺距离而不受到任何惩罚。如果想要移出距离绳子拴住的位置5尺以上距离，目标需要进行一次冲撞战技检定，对抗等同于“10+1/2你的施法者等级+施法关键属性修正”的CMD。目标与影绳拴住方格的距离每超出5尺，就会受到-1减值。检定失败意味着目标的移动被浪费并且无法移动得更远。如果目标在检定中失败10点或者更多的话，他会向着影绳的方向被拉动5尺并且摔倒。而当目标在检定中胜出10点或更多时，法术效果结束。该法术对没有影子或倒影的生物无效。如果目标使用传送效果或者离开当前的位面，法术效果结束。
