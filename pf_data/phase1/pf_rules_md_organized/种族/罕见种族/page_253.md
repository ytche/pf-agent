**替换儿（****Changelings****）******





替换儿是鬼婆和她们的爱人经由疯狂或是法术诞下的后代。在被丢弃到特定的养父母门口后，替换儿会被陌生人抚养长大。她们通常高挑而苗条，有着深幽的发色和迷人的外表，而其他的特征就如同其父亲的种族。替换儿总是女性，她们异色的双瞳和反常的苍白皮肤显示出了她们的真正身份。在青春期，一名替换儿会收到“呼唤”，一种将她们引向发现她们真正起源的旅途的催眠般的心灵之语。拒绝了这种呼唤的替换儿选择了她们自己的命运，而注意到这种呼唤并找到了她们的“母亲”的替换儿或许会通过变为鬼婆而获得更加强大的力量。









**替换儿种族特性（****Changeling 
Racial Traits****）******





**+2****感知，****+2****魅力，****-2****体质**：替换儿身体脆弱，但是聪慧而又动人。





**生物类型**：替换儿属于类人生物，替换儿子类。





**中型体型**：替换儿是中等体型生物，不因体型获得任何加值或者减值。





**标准速度**：替换儿的基本速度为30尺。





**鬼婆种族特性（****Hag 
Racial Trait****）**：替换儿继承了下列种族特性之一，这取决于她母亲属于何种鬼婆。





● **凶拙替换儿（****Hulking 
Changeling****）****（妖鬼婆，****Annis**** 
Hag****）**：替换儿的近战伤害获得+1种族加值。





● **绿寡妇（****Green 
Widow****）****（绿鬼婆，****Green 
Hag****）**：替换儿在使用唬骗检定对抗对她有性趣的生物时获得+2种族加值。





● **海肺（****Sea 
Lungs****）****（海鬼婆，****Sea 
Hag****）**：替换儿在受到溺毙的危险之前，能够屏息的轮数等同于她体质的三倍。





**利爪（****Claws****）**：替换儿的指甲坚硬而又锐利，这使她们获得了2爪抓攻击（每只造成1d4点伤害）。





**天生防御（****Natural 
Armor****）**：替换儿拥有AC天生防御加值+1。





**黑暗视觉（****Darkvision****）**：替换儿拥有60尺黑暗视觉。





**起始语言**：通用语以及替换儿所居住社会的主要语言。拥有足够智力的替换儿可以选择下列语言作为额外语言：邪灵语，龙语，矮人语，精灵语，巨人语，豺狼人语，地精语以及兽人语。

**种族特性替换（****Alternate

**迷雾之子（****Mist 
Child****）**：当替换儿处于隐蔽或者全隐蔽时，对她攻击的失手率提高5%。该特性取代凶拙替换儿。





**尤物（****Object 
of Desire****）**：当替换儿施放‘魅惑人类’以及‘魅惑怪物’时施法者等级+1。该特性取代绿寡妇。





**海洋之女（****Ocean’s Daughter****）**：替换儿的游泳检定获得+1背景加值。并且在以游泳检定避免游泳造成的非致命伤害时自动成功。该特性取代海肺。








**可选天赋职业奖励（****Favored 
Class Options****）******





**先知**：当决定【先知诅咒】能力的效果时，视为先知等级高于实际1/2。





**盗贼**：获得1/6个盗贼天赋。





**女巫**：女巫魔宠习得一个女巫法术列表中的法术。此法术必须比女巫可以获得的最高环级法术低一环。如果女巫更换她的魔宠，新的魔宠依旧了解这个法术。

**织梦者（****Dreamweaver****，女巫变体）******





替换儿织梦者通过她的鬼婆血统来往于梦境之界（dream 
realms），以接触凡人的精神与灵魂——无论善恶。





**本职技能**：织梦者将察言观色加入她的本职技能列表，并从中移除医疗。





**庇护主（****Patron****）**：织梦者的庇护主通常是【征兆（Portents, 
UM）】或【繁星（Stars, 
UM）】。





**法术**：织梦者使用下列法术取代部分庇护主法术。





| 织梦者奖励法术 |
| --- |
| 2级 | 播种思想（sow        thoughts, ARG） | 12级 | 梦之衣（cloak        of dreams, APG） |
| 4级 | 暮光之尘（dust        of twilight, APG） | 14级 | 幻化灵体（ethereal        jaunt） |
| 6级 | 深度睡眠（deep        slumber） | 16级 | 片刻预知（moment        of prescience） |
| 8级 | 修改记忆（modify        memory） | 18级 | 星界投射（astral        projection） |
| 10级 | 托梦术（dream） |  |  |





**织梦（****Dream 
Spinner, Su****）**：2级起，若一名生物由于织梦者施放的【沉眠（Slumber, 
APG）】巫术或法术而进入睡眠，织梦者对其施放〔影响心灵〕的法术DC提高1点。即使成功豁免法术目标也不会醒来，而且还不会有任何抗拒法术的记忆。如果应用得当，织梦者能够将一个〔影响心灵〕的法术（即‘播种思想’、‘暗示术’等等）的要素融入目标的潜意识中，使其相信法术的效果源于他的梦境（详细如何将这些要素恰当地融入梦境由GM决定）。该能力取代2级的女巫巫术。





**窃梦（****Dream 
Thief, Su****）**：6级起，若任何生物由于织梦者施放的【沉眠】巫术或法术而进入睡眠，她可以改变其睡眠意识（sleeping 
mind）。她能够重塑一名目标的记忆，如同使用了‘修改记忆（Modify 
Memory）’一般。此外，她能够将自己植入目标的梦境记忆之中，暗示目标的意识对织梦者展示一些特殊的信息；做梦的人的潜意识会抗拒，或者通过断断续续的记忆蒙骗她，这类似于僵尸能够抗拒使用‘死者交谈’提出的问题一般。成功的意志豁免能够免受上述两类效果（DC等同于女巫巫术）。无论豁免是否成功，同一名生物无法在1天内再次成为该巫术的目标。该能力取代6级的女巫巫术。





**梦之主（****Dream 
Possession, Su****）**：10级起，织梦者可以操纵任何由于自己施放的【沉眠】巫术或法术而进入睡眠的生物。该效果的作用如同‘魔魂壶（magic 
jar）’一般，使用女巫魔宠作为魔魂之壶。成功的意志豁免能够免受该效果影响（DC等同于女巫巫术）。无论豁免是否成功，同一名生物无法在1天内再次成为该巫术的目标。该能力取代10级的女巫巫术。





**推荐巫术**：凶兽（Beast 
of Ill-Omen, UM），魅惑（Charm, 
APG），沉眠（Slumber, 
APG）。


**推荐强力巫术**：噩梦（Nightmares, 
APG），预观（Vision, 
APG）。


**推荐高等巫术**：凶兆（Dire 
Prophecy, UM），永眠（Eternal 
Slumber, 
APG）。

**母亲赠礼（****Mother’s Gift****）******


***你从鬼婆母亲那里继承了特殊的礼物。*********


**先决条件**：替换儿。


**专长效果**：你获得的黑暗馈赠由下列方式体现出来。当你选择该专长时选择其表现形式，一旦选定则无法改变。


**鬼婆之爪（****Hag 
Claws, Ex****）**：爪抓的攻击检定以及伤害检定获得+1加值。


**骇人强韧（****Surprisingly 
Tough, Ex****）**：你的天生防御加值增加1点。


**神秘抗力（****Uncanny 
Resistance, Su****）**：你获得等同于“6+角色等级”的法术抗力。


**特殊说明**：你可以选择该专长至多3次。其效果无法叠加。每次获得专长时，你必须选择不同的表现形式。

**播种思想（****Sow 
Thought****）******


| 学派 |  | 惑控系（胁迫）〔影响心灵〕 |
| --- | --- | --- |
| 环级 |  | 吟游诗人1，术士/法师1，女巫1 |
| 施放时间 |  | 标准动作 |
| 成分 |  | 语言，姿势 |
| 范围 |  | 近距（25尺+5尺/每2等级） |
| 目标 |  | 一个生物 |
| 持续时间 |  | 永久 |
| 豁免 |  | 意志，通过则无效 |
| 法术抗力 |  | 可 |


你在受术者的精神中种植一个主意、观念或猜疑。目标会相信这个想法是属于他自己的，但是不需按照它行动。如果这个想法与目标惯常的思维相悖（比如让一名圣武士思考“我应该杀死我的朋友”），那么目标就有可能怀疑是否有影响心智的魔法在生效。这个想法必须非常明确，使其能够用1、2句话表达出来。使法术成功不需要你与目标有相通的语言，但是如果没有相通的语言，则只能种下最基本最简单的想法。
