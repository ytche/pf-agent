# 切利亚斯 CtIE 替换儿种族选项

<!-- 切利亚斯CtIE-source:切利亚斯，炼狱帝国CtIE.md:pyrophile -->
> 来源：切利亚斯，炼狱帝国（Cheliax, The Infernal Empire），页码见原书，未整理 → 切利亚斯CtIE → 种族替换特性 → 替换儿
由灰烬鬼婆的的邪恶行径诞生的替换儿往往有一个明显的灰色眼睛；或者，它们的皮肤总是干燥甚至几乎完全脱水，并且有慢性银屑病。灰烬鬼婆的女儿可以使用以下特质作为她的种族特质。**　　嗜火者（Pyrophile）**：当使用具有火焰描述符的法术时，替换儿在伤害掷骰上获得＋1种族加值。这个加值在1级之后每4级增加1。
