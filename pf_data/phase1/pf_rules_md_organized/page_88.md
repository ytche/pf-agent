**先知秘示域（****Oracle 
Mystery****）******





**秘示域（****Mystery****）**：每一个先知都拥有属于自己的神力奥秘以为力量和法术之源，这些秘示域也同样会给予他们以额外的本职技能和其他特殊能力。秘示域代表了一个先知所追随的信念以及对于支持类型概念神祇的赞美，或是这些大能赋予一个代行者发自内心的召唤。举例来说，一个拥有波涛秘示域的先知可能是因为她在在风口浪尖之间出生长大、并受到了江河湖海之神的启迪，作为水之平静与狂暴双面的化身在人间行走。这些来源不明的能力将随着先知等级的提升而渐变演化为更多更强的力量，在她的第一个等级先知需要选择一个秘示域，一旦选定即无法更改。在2级，以及之后每提升2个等级时，取决于她的秘示域，先知可以将额外的一个法术加入她的已知法术列表。这些法术计在她已知法术数量之外，在提升等级时，先知无法替换这些法术。

**战斗秘示域（****Battle****）******





**本职技能**：选择了战斗秘示域的先知将以下技能加入他的本职技能列表：威吓，知识（工程），察觉，骑术。





| 战斗秘示域奖励法术 |
| --- |
| 2级 | 人类变巨术（enlarge person） | 12级 | 群体公牛之力（mass bull's strength） |
| 4级 | 云雾术（fog cloud） | 14级 | 控制天气（control weather） |
| 6级 | 魔化防具（magic vestment） | 16级 | 地震术（earthquake） |
| 8级 | 火墙术（wall of fire） | 18级 | 复仇风暴（storm of vengeance） |
| 10级 | 正气如虹（righteous might） |  |  |





**启示**：选择了战斗秘示域的先知可选择下面给出的启示。





**战嚎（****Battlecry, Ex****）**：花费一个标准动作，你能够释放一个充满激励的战嚎。100尺内所有听到战嚎的盟友在攻击检定，技能检定和豁免检定上获得+1士气加值，持续轮数等同于你的魅力加值。10级此加值变成+2。每天你可以使用此能力1次，并在5级以及之后每5级增加1次使用次数。





**战地明晰（****Battlefield Clarity, Ex****）**：每天1次，无论何时当你在豁免检定失败后导致目盲，耳聋，战栗，惊惧，麻痹，恐慌或是震慑状态时，你都可以再投一次豁免，并获得+4加值。你必须接受第二次的结果，即使它更糟。在第7级和第15级，你可以增加1次每天使用数量。





**战斗医师（****Combat Healer, Su****）**：当你使用一个“治疗（Cure）”法术时，你可以用一个迅捷动作来释放它，如同使用“法术瞬发”专长，但要花费两个法术位。这不会提升法术等级。在7级你可以每天使用此能力1次，并在之后的每5级增加1次使用次数。要选择此启示你至少要达到7级。





**钢铁之肤（****Iron Skin, Su****）**：每天1次，你的皮肤像钢铁一样变得更加坚硬，使你获得伤害减免“10/精金”。这项能力作用如同“石肤术”，并使用你的先知等级作为施法者等级。在15级，你可以每天使用此能力2次。要选择此能力你至少要达到11级。





**战技熟稔（****Maneuver Mastery, Ex****）**：选择一种类型的战技。当使用你选择的战技时，将你的先知等级当做你的基本攻击加值计算战技加值。7级你获得精通专长（例如“精通绊摔”）以给你的战术提供加值。11级你获得高级专长（例如“高级绊摔”）给你的战术进一步提供加值。你不需要达到这类专长的先决条件。





**坚韧身躯（****Resiliency, Ex****）**：当你的生命值降为0时你并不会陷入瘫痪，也不会再获得恍惚状态。7级你获得“顽强”作为奖励专长。11级你在陷入瘫痪时进行标准动作不会失去1点生命值。你不需要达到获得顽强专长的先决条件。


【专长速查】**顽强（****Diehard****）**：生命值低于0时保持清醒，伤势自动稳定。****





**军械精通（****Skill at Arms, Ex****）**：你擅长所有军用武器，中型盔甲和重型盔甲。





**惊人突进（****Surprising Charge, Ex****）**：每天1次，你能以一个直觉动作移动你速度的距离。你在7级和15级可以增加1次此能力的使用次数。





**战阵先决（****War Sight, Su****）**：当你骰先攻时，你可以骰两次并采用任何一个结果。7级你总是可以在突袭轮行动，不过若你没有发现伏击，你将最后行动，不管你的先攻值是多少（在之后的回合恢复正常）。11级你可以骰三次先攻并采用任何一个结果。





**武器熟稔（****Weapon Mastery, Ex****）**：选择一种你擅长的武器，你获得此武器的“武器专攻”专长。8级你获得此武器的“精通重击”专长。12级你获得此武器的“高等武器专攻”专长。你不需要达到这些专长的先决条件。


【专长速查】**武器专攻（****Weapon Focus****）**：指定一种武器，攻击检定+1。****


【专长速查】**精通重击（****Improved Critical****）**：选择一种武器，重击威胁范围加倍。****


【专长速查】**高等武器专攻（****Greater Weapon Focus****）**：指定一种武器，攻击检定+1。****





**最终启示**：当达到20级时，你成为了战斗的化身。你能以一个整轮动作进行一次全力攻击，并移动相当于你速度的距离（你可以在攻击之前或之后移动）。当你造成重击时，你可以忽略目标可能拥有的伤害减免。你在AC上获得+4洞察加值以对抗对你造成的重击。当你的生命值低于0时，你不会死亡，除非你的负生命值达到你体质值的两倍。








**骨骸秘示域（****Bones****）******





**本职技能**：选择了骨骸秘示域的先知将以下技能加入他的本职技能列表：唬骗，易容，威吓，隐匿。





| 骨骸秘示域奖励法术 |
| --- |
| 2级 | 惊恐术（cause fear） | 12级 | 死亡法阵（circle of death） |
| 4级 | 虚假生命（false life） | 14级 | 操控死灵（control undead） |
| 6级 | 操控死尸（animate dead） | 16级 | 凋死术（horrid wilting） |
| 8级 | 恐惧术（fear） | 18级 | 女妖之嚎（wail of the banshee） |
| 10级 | 杀生术（slay living） |  |  |





**启示**：选择了骨骸秘示域的先知可选择下面给出的启示。





**骨制铠甲（****Armor of Bones, Su****）**：你可以创造出一件骨制铠甲，为你提供+4盔甲加值。7级以及之后的每4级，该加值再+2。在13级，这件盔甲为你提供伤害减免“5/钝击”。你每天可以使用此铠甲的小时数等于你的先知等级。这些时间不必连续，但每次使用最少消耗1小时。





**流血伤害（****Bleeding Wounds, Su****）**：当你的某个造成负能量伤害的法术或能力（例如“造成轻度伤”或“引导负能量”）对敌人造成伤害时，他会开始出血，每轮受到1点伤害。5级以及之后的每5级，该伤害再加1。这种出血状态可以通过DC15的医疗检定和治疗伤害的效果终止。





**死亡之触（****Death's Touch, Su****）**：你可以通过近战接触攻击对敌人造成可怕的伤害。该攻击会造成“1d6+1/2先知等级”点负能量伤害。如果对不死生物使用，将会治疗他们并提供抵抗驱散+2加值，持续1分钟。你每天可以使用此能力的数量等于“3+魅力修正”。





**临近死亡（****Near Death, Su****）**：你在对抗对疾病，影响心灵的效果和毒药的豁免检定上获得+2洞察加值。7级该加值作用在对即死效果，睡眠效果和震慑的豁免检定上。11级该加值变为+4。





**唤起死亡（****Raise the Dead, Su****）**：以一个标准动作，你可以唤起一个骷髅或僵尸来服侍你。这个不死生物的生命骰等同于你的先知等级。不死生物停留的轮数等于你的魅力修正。7级你可以唤起血腥骷髅（bloody skeleton）和急速僵尸（fast zombie）。15级你可以唤起进化的骷髅或僵尸。你可以每天使用此能力1次并在10级获得1次额外的使用次数。





**抗拒生命（****Resist Life, Su****）**：当你被正负能量影响时，你被当做不死生物。你不受“驱散亡灵”或“命令亡灵”影响，除非你本来就是不死生物。7级你获得+2驱散抗力。该加值在11级和15级再+2。





**灵魂吸取（****Soul Siphon, Su****）**：作为一次远程接触攻击，你可以释放一道射线，使目标获得一个负向等级。这个负向等级持续时间等同于你的魅力修正的分钟数。当该能力使目标获得负向等级时，你恢复等同于你先知等级的生命点数。你每天可使用此能力1次，并在11级及之后的每4个等级再增加1次使用次数。要选择此启示你至少要达到7级。





**灵魂行走（****Spirit Walk, Su****）**：以一个标准动作，你可以变成虚体和隐形状态。当变成这种形态时，你可以向任何方向移动，穿过任何物体(除了那些由力场组成的)。处于这种形态时你除了移动无法做其他动作。你可以保持此状态的轮数等于你的先知等级，但你可以通过一个标准动作提前结束此能力。11级时，你每天可以使用此能一次，15级时可以使用两次。要选择此启示你至少要达到11级。





**不死奴役（****Undead Servitude, Su****）**：你获得“命令亡灵”作为奖励专长。你每天可以引导负能量的次数等于“3+魅力修正”，但只能用于命令不死生物。你能够选择其他专长来增强这项能力，比如“精通导能”。但是不能用专长来改变这项能力，比如“阵营导能”。对抗此专长的DC为“10+1/2先知等级+魅力修正值”。


【专长速查】**命令亡灵（****Command Undead****）**：引导能量可以被用于控制不死生物。





**墓穴之声（****Voice of the Grave, Su****）**：你可以使用“死者交谈”，使用该法术时，此能力持续的时间等同于你的先知等级，这些时间不需要连续。5级以及之后的每5级，尸体在对抗该效果的意志检定上都会承受-2减值。





**最终启示**：当达到20级时，你成为死亡的大师。每轮1次，你能以自由动作使用“出血术（Bleed）”或“稳定伤势（Stabilize）”法术。当你的生命值低于0时，你的伤势自动稳定。你可以随意使用“操纵死尸”法术而不需支付材料成分（虽然你还要受到可控制生物HD上限的限制）。每天1次，你可以使用“真言术：死”，但法术的目标可以是生命值小于150点的生物。

| 6级 | 火球术（fireball） | 16级 | 焚云术（incendiary cloud） |
| 8级 | 火墙术（wall of fire） | 18级 | 火焰之躯（fiery body, APG） |
| 10级 | 五级召唤怪物术（summon monster V，限火元素） |  |  |





**启示**：选择了烈火秘示域的先知可选择下面给出的启示。





**燃烧魔法（****Burning Magic, Su****）**：如果某个目标没有通过你释放的火系魔法的豁免检定并受到火焰伤害，他将着火。在轮到着火的目标开始行动的时候他受到每法术等级1点的火焰伤害。着火状态将持续1d4轮，但可以用一个移动动作结束这一状态，只要该目标通过一个反射检定（使用那个法术的DC）。将目标浸湿水可以使他在豁免检定上获得+2加值，而把他浸入水中则可以直接将火熄灭。不需要通过豁免的法术不会使目标着火。





**余烬之舞（****Cinder Dance, Ex****）**：你的基本速度增加10尺。5级你获得“灵狐步”作为奖励专长。10级你获得“神行步”作为奖励专长。你不需要达到专长的先决条件。有跛足先知诅咒的先知无法选择此启示。


【专长速查】**灵狐步（****Nimble Moves****）**：移动时忽略5尺困难地形。


【专长速查】**神行步（****Acrobatic Steps****）**：移动时忽略20尺困难地形。





**火焰喷吐（****Fire Breath, Su****）**：以一个标准动作，你可以从口中喷出一个15尺锥形火焰。这个火焰会造成1d4每等级的火焰伤害，最大10d4。通过反射检定可使伤害减半。你每天可以使用此能力1次，在5级以及之后的每5级再加1次使用次数。该豁免DC基于魅力。

| 自然秘示域奖励法术 |
| --- |
| 2级 | 魅惑动物（charm animal） | 12级 | 石言术（stone tell） |
| 4级 | 树肤术（barkskin） | 14级 | 漫天虫蚀（creeping doom） |
| 6级 | 植物交谈（speak with plants） | 16级 | 动物型态（animal shapes） |
| 8级 | 树林气息（grove of respite, APG） | 18级 | 世界波（world wave, APG） |
| 10级 | 启蒙术（awaken）       动物异变(Animal Growth) |  |  |





**启示**：选择了自然秘示域的先知可选择下面给出的启示。





**坐骑纽带（****Bonded Mount, Su****）**：你得到了一匹非凡聪顷，强壮，而且忠贞的坐骑。这个生物必须是你可以骑乘并且适合骑乘的。中体型的先知可以选择骆驼或马，而小体型的先知则可以选择矮种马或狼，小体型先知在4级时也可以选择野猪或狗。这匹坐骑的能力如同德鲁伊的动物伙伴，并以你的先知等级作为动物伙伴的有效德鲁伊等级。此坐骑的智力值至少为6。





**侵蚀之触（****Erosion Touch, Su****）**：以一个近战接触攻击，你可以对一个物品或构装体造成每先知等级1d6的伤害。如果此能力被用来攻击由一个由其他人所持有的物品，则将之当做击破武器战技处理。你每天可以使用1次侵蚀之触，每3级再加1次。





**动物之友（****Friend to the Animals, Ex****）**：将所有的“召唤自然盟友”法术加到你的法术列表。要施展这些法术，你仍然需要消耗你的可知法术位选取召唤自然盟友。此外，距离你30尺之内的动物们在所有的豁免掷骰上面得到相当于你魅力修正的加值。





**生命虹吸（****Life Leach, Su****）**：你可以从敌人的身躯之中提取生命之力加到你自己身上。以一个标准动作，你可以对30尺内的一个活物发动“生命虹吸”，这个能力会对目标造成每2先知等级1d6点的伤害，同时使你获得等量的额外生命值，此生命值持续的小时数相当于你的魅力修正。你没办法对一个目标造成超过对方现有生命值加上其体质属性的伤害，因为这样的伤害已经可以杀死对方。目标可以通过一个强韧检定使受到的伤害减半。7级时你每天可以使用1次这个能力，之后每4级再多1次。要选择这个启示，你必须达到7级。





**自然预知（****Natural Divination, Ex****）**：你可以阅读刚宰杀的新鲜动物或是人形生物的内脏，以在单次豁免检定上得到相当于你魅力修正的洞察加值。此外，透过观察与解释鸟类的飞行途径，你可以在单次技能检定上得到+10的表现加值。最后通过检查岩石或泥土上的印痕，或是看着洒入风中沙尘的形状，你可以在单次的先攻检定上得到+4的洞察加值。这些加值必须在24小时之内被使用，同时，你必须在掷骰前宣布你是否要使用这些加值。进行一次自然预知得花费10分钟的时间，你每天可以使用自然预知1次，每获得4个先知等级额外增加1次。





**环境低语（****Nature's Whispers, Ex****）**：你和大自然非常的亲近，让你可以从环境的低语中感受到危险的征兆并保持警觉。从不寻常的蛙叫到隆隆地鸣，一切都指示着你趋吉避凶，将你的魅力取代敏捷加到你的AC和CMD上，任何会导致你失去AC敏捷加值的效果改为让你失去AC上的魅力加值。





**动物交谈（****Speak with Animals, Ex****）**：选择一个具体的动物种类（鹰，狐狸，狗，青蛙之类有的没的），你能够与该种动物进行交谈，如同你在“动物交谈”的法术影响之下。每3个先知等级，你可以额外选择一个种类生物。





**天地精魄（****Spirit of Nature, Su****）**：于自然环境中，当你生命值被降到负值的时候你将自动稳定。5级时当你生命降为负值，你将得到1点的快速医疗，持续1d4轮的时间。10级时这个能力可以在各种场合发挥作用，就算你在城市中或是地下城里。15级当你生命值为负时，你将得到3点快速医疗1d4轮，这个能力取代5级得到的快速医疗1。





**超然连结（****Transcendental Bond, Su****）**：你与万物的契合让你可以和所有的活物分享思绪，你可以透过这个能力和盟友沟通。这个能力如同“心灵连线（Telepathic Bond）”法术，不过你每天可以和你盟友沟通的轮数相当于你的先知等级，而你可以链接的人数则相等于你的魅力修正。要和一个生物建立连结，你必须以一个标准动作接触对方。10级时，每天1次，你可以透过这条联线对一个连结的盟友施展接触法术。





**还原工艺（****Undo Artifice, Sp****）**：11级时，你得到将无生命的工艺品与其组成部件还原成未加工天然材料的能力。这个能力的效果如同“变形万物”，不过它可以作用在魔法和非魔法的无生命对像上。这个能力的持续时间总是永久，不过他没有办法像“变形万物”一样用来模拟其他法术的效果。通过强韧检定的对象将不受影响，魔法物品的价值每增加5000GP其强韧检定将得到+1的增强加值。你每天可以还原物品的次数相当于你的魅力修正。





**最终启示**：20级，你发现了生命本质的奥秘，使你对你的身体得到了他人难以想像的控制能力。每天1次，以一个整轮动作，你可以将自己包覆在一个有机物构成的茧中。当封闭在茧中的时候你被视为无助。8小时之后，你将你的物种转化为植物，动物或人形生物，得到该物种的基本特性。这个变化不会改变你的生命骰数、生命值、豁免加值、技能点数、本职技能或专长。每次型态转变的时候，你将清除身上所有的毒素和疾病，补满生命点数，并恢复所有属性伤害。在每次转化的时候，你必须选择和你当下不同的物种类别。








**岩石秘示域（****Stone****）******





**本职技能**：选择了岩石秘示域的先知将以下技能：估价，攀爬，威吓和生存加入他的本职技能列表。





| 秘示域奖励法术 |
| --- |
| 2级 | 魔石术（magic stone） | 12级 | 石言术（stone tell） |
| 4级 | 召岩术（stone call, APG） | 14级 | 雕像术（statue） |
| 6级 | 融身入石（meld into stone） | 16级 | 驱离金石（repel metal or stone） |
| 8级 | 石墙术（wall of stone） | 18级 | 元素集群（clashing rocks, APG，限土元素） |
| 10级 | 石肤术（stoneskin） |  |  |





**启示**：选择了岩石秘示域的先知可选择下面给出的启示。





**酸性皮肤（****Acid Skin, Ex****）**：你获得5点强酸抗力。在5级该抗力变为10，11级变为20。17级，你免疫强酸。





**击倒攻击（****Clobbering Strike, Ex****）**：当你用攻击法术对敌人造成重击时，你可以立即用一个迅捷动作来对你的敌人进行绊摔。这次绊摔尝试你不会像通常情况那样受到借机攻击。





**水晶视野（****Crystal Sight, Ex****）**：你可以看穿岩石，大地或是沙砾如同他们是透明的水晶。你的凝视可以穿透等同于你先知等级的尺数，或是看穿此数量1/12厚度（即先知等级的英吋数）的金属。你每天可以使用此能力的轮数等同于你的先知等级，但不必连续。





**大地穿行（****Earth Glide, Su****）**：你可以穿过岩石，泥土或大多数的土石类物质，除了加工过的石材和金属，就好像鱼在水中穿行一样容易。如果能够抵抗火焰伤害，你甚至能穿行岩浆。你用你的基本速度穿行。当穿行的时候，你可以如常呼吸（你不需要屏息）。你身后不会留下隧道或深洞，也不会留下任何痕迹或标志。当在你所处的区域使用“移土术（Move Earth）”会把你吹离30尺并震慑1轮，除非你通过DC15的强韧豁免。你每天可以穿行每先知等级1分钟，不必连续但每次至少要花费1分钟。要选择此启示你至少要达到7级。你穿行的时候可以带其他的生物，但每分钟每个生物都会额外消耗1分钟。





**强力石子（****Mighty Pebble, Su****）**：以一个标准动作，你可以用元素之力改造一颗石子（或其他类似大小的石制品），使它能够通过远程攻击命中目标后爆炸。该石子拥有20尺的射程，攻击和伤害具有先知等级1/4的增强加值。任何被石子击中的目标受到每两个先知等级1d6（最少1d6）的伤害。相邻方格的生物受到一半伤害，若通过反射检定则不受伤害。豁免DC为“10+1/2先知等级+魅力修正”。若攻击未命中，将石子作为投掷武器来决定落点。你每天可使用此能力1次，在5级和以后的每5级再加1次。





**石块投掷（****Rock Throwing, Ex****）**：你是一个熟练的掷石者，在投掷石块的攻击检定上获得+1种族加值。你可以投掷最多比你的体型小两个级别的石块。每个石块的射程为20尺，你最多可以投掷5倍射程的距离。投掷石块的伤害为中型2d4，小型2d3，加上1.5倍你的力量修正。





**碎片爆发（****Shard Explosion, Ex****）**：以一个迅捷动作，你能以你为中心爆发出一阵锐利的碎石。这些碎石对10尺之内的所有生物造成每两个先知等级1d6（最少1d6）的伤害。通过反射检定可使伤害减半。豁免DC为“10+1/2先知等级+魅力修正”。此外，碎片使爆炸范围变为困难地形，直到你下一轮行动为止。你每天可以使用此能力1次，在5级和以后的每5级再加1次。





**破金皮肤（****Steelbreaker Skin, Su****）**：以一个标准动作，你可以硬化肉体使攻击你的武器受伤或损毁。当近战或远程武器击中你时，你能以一个自由动作对其进行击破武器检定，即使还没轮到你行动（如果是远程武器，将它的CMD看做“15+攻击者的基本攻击加值”而不是攻击者的CMD）。这不会引起借机攻击。若你击破武器战术成功，你对武器造成如同徒手攻击的正常伤害（而不是瘀伤）。这次攻击造成的伤害能忽略等同于你先知等级的硬度。这项能力不能保护你免于伤害，除非你将该武器完全摧毁。你每天可以使用此能力1次，持续时间为每先知等级1分钟。要选择此启示你至少要达到7级。





**稳如磐石（****Stone Stability, Ex****）**：当你站在地面时，你在对抗冲撞和绊摔的CMD获得+4加值。5级时你获得“精通绊摔”作为奖励专长。10级时你获得“高等绊摔”作为奖励专长。你不需要达到专长的先决条件。


【专长速查】**精通绊摔（****Improved Trip****）**：绊摔战技+2，不会引发借机攻击。


【专长速查】**高等绊摔（****Greater Trip****）**：绊摔战技+2，被你摔倒的敌人引起借机攻击。





**强酸之触（****Touch of Acid, Su****）**：以一个标准动作，你可以通过一个近战接触攻击造成每两个先知等级1d6的强酸伤害。你每天可以使用此能力的次数为“3+魅力修正”。11级你所持有的任何武器能增加1d6点强酸伤害，如同酸蚀武器一般起作用。





**最终启示**：当达到20级时，你成为强酸与泥土的大师。你可以将以下任何一个专长应用于你的酸和土系法术，而不需要提高法术等级：法术增远，法术强效，法术默发或法术定发。








**波涛秘示域（****Waves****）******





**本职技能**：选择了波涛秘示域的先知将以下技能加入他的本职技能列表：特技，脱逃，知识（自然），游泳。





| 波涛秘示域奖励法术 |
| --- |
| 2级 | 海洋之触（touch of the sea, APG） | 12级 | 液体形态（fluid form, APG） |
| 4级 | 水流术（slipstream, APG） | 14级 | 漩涡之流（vortex, APG） |
| 6级 | 水中呼吸（water breathing） | 16级 | 水幕天华（seamantle, APG） |
| 8级 | 冰墙术（wall of ice） | 18级 | 津波（tsunami, APG） |
| 10级 | 间歇泉（geyser, APG） |  |  |





**启示**：选择了波涛秘示域的先知可选择下面给出的启示。





**暴风雪（****Blizzard, Su****）**：以一个标准动作，你可以制造一场暴风雪。你可以制造10尺立方每先知等级的风暴。这些立方可以组合成你希望的任何形状，但每一块都必须与另一块相连并且至少有一块与你相连。在这个风暴中的生物会受到1d4每等级的寒冷伤害。通过反射检定可使伤害减半，豁免DC为“10+1/2先知等级+魅力修正”。风暴持续的时间等于你的魅力修正。在风暴的范围内地面处于结冰状态。在风暴中5尺之外物体完全不可见，这提供了全隐蔽。5尺之内的物体处于隐蔽状态。你每天可以使用此能力1次。要选择此启示你至少要达到11级。





**流体特性（****Fluid Nature, Ex****）**：你在对抗卸除武器，擒抱和闯越的CMD获得+4加值。当敌人对你进行重击确认时，他在确认检定上承受-4减值。5级你获得“闪避”作为奖励专长。你不需要达到专长的先决条件。


【专长速查】**闪避（****Dodge****）**：闪避AC+1。





**流体行动（****Fluid Travel, Su****）**：你可以在液体上行走，就好像它们是固体一样。在液体上行走不会使你受伤；你可以在酸液甚至熔岩上行走，虽然你还是会因为太靠近熔岩而受到火焰伤害。你可以用你正常的地面速度在这些表面上移动。在7级，当此能力作用时，你也可以选择潜下水，并获得60尺游泳速度以及“水中呼吸”能力。你每天可以使用此能力每先知等级1小时，这些时间不必连续，但每次使用至少要花费1个小时。





**冻寒咒语（****Freezing Spells, Su****）**：如果某个目标没有通过你释放的魔法的豁免检定并受到冻寒伤害，他将恍惚1轮。不允许豁免的法术不会造成恍惚效果。11级持续时间变为1d4轮。





**寒冰铠甲（****Ice Armor, Su****）**：你可以创造出一件寒冰铠甲，为你提供+4盔甲加值。7级以及之后的每4级该加值再+2。13级这件盔甲为你提供伤害减免“5/穿刺”。在寒冷的环境中，盔甲加值（以及伤害减免加值）增加2点；在十分炎热的环境将会减少2点。你每天可以使用此铠甲的小时数等于你的先知等级。这些时间不必连续，但每次使用最少消耗1小时。





**冰冷皮肤（****Icy Skin, Ex****）**：你获得5点寒冷抗力。5级该抗力变为10，11级变为20。17级，你免疫寒冷。





**惩罚变形（****Punitive Transformation, Su****）**：你可以将你的敌人变成无害的动物如同使用“恶意变形术”。目标必须通过强韧和意志豁免，豁免DC为“10+1/2先知等级+魅力修正”。这种变形效果持续每先知等级1轮。变形另一个目标会让先前被变形的人立即恢复原状。你每天可使用此能力的次数等于你的魅力修正。要选择此启示你至少要达到7级。





**流水形态（****Water Form, Su****）**：以一个标准动作，你可以变成小型水元素，如同“元素形态I”；9级你可以变成中型水元素，如同“元素形态II”；11级你可以变成大型水元素，如同“元素形态III”；13级你可以变成超大型水元素，如同“元素形态IV”。你每天可以使用此能力1次，持续时间为每先知等级1小时。要选择此启示你至少要达到7级。





**流水视野（****Water Sight, Su****）**：你可以看透云雾而不承受减值，如同你在正常环境下视物。在7级，你可以在任何直径超过1尺的平静水面进行探知，如同使用“探知术”。15级它将如同“高等探知术”般作用。你每天可使用探知的轮数等于你的先知等级，但不必连续。





**寒冬之触（****Wintry Touch, Su****）**：以一个标准动作，你可以通过一次近战接触攻击，造成1d6+1/2先知等级的寒冷伤害。你每天可以使用此能力的次数为“3+你的魅力修正”。11级你所持有的任何武器将会成为冻寒武器。





**最终启示**：当达到20级时，你成为冰与水的大师。你可以将以下任何一个专长应用于你的冰或水系法术而不需要提高法术等级：法术增远，法术强效，法术默发，法术定发。

奖励法术：石拳术APG（2级），滑翔术APG（4级），充能之拳UM（6级），灵界拳OA（8级），异界探知（10级），通晓传奇（12级），灵视（14级），神威如狱UC（16级），钢筋铁骨（18级）
启示：拥有修持秘示域的先知可以选择以下启示。

  辟榖食气 Absence of Body 
  (Su)：你只需要你所属种族原本需求量一半程度的饮食就可以生存。除此之外，当你屏息时，你可以保持屏息的时间额外增加相当于你的先知等级的轮数。在15级时，你无需饮食就能生存，并且你可以屏息的时间提升到原本的10倍长度（每点体质值可以让你屏息2分钟，外加每先知等级1分钟的额外时间）。

  神足通 Absence of 
  Form（Su）：你可以以类法术能力的形式使用法术羽落术，每天可以持续的轮数相当于你的先知等级。这些轮数无需连续生效。如果你在坠落的羽落术生效期间用完了这个能力的持续时间，那么你会如常的从已经羽落的高度掉下去并承受坠落伤害。在10级时，你还可以消耗本能力的每日使用轮数来获得法术凌空而行的效果。

  圣体护持 Ascetic 
  Armor（Su）：你通过静修凝神而掌握了将外物从你的身体上弹开的密法。若你未穿着护甲也未处于中载或重载负重，那么这密法便能让你在防御等级上获得+4护甲加值。在7级和之后每提升4个等级时，这个护甲加值再额外+2。在13级时，你还会获得DR 
  5/徒手击打或天生武器。你每天可以享受本启示好处的时间相当于你的先知等级数个小时。这些时间无需连续使用，但每次使用至少需要持续1小时。

  渡来步 
  Fleet（Su）：你的基础陆地移动速度获得+10尺增强加值。如果你穿着护甲或是处于中载或重载负重，那么你无法获得这些额外速度。在7级以及之后每提升6个等级时，这个速度加值再增加10尺。如果你的先知诅咒为跛足，那么你不能选择本启示。

  护法金刚 Martial 
  Disciple（Su）：密法验修和训练使你掌握了强悍的徒手武术。你获得精通徒手击打作为奖励专长，即使你并未满足获取本专长的先决条件。你的徒手击打伤害骰与相当于你的先知等级的武僧徒手击打伤害骰相同。如果你已经拥有了武僧等级，那么你可以将这两个职业等级合计来计算徒手击打伤害。

  忿怒法 Oracular 
  Spellstrike（Su）：结合神术与徒手击打武技的精要，你可以通过自己的拳脚快速传导法术攻击。这个启示与魔战士的法术打击能力相同，但你只能使用徒手击打攻击来传递法术，无论你是否拥有其他能力都是如此。除此之外，你使用牧师法术列表中的法术而不是魔战士法术列表中的法术来使用法术打击。你必须达到7级才能选择本启示。

  洁净通 Rapid 
  Convalescence（Sp）：在尝试从中毒或疾病状态恢复时，你需要连续成功通过的豁免检定减少一次（最少需要一次）。除此之外，你可以消耗一个你尚未使用的本日法术位来在下一次对抗毒素或疾病效果的豁免检定上获得相当于消耗法术环数的增强加值，这个效果只有在法术消耗后相当于1分钟/消耗的法术环数时间内会生效。

  伽蓝镜 Spell 
  Deflection（Su）：通过一个准备动作，你可以反制任何对你或一个邻接你的盟友施放的，需要一次远程接触攻击命中的法术（如射线法术）。为了反制该法术，你需要进行一次成功的徒手击打攻击检定，如果这次攻击检定的结果高于20+这个法术的施法者等级，那么这个法术无效。在17级时，如果你使用这个启示来反制法术，那么它还会被反弹回它的施法者，使用和原本相同的远程接触攻击检定结果进行攻击。你必须达到11级才能选择本启示。
