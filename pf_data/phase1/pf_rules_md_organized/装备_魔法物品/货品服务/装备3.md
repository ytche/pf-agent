**密文杖 Code 
Rod**
**价格：**1SP **重量** 1  磅

    
从表面上看，这个装置只不过是一个普通的短杖，看上去像是燕尾榫，尽管它可以做成任何圆柱形物体，比如手杖或手杖、窗帘杆、卷轴匣、风铃或吹箭。最简单的密文杖成本为1 
sp，重量为1磅。如果这根在作为密文杖之外另有用途，而不是作为一个代码杆，它使用二者间较高的价格和重量。两根周长相匹配的密文杖必须成对使用才能正常生效。第二个密文杖可以是一个形似第一根短杖的物品，或者它可以简单地做成相同的尺寸。使用密文杖时，要将一条狭长的纸条以螺旋状缠绕在密文杖上，每次缠绕时，纸条边缘都要接触到前一个密文，形成一个连续的表面。信息写完后，纸条被解开，信息便无法辨认。然后，纸条可以卷起来发送给收件人，收件人将纸条缠绕在另一根杆上，就可以读取信息了。用户可以用普通语言书写，也可以对信息进行进一步编码。截获信息的人如果识别出使用了密文杖，就可以尝试找到另一根周长相似的杆，利用语言学破解密文杖的信息。

**边栏：诡道工具Tools of 
Intrigur**
  
仅有高超的技能是不够的，还需要有合适的工具！以下列出的所有物品都适合间谍和破坏者使用。其中一些出现在* Pathfinder RPG Core 
Rulebook* 中，但所有物品都可以在*Pathfinder RPG Ultimate 
Equipment*中找到。
    **伪装： 
**如果你想混入人群，就需要一套易容工具箱和合适的服装。伪装盔甲可以让奥术施法者和其他轻甲角色混入士兵中，而不影响他们的能力。双面斗篷、快脱衣服或假发可以方便快速更换伪装。再配上窃贼服装、藏物围巾或暗格箱，可以隐藏你的非法工具或赃物。
  
  **伪造：** 用字母书或伪造文书工具包制作更好的伪造文件。
    
**渗透：** 
无数的魔法物品都有帮助渗透的能力。许多魔法物品通过提供数值加成（如*隐匿灵药*）或额外选项（如*次级岩石披风*）来提高你的技能。还有一些可以复制有用的法术，包括伪装帽和隐形戒指等经典魔法物品。能让你在别人无法到达的地方旅行的物品，如浮空靴或蜘蛛攀爬拖鞋，总是非常有用的。次元空间可以用来偷偷携带工具或掠夺物品。
  
  
**侦察：**一些工具能让侦察工作变得更容易。笔和纸、粉笔和石板，或者手写笔和蜡板都可以用来做笔记、绘制地图或草图。窃听器可以让你更方便地窃听，镜子或潜望镜可以让你在隐蔽时观察事件，或在角落里偷看守卫。**
  
  
 偷窃：**除了无处不在的小偷工具外，其他绕过门锁的工具从精巧（镂空钥匙或蜡钥匙坯）到粗暴（酸瓶或绳锯）不等。玻璃刀或胶纸在闯入有窗户的建筑物时非常有用。炼金油脂和攀爬工具都能提高你进入困难地方的能力。
