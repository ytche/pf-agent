**炼金清洁剂（Alchemical Cleaner）**
> 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 物品
**价格：**300GP；**重量**：1磅
**类别**：炼金工具
**描述**：这种腐蚀性的炼金溶液可以溶解血液、毛发和小块的肉屑。将其撒布在一个5尺方格上需要一个整轮动作，并使察觉检定寻找此类材料的DC提高20。（在察觉检定中寻找此类材料失败且差值在5或以内的生物会意识到该区域被不自然地清理干净了。）这仅适用于原本的察觉DC，而不适用于由灭迹者ACG或无痕执行官UI等变体所替代的检定。一瓶炼金清洁剂的液体足够覆盖九个5尺方格。一瓶炼金清洁剂可以作为溅射武器投掷，投掷时的功能与强碱瓶APG相同。制造炼金清洁剂需要一次DC
25的工艺（炼金）检定。
**制造条件**：工艺（炼金）DC 25

> 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 物品
**价格**：1,000GP；**运费（每英里）**：―
**类别**：交通工具，陆地
**描述**：商队主人的货车在大多数方面与高质量的重型走私货车（见下文）类似，但额外允许在车内隐藏一个便携洞（价格未包含在上文）。便携洞安放在车厢底板的表面，上面再铺设第二层木板，并用螺母和螺栓固定，看起来就像是货车的正常一部分。因此，便携洞就像一片夹在两片面包之间的薄肉一样夹在两层木板之间。知晓便携洞存在的人可以将非法货物装入其中，然后将第二层地板固定到位，并在上面装载正常货物。货车的重量不会超过应有重量。此设计允许运输活体货物（必要时将其保持安静或昏迷），因为覆盖便携洞开口的木板之间的间距恰好足够让空气流通，如果走私者将便携洞保持开启并固定的话。除非有人知道要寻找什么，否则需要一次成功的DC
30的察觉检定才能发现隐藏的第二层结构。

**加料猜杯游戏杯组（Loaded Shell Game Cups）**
> 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 物品
**价格**：10GP；**重量**：1磅
**类别**：冒险装备
**描述**：这套包含三个杯子和配套小球的套具专为在流行的猜杯游戏中作弊而设计。在游戏中，庄家会将三个一模一样的杯子口朝下放置，并向顾客（或受害者）展示一个小球。庄家随后将小球放在桌上，用一个杯子盖住它，然后快速来回地洗动三个杯子，期望受害者无法跟上，从而无法准确选择藏有小球的杯子。
使用这套杯具时，每个杯子底部隐藏的小杠杆可以来回翻动杯内的额外夹层。当夹层打开时，小球可见；当夹层关闭时，杯子会将小球收进其中并将其隐藏不见。庄家可以控制哪个杯子"显示"小球，同时让另外两个杯子将小球藏在各自的杯中。为此，庄家进行一次有+5加值的巧手检定与受害者的察觉检定对抗，才能在不被察觉的情况下激活杠杆。

<!-- VC-source:物品10.md:劣质物品 -->
**劣质物品（Shoddy Item）**
> 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 物品
**价格**：不定；**重量**：不定
**类别**：冒险装备
**描述**：劣质物品是任何被巧妙但粗劣地制造的普通装备，其材料和做工都比预期差，但缺陷被隐藏起来。材料层比正常情况更薄，插销和铰链仅松散连接，金属混合不当，导致合金更软，诸如此类。劣质物品以与其制作精良的同类相同的价格出售。制造劣质物品需要制造劣质物品专长（见上文），以成功隐藏粗劣的工艺。劣质物品总不会是精制品，也不使用特殊材料（尽管它们可能看起来是由特殊材料制成的），一次性使用的物品不能做成劣质物品。
任何劣质物品的硬度降低2，其生命值减半。任何以劣质方式制造的武器或护甲在每次使用时都会受到伤害；武器在攻击中会受到等同于其造成的伤害（减去其较低的硬度值）的伤害，护甲则会受到等同于佩戴者因敌人成功攻击所失去生命值的伤害（同样是在考虑调整后的硬度之后）。除武器和护甲以外的物品，使用的每天有10%的几率获得破损状态，并且如果它们的使用次数有限，则其可用次数减半。在任一情况下，获得破损状态的劣质物品无法移除此状态（即使使用魔法，或之后恢复生命值也不行），除非再次成功进行工艺检定并花费金币修复最初的缺陷。被摧毁的劣质物品无法通过任何方式修复，仅能回收部分原材料。劣质物品的价格通常与其同类正常物品相同。
角色在一次DC
15的估价（或合适的工艺）检定中成功时可以发现物品的劣质状况，但必须专门检查该物品才能做到这一点。

<!-- VC-source:物品10.md:滑索钩 -->
**滑索钩（Zip-Line Hook）**
> 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 物品
**价格**： 55GP（精制品）、 5GP（普通）；**重量**：1磅（精制品）、1磅（普通）
**描述**：这种钝铁钩通过坚固的带子固定在使用者的前臂上。当该物品挂在一根绳索或其他类似物体上，且该物体以向下的角度固定时，持有者可以用它以移动动作用30尺的速度沿绳索下降，而不是以正常速度攀爬，但使用者每轮必须至少花费一个移动动作这样做，否则会坠落。以这种方式使用滑索钩时，在90°（垂直向下）的坡度上需要一次DC
5的攀爬检定，每偏离该基准15度，DC增加5，最大为在15°或165°坡度时的DC
30。在没有坡度或在向上倾斜的绳索上无法使用滑索钩。
滑索钩是为双手使用而设计的。角色可以单手使用滑索钩，但这样会在攀爬检定上承受C8罚值。通过滑索移动在施法时视为剧烈动作。如果滑索或绳索在使用中断裂，使用滑索的角色会坠落。
滑索钩可以由布料、皮革或任何可弯曲的钩状物体临时制作。每当角色使用移动动作用临时滑索钩移动时，该钩会因摩擦而承受1d6点伤害。精制品滑索钩在用来沿绳索下降时给予攀爬检定+2环境加值。
