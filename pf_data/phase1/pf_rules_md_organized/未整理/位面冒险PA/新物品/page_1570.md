**魔法物品（Magic Items）**
下列魔法物品由极限装备（Pathfinder 
RPG Ultimate 
Equipment）概述中的类别划分，所以你可以以那本书中详述的随机生成来使用这些魔法物品。如果你在进行一场位面冒险的话，可以考虑在宝藏生成器中随机投骰前就使用本书中的物品，也可以将这些物品放入宝藏生成器。

**护甲特殊能力（Armor Special 
Abilities）**
这些护甲特殊能力可以有助于保护那些即将探索伟大彼岸（the Great 
Beyond）者。关于魔法护甲规则详见核心规则书（Pathfinder RPG Core 
Rulebook）第461页的护甲部分。

**表格1-3：护甲特殊能力（Armor Special 
Abilities）**


| +1护甲特殊能力（+1 Armor Special Ability） | 基础价格（Base Price）注1 |
| --- | --- |
| 气缓（Billowing） | +1加值 |
| 结茧（Cocooning） | +1加值 |
| +3护甲特殊能力（+3 Armor Special Ability） | 基础价格（Base Price）注1 |
| 共旅（Cotraveling）注2 | +3加值 |
| 混影（Shadow blending） | +3加值 |

注1：折算成该护甲的增强加值后来确定总价格。
注2：这种特殊能力也可应用于盾牌。

**【PFS】气缓（Billowing）**
**灵光**：昏暗咒法系；**施法者等级**：3级
**栏位**：无；**价格**：+1加值；**重量**：-磅
**描述**：
气缓护甲持续性的在穿戴者周围创造气元素缓冲。穿戴者免疫来自束缚的额外伤害以及来自掩埋的伤害，尽管其窒息不会受到护甲的保护。当穿戴者跌落超过20尺时，他可以以一个直觉动作尝试一次DC 
15的飞行检定，使他的跌落伤害减半。
**制造条件**：制造魔法武器和防具（Craft Wondrous 
Item），缓冲护垫（cushioning bands），羽落术（feather fall）；
**制造成本**：+1加值

**【PFS】结茧（Cocooning）**
**灵光**：中等变化系；**施法者等级**：9级
**栏位**：无；**价格**：+1加值；**重量**：-磅
**描述**：
结茧护甲可在穿戴者毫无防备时从位面险境（planar 
hazards）中保护她，并把她裹在一层薄薄的保护膜中。如果穿戴者在她原生位面以外的一个位面突然失去意识（unconscious）的话，该护甲赋予她免疫那个位面的有害环境效果，包括毒性（toxicity）、极端温度（extreme 
temperatures）、负能量（negative energy）、以及空气不足（lack of 
air）。只要她保持失去意识（unconscious）这种免疫力就会持续。
**制造条件**：制造魔法武器和防具（Craft Wondrous 
Item），位面适应（planar adaptation）；
**制造成本**：+1加值

**【PFS】共旅（Cotraveling）**
**灵光**：强烈咒法系；**施法者等级**：14级
**栏位**：无；价格：+3加值；**重量**：-磅
**描述**：
共旅护甲饰有五臂螺旋形的刺绣图案。当护甲被穿戴时，其穿戴者可以接触一名自愿生物并将该生物调谐至五臂之一；一旦其一臂被调谐后，它会发出好似是星光的微光。每日1次，当穿戴者被一道法术或效果送到另一个位面时，以一个自由动作（即便它不是该穿戴者的行动轮），他可以激活该护甲并允许所有与之调谐的生物伴随他，只要被调谐生物在其30英尺以内。如果一名已调谐生物愿意的话，它可以随着该角色旅行，与该角色抵达目的位面，并与穿戴者保持着穿戴者使用该能力时一致的相对距离（或根据新位面的基本特征，尽可能靠近它）。即使不是所有已调谐的角色都愿意或能够陪同旅行者前往新的目的地，然而一旦使用后，螺旋的五臂会全部停止工作， 
并且其穿戴者将新生物调谐到螺旋之前，必须等待24小时。
**制造条件**：制造魔法武器和防具（Craft Wondrous 
Item），异界传送（plane shift）；
**制造成本**：+3加值

**【PFS】混影（Shadow 
Blending）**
**灵光**：中等幻术系；**施法者等级**：11级
**栏位**：无；**价格**：+2加值；**重量**：-磅
**描述**：
混影护甲是豪无光彩的，而且可以削弱其穿戴者服装的任何颜色至暗灰色。攻击昏暗（dim 
light）中的穿戴者，拥有40%的失手率而非正常的20%。此能力不会授予全隐蔽（total 
concealment）；它仅可增加失手率。如果该护甲还拥有暗影（shadow）、强化暗影（improved shadow）、或高等暗影（greater 
shadow）护甲特殊能力的话，该失手率增加至50%。
**制造条件**：制造魔法武器和防具（Craft Wondrous 
Item），行影术（shadow walk）；
**制造成本**：+3加值
