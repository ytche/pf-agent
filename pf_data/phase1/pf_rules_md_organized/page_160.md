**猫族（****Catfolk****，又译猫人）******





猫族是永不言退的天生探险家，不过这种不知疲倦可不仅限于追求大地彼端的地平线。很多猫族视探险为个人成长的有效途径。虽然猫族大多灵巧、机敏，是地上最具活力的生物；部分猫族还是有着静修和精研的强烈倾向。这些个体喜欢寻找老问题的新解法，并质疑哪怕是最为根深蒂固的价值观。她们天性好奇、而猫族文化绝不会打压求知欲，反而还加以培养和鼓励。很多猫族被其他种族看作开朗的怪人，但稍稍有些脱线、怪奇和蛮勇在猫族部族内部从来都不丢人。猫族之民最大的愉悦和追求是站在舞台中央大放异彩；但她们也决不会放弃守护家园——无论是自己出生的部族，还是与自己结下深厚羁绊的友邦。猫族对家人和朋友慷慨而又忠贞。





**体貌描述**：整体而言，猫族轻盈柔软、苗条修长，身高在矮人和人类之间。尽管人类特征明显，猫族身上还是有很多猫科动物的痕迹，包括包裹皮肤的软毛、细长的瞳孔、以及光滑圆润的尾巴。她们有着尖耳朵，但和精灵们不同、更圆更像猫咪。她们操作物件时和其他类人种族一样灵巧，但她们的手指前端小而尖锐，附有伸缩自如的爪子。这些爪子理论上没有强健到能够作为武器的地步，但这个种族的一些成员——天赋异禀或是后天研磨——可以用它们造成致命的效果。猫须很常见但并不普遍存在，而她们的毛色和眼睛的颜色也多姿多彩。





**社会**：尽管自我表现是猫族文化中极为重要的一环，这一点常常会因强烈的集体感而有所收敛。野外的猫族是以捕猎采集为生的部落之民。对个人权力的追逐从来不会被置于部族的平安喜乐之前。不在少数的种族低估了温和的猫族，太晚才意识到凝聚力可以让她们变得多强。


猫族愿意被最有才具的成员所领导，通常是由族长们组成的长老会；而作为长辈的族长则通过协商或选举来选出。在危急关头，长老会将从族长之中推举一位大族长领导整个部族。大族长是部族中最有能耐的成员，并常拥有魔法天赋。居住在城市或文明地域的猫族仍然会组成类似的部族结构，但经常将部族之外、甚至是其他种族的朋友也当成自己部族的一份子。在冒险团队中，认为自己并不适合担任领袖的猫人，经常会服从于她认为按照部族文化最接近大族长的同伴。





**关系**：好奇而适应力强，猫族几乎能够和每个善意的种族互惠。她们很容易和半身人、人类、尤其是精灵打成一片。猫族和精灵都有着富于激情的天性，并且都爱好音乐、舞蹈、讲述故事；精灵社群经常亲切指导猫族部族，而这些精灵们也小心翼翼地避免对猫族朋友们流露出居高临下的态度。侏儒们是猫族的天生伙伴，而猫族也欣赏侏儒的古灵精怪和勤奋品质。只要狗头人不犯疆界，猫族对这些爬虫生物也保持宽容。兽人的狂野天性激起了猫族的强烈困惑和反感，她们不能够理解兽人的野蛮和自我毁灭的倾向。另一方面，半兽人却激起了猫族的兴趣，尤其是那些拚命克服野蛮亲族可憎天性的半兽人。猫族经常将地精和鼠族视作害人精，唾弃他们大量繁衍和为害一方的倾向。





**阵营和宗教**：集体意识和无私合作是猫族文化的核心，天性善良而又好奇的她们愿意接受很多种族的习俗，多数猫族是善良阵营的。由于感知不是她们的长项，大多数猫族同时也是混乱阵营的；尽管如此，也有不少例外存在。





**冒险**：天生的追踪才能、捕猎采集的部族生活方式促使不少猫族投身于游侠和德鲁伊之道，但这些角色并不一定符合爱好歌唱、舞蹈和故事讲述等艺术的猫族脾胃。猫族传说也讲述了不少伟大的英雄术士流下的传统。克制住漫游癖的猫族常成为法师和武僧，其中不少武僧选择了灵动卫士（见下文）之道。尽管猫族骑士和审判者很少见（为某个理由建立毫不动摇的信仰不太像猫族的思维方式），选择这些道路的猫族从未被轻视过。猫族明白勇于探索历练、保持自知之明才能让路走得长远，因此对几乎所有的生活方式都来者不拒。





**常用男名**：卡路思（Carruth），德雷温（Drewan），菲路思（Ferus），格兰（Gerran），喵可坦（Nyktan），洛卡（Rouqar），崔瑟贝（Zithembe）。





**常用女名**：阿雅拉（Alyara），杜丽涅（Duline），霍雅（Hoya），姬娅娜（Jilyana），蜜拉（Milah），米妮丽（Miniri），斯斐莉莉（Siphelele），提耶莉（Tiyeri）。









**猫族种族特性（****Catfolk**** 
Racial Traits****）******





**+2****敏捷，****+2****魅力，****-2****感知**：猫族随和而又敏捷，但是经常缺乏常识。





**生物类型**：猫族属于类人生物，猫族子类。





**中型体型**：猫族是中等体型生物，不因体型获得任何加值或者减值。





**标准速度**：猫族的基本速度为30尺。





**昏暗视觉（****Low-Light 
Vision****）**：猫族在昏暗中可以看人类的两倍远。





**猫之幸运（****Cat's 
Luck, Ex****）**：每日1次，当猫族骰反射豁免时，他可以骰两次豁免并且取高。他必须在投骰之前决定是否使用此能力。





**狩猎本能（****Natural 
Hunter****）**：猫族在察觉、隐匿、生存上获得+2种族加值。





**短跑健将（****Sprinter****）**：猫族在进行冲锋、奔跑、撤退动作时获得10尺种族加值。





**初始语言**：猫族的初始语言为通用语和猫族语。具有较高智力的猫族从以下语言中选择：精灵语，豺狼人语，侏儒语，地精语，半身人语，兽人语和木族语。

**猫爪（****Cat's 
Claws****）**：一些猫族的爪子比他们其他族类更加强壮发达，他们可以将其当做武器来进行攻击。这一对爪子是主要武器，并且能造成1d4点伤害。这一种族特性取代狩猎本能。【编注：主要天生武器采用完整基本攻击加值进行攻击，伤害加值为力量修正；能够和武器攻击同时展开全力攻击，但那时将视为次要天生武器，采用基本攻击加值-5进行攻击，伤害加值为力量修正一半。】





**猫之狡黠（****Clever 
Cat****）**：猫族通常天性友善，但是也不能排除那些狡猾的家伙。他们中的一些将社会的险恶当做了游戏——参与并且赢下它。这些猫族在唬骗、交涉和察言观色上获得+2种族加值。这一种族特性取代狩猎本能。





**攀爬者（****Climber****）**：猫族猎人擅长从树木或者其他制高点发起狩猎。这些猫族拥有20尺攀爬速度（包括在攀爬检定上有+8种族加值）。这一种族特性取代短跑健将。





**好奇心（****Curiosity****）**：猫族天生就对他们身边的世界充满了好奇，不过有些比起他们的同类更加变本加厉。这些猫族在获得信息的交涉检定上获得+4种族加值，并且知识（历史）和知识（地方）对他们而言总是本职技能。如果他们的职业包括了其中的一个知识技能作为本职技能，则他们在此技能检定上获得+2种族加值。这一种族特性取代狩猎本能。





**猫落（****Nimble 
Faller****）**：一些猫族拥有惊人的平衡能力，并且对于自身的重心相当敏锐。拥有这一特性的猫族在落地时总是以双脚着地，即使他们会在这次坠落中受到坠落伤害。此外，拥有这一特性的猫族在对抗摔绊的CMD+1。这一族特性取代短跑健将。





**灵敏嗅觉（****Scent****）**：有些猫族的嗅觉灵敏，不过他们的视力就一般了。拥有这一特性的猫族获得“灵敏嗅觉”能力。这一种族特性取代昏暗视觉。


【能力速查】**灵敏嗅觉（****Scent, 
Ex****）**：这种特殊能力可以让生物察觉接近的敌人、嗅出隐藏的对手、或者凭借嗅觉展开追踪。具有灵敏嗅觉能力的生物能够辨识熟悉的气味，就像人类能认出熟悉的画面。凭借嗅觉，生物可以发现30尺以内的敌人。如果对手在上风处，则距离增为60尺；若在下风处，则减为15尺。如果是强烈的气味，比如浓烟或者腐烂的垃圾味道，可在上述距离两倍之内闻到。某些无法抵挡的气味，比如臭鼬或穴居人的恶臭，则可在通常距离的三倍之内闻到。具有灵敏嗅觉的生物无法确定气味来源的具体位置，只知道它存在于嗅觉范围内的某处。生物可以用一个移动动作来觉察到气味来源的方向。只要生物进入气味源的5尺之内，它就能精确确定源头的位置。具有灵敏嗅觉的生物可以通过气味来追踪，这时它用感知 
(或生存技能) 检定来找到或追踪气味。新鲜痕迹的通常DC是10（无论气味停留在什么表面）。该DC会因气味来源的强弱、生物的数量和痕迹新旧的差别在此基础上增加或减少。痕迹每经过1小时DC会增加2。除此之外，此能力的判定上都按照追踪专长的规则。地面状况和低能见度不会影响通过嗅觉来展开追踪的生物。

**贼猫（****Cat 
Burglar****，盗贼变体）******





凭借过人的手腕和潜行天赋，猫族得以成为优秀的窃贼。贼猫是破门而入的大师，即使是在一只初出茅庐的贼猫身上，你也只能看见猫的优雅，却不见任何犯罪的影子。对于贼猫而言，锁和陷阱没有任何意义。





**魅****影身姿（****Phantom 
Presence, Ex****）**：4级起，贼猫精通潜行之道，并且她可以在地城和城市中不留下任何踪迹的移动。在地牢和城市中，她不留下任何踪迹，也不能被跟踪，当然如果她希望，她也可以选择留下踪迹。此外，她在隐匿检定中总是可以取10。这个能力取代直觉闪避。





**陷阱天敌（****Trap 
Saboteur****）（****SU****）**：8级起，贼猫开始精通避开陷阱和锁——亦或是操控它们。她可以用一个标准动作尝试开锁，并且以正常情况下一半的时间（至少1轮）无效一个陷阱。当她经过一个没有能够解除的陷阱时，她可以选择在1分钟内压制陷阱不让其被触发。如果她这样做了，她也可以用一个自由动作提前结束压制。这个能力取代精通直觉闪避。

**灵动卫士（****Nimble 
Guardian****，武僧变体）******





一些猫族武僧将他们优雅的力量奉献给他人，尤其是那献身于同一组织或者是能够见证他们武僧之道的盟友们。





**援护防御****（****Defensive 
Aid, Ex****）**：2级起，每日“3+感知修正”次，灵动卫士可以干涉对于相邻盟友的攻击或者范围伤害的效果。如果相邻的盟友是攻击的目标或者需要通过一次反射豁免来减少伤害，则灵动卫士能以一个直觉动作给予这位盟友AC或者反射豁免+4环境加值。灵动卫士必须无甲或者穿戴轻甲才能使用此能力。这个能力取代反射闪避。





**灵活反射（****Nimble 
Reflexes, Ex****）**：3级起，灵动卫士反射豁免+2。这个能力取代心如止水。





**防御精通（****Defensive 
Mastery, Ex****）**：5级起，灵动卫士获得额外3次每日【援护防御】的使用次数。此外，如果一个盟友得到【援护防御】的帮助并且在反射豁免中成功、但是依旧需要受到伤害的场合，灵动卫士可以花费1点气来无效这个伤害。这一行为并不花费动作。这个能力取代百病不侵。





**守护之猫（****Guardian 
Feline, Su****）**：7级起，灵动卫士可以花费2点气变身为猫形态。这个效果持续1小时或者直到灵动卫士变身回来。变身（变成猫或变回来）是一个不会引发借机攻击的标准动作，必须选择猫科动物（猎豹、狮子等）作为变身形态。此能力类似‘野兽形态II’法术。9级时，此能力类似‘野兽形态III’法术。这个能力取代混元体。





**反射闪避（****Evasion, 
Ex****）**：9级起，灵动卫士获得【反射闪避】。这个能力取代精通反射闪避。

**爪刃（****Claw 
Blades****）**：这种特殊的刀刃只有拥有【猫爪】种族特性的猫族才能使用。一套5件，按在穿戴者的一只手爪上。这种刀刃基于穿戴者用爪的攻击骰上获得+1增强加值，并且将武器类型由天生武器改变为轻型挥砍武器。拥有【猫爪】种族特性的猫族擅长这种武器。爪刃可以像正常武器一般附魔，计算成本时将一只手爪上的5枚刀刃视为一组计算。爪刃价格305gp，重2磅。





**肉垫靴（****Softpaw**** 
Boots****）**：这种柔软而又特殊的靴子是由丝绸和专门的熟皮制成。它们专门按照猫族的脚设计，贴合猫族脚部结构，用以柔化脚步和减少痕迹。穿着肉垫靴的猫族在隐匿上获得+1环境加值。此外，发觉或者追踪穿着肉垫靴的猫族的足迹的DC+2。肉垫靴价格25gp，重1磅。





**气味信息素工具包（****Trailscent**** 
Kit****）**：这种装着特制猫族信息素和炼金试剂的小盒子可以用来留下一种细微而又长效的气味，只有猫族可以闻到和辨别这个气味。花费1分钟，猫族可以将其混合并且涂在特定目标上用以留下气味，目标可以是一棵树、一堵墙，甚至是更小的东西。当猫族这样做了以后，这留下了下列气味印象之一：危险，食物，避难所，或者是所有权。所有权的印象具体到使用这一工具包的猫族，这意味着她拥有这一领土或者物品。其他种族可以用这一工具包建立危险，食物或者避难所的印象，但这样做需要通过一个DC20的工艺（炼金）检定。猫族可以在30英尺外闻到气味信息素工具包留下的味道。如果气味在上风处，则猫族闻到气味的距离增加60尺；如果是逆风，则下降到15尺。一个拥有“灵敏嗅觉”种族特性的猫族闻到气味的距离翻倍。气味印象持续1年或者直到被冲走。每个工具包可以使用10次。气味信息素工具包价格10gp，重5磅，制造工艺DC25。【译者吐槽：卧了个大槽！尼玛这是喵星人还是汪星人啊！】

**黑猫（****Black Cat****）******


***厄运降临在那些胆敢攻击你的人身上。*********


**先决条件**：猫族。


**专长效果**：每日1次，当你被近战攻击命中时，你可以用一个直觉动作让攻击者以-4罚值重投攻击骰。攻击者必须接受重投的结果。这是一个超自然能力。


**特殊说明**：当你选择这个专长时你的毛色将变为纯黑色。





**猫族典范（****Catfolk**** Exemplar****）******


***你猫科动物的特征比起你的同族更加鲜明突出。*********


**先决条件**：猫族。


**专长效果**：你可以选择“化兽态”专长，即使你没有达到先决条件。此外，你以下列方式之一表现你猫科动物的形态。你在选择此专长的时候决定表现形态，并且无法在以后改变。


**增强感官（****Enhanced Senses, Ex****）**：如果你有昏暗视觉，你获得猫族的【灵敏嗅觉】种族特性。如果你有【灵敏嗅觉】种族特性，你获得昏暗视觉。


**急速冲刺（****Fast Sprinter, Ex****）**：你在进行冲锋、奔跑、撤退动作时获得10尺种族加值。如果你有【短跑健将】种族特性，则你在进行冲锋、奔跑、撤退动作时获得的加值提高到20尺。


**锐爪（****Sharp Claws, Ex****）**：如果你没有【猫爪】种族特性或者“化兽态（兽爪）”专长，你获得【猫爪】种族特性。如果你有【猫爪】种族特性或者“化兽态（兽爪）”专长，则你的爪的伤害增加到1d6。


**特殊说明**：你可以多次选择这一专长。其效果不叠加。每次选择这个专长，你必须选择一个不同的表现形式。


【专长速查】**化兽态（****Aspect of the Beast, APG****）**：得到四选一的兽类优势。





**爪袭（****Claw Pounce****）〔战斗〕******


***你可以一边冲锋一边用你的爪子攻击。*********


**先决条件**：力量13，敏捷15，机敏前锋，基本攻击加值+10，猫族，【猫爪】种族特性或者“化兽态（兽爪）”专长。


**专长效果**：当你冲锋时，你可以用爪子全力攻击。


**通常状况**：冲锋是一个特殊的整轮动作，你只能做一次攻击。





**猫科优雅（****Feline Grace****）******


***你与生俱来的优雅使你得以应付最棘手的情况。*********


**先决条件**：敏捷13，猫族。


**专长效果**：你在对抗冲撞，擒抱，闯越，移位和绊摔战技的CMD+2。





**机敏前锋（****Nimble Striker****）〔战斗〕******


***你与生俱来就是冲锋的料，没人能比你做得更好。*********


**先决条件**：敏捷13，基本攻击加值+1，猫族，【短跑健将】种族特性。


**专长效果**：当你在使用“顺势斩”专长、“突刺”专长或者冲锋时，不必承受AC-2的罚值。

**猫眼冠（****Cat's Eye Crown****）******


**灵光**：中等预言系；**施法者等级**：10级；


**位置**：头部（或者无，见下文）；**价格**：18000gp；**重量**：1磅。


这顶纤细的银制冠饰的中央镶嵌着一枚猫眼石。当宝石被固定在冠饰上时，佩戴者获得60尺黑暗视觉；如果佩戴者已经拥有黑暗视觉，则她黑暗视觉的范围增加60尺。这枚宝石可以被取下并且扔进房间、投到洞里、抛出窗外或者按到别的生物上。每天一次，佩戴者可以用一个命令启动宝石并且获得‘锐耳术/鹰眼术’的法术效果，但是佩戴者使用猫眼石作为魔法传感器，并且在魔法传感器处于黑暗环境下获得黑暗视觉。如果宝石由一个生物持有或携带，那么即使那个宝石被放在袋子或者其他的容器里，无论宝石的携带者有无意识到这颗宝石的存在或者是否知晓这颗宝石真正的功能，冠饰的佩戴者都能够将那个生物作为‘锐耳术/鹰眼术’的传感器。破坏宝石（硬度8，生命值5）可以切断联系。一颗价值不低于100gp的猫眼石可以被雕琢并且和冠饰匹配，这个过程需要24小时。


**制造条件**：“制造奇物”；‘锐耳术/鹰眼术’，‘黑暗视觉’；必须由猫族制造。


**制造成本**：9000gp。





**无畏肉垫靴（****Daredevil Softpaws****）******


**灵光**：微弱惑控系；**施法者等级**：3级；


**位置**：脚部；**价格**：1400gp；**重量**：1磅。


这双神奇的肉垫靴（见上文）允许猫族在穿着它通过威胁区域的时候获得额外的机动性。以一个自由动作，穿戴者可以轻叩她的足跟并且在她通过危险区域、或者穿过敌人威胁格避免借机攻击的特技检定获得+5表现加值。这个效果每日可以持续10轮，不过使用时间不需要连续。此外，当穿戴者穿越敌人的威胁格但没有引发借机攻击时，她对那个敌人的攻击+2，直到她的行动轮结束。


**制造条件**：“制造奇物”；‘猫之优雅’。


**制造成本**：700gp。

**九命天猫****（****Nine Lives****，又译９命）******


| 学派 |  | 防护系 |
| --- | --- | --- |
| 环级 |  | 牧师8，女巫9 |
| 施放时间 |  | 标准动作 |
| 成分 |  | 声音，姿势，材料/法器（猫的胡须） |
| 范围 |  | 接触 |
| 目标 |  | 一个接触到的生物 |
| 持续时间 |  | 1小时/每等级 |
| 豁免 |  | 意志，通过无效（无害） |
| 法术抗力 |  | 可（无害） |


和法术的名字不同，这个强大的法术并不能赋予目标更多的生命，而是在一定程度上给予目标脱离险境以及减轻有害效果的能力。在法术持续时间内，目标能以直觉动作使用下列任何一种能力。这些能力使用9次后，法术结束。


**猫幸**：目标可以在一次豁免失败时使用这个能力。目标可以重投豁免骰，但必须采用新的结果即使新结果更加糟糕。


**坚韧**：目标可以在被重击或者偷袭时使用这个能力。无效重击或者偷袭效果并且只能造成普通伤害。


**回春**：目标可以在生命值降到0或者更低时使用这个能力。目标立即治愈3d6点伤害。如果治愈的生命值使得目标的生命值变为正数，则目标不会失去意识。如果目标的生命值依旧不是正数，则目标自动稳定。这两种效果都能在伤害原本足矣杀死目标时生效。


**摆脱**：目标可以在受到任何下列效果影响的时候使用这个能力：目盲，困惑，畏缩，眩晕，目眩，纠缠，力竭，疲乏，惊惧，反胃，惊惧，恐慌，战栗，恶心，恍惚。使用这个能力终止其中的一个效果。


**逃脱**：目标可以在被擒抱或者压制时使用这个能力。目标自动脱离擒抱或压制如同做出了一次成功的逃脱对抗。


**稳定**：目标可以在被摔绊或者其他原因倒地时使用这个能力。目标稳定身形并且保持直立。





**窃取呼吸（****Steal Breath****）******


| 学派 |  | 变化系〔气〕 |
| --- | --- | --- |
| 环级 |  | 诗人2，德鲁伊2，术士/法师2 |

| 成分 |  | 语言，姿势 |
| 范围 |  | 近距（25尺+5尺/每2等级） |
| 目标 |  | 一个活物 |
| 持续时间 |  | 1轮（见下文） |

你将空气从生物的肺里抽出，对他造成伤害并且使之无法说话、使用喷吐武器或是施展有语言成分的法术。如果目标没有通过豁免，则受到2d6点伤害，并且不能说话、使用喷吐武器或者任何依赖呼吸的行为。一股可见的空气漩涡从目标的嘴里流出并且进入你的嘴里。


如果在法术持续时间中目标移动出了法术范围或者和你之间不存在效果线，则法术立即结束。这个法术无法影响不需要呼吸的生物。
