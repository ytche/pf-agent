## 记录格式

每条问题包含：

- **来源规则书**：产生问题的 L2 来源书名。
- **问题归类**：`markdown格式` / `标题定位` / `目标位置待确认` / `条目归属待确认` / `脚本限制` / `其他`。
- **严重程度**：`阻塞性` / `需要人工校验` / `影响轻微` / `建议优化`。
  - `阻塞性`：导致整理无法继续，必须先解决。
  - `需要人工校验`：当前有临时方案，但正确性需人工确认。
  - `影响轻微`：对当前整理结果影响小，可后续顺手修复。
  - `建议优化`：流程或脚本可改进，但不影响当前交付。
- **涉及文件**：源 Markdown 文件名或目标文件路径。
- **问题描述**：具体问题现象及影响。
- **当前处理**：本次整理采用的临时处理方式。
- **备注**：建议后续如何彻底解决。
