# 来源书链路修复方案（book 未知 30.4% + chm_toc_path 空 22.7%）

> 记录时间：2026-08-03 | 状态：**已实施（2026-08-03）**——断点 A 重跑两后处理脚本（book 未知 1806→100）、断点 B 回填脚本落地（toc 空 1348→0），详见 §六
>
> 关联：KN093（feat_index 重复）、KN092（benefit 覆盖率）、KN030（chm_toc_path 映射表）、KN075（链接残留）

## 一、问题背景

来源书链路：

```
源文件 → chm_toc_path（MdMappingTocProvider，按 md_mapping.json 文件名查）
       → book 缩写（pipeline 判定链：页头《书名》→ chm_toc_path 子串缩写匹配）
       → 后处理：apply_chm_toc_mapping.py（doc_id 粒度套映射表，conf=70）
```

当前产物（chunks.jsonl，5948 chunks）两个缺口：

| 缺口 | 数量 | 归属 |
|---|---|---|
| **book 未知**（`?`） | 1806 chunk / 85 doc | 断点 A |
| **chm_toc_path 空** | 1348 chunk / 83 doc | 断点 B |

**关键事实：两者完全不相交（都缺 = 0）**——book 未知的都是页码文件（`page_XXX`/`专长N`），toc 空的是 organized 中文名文件（`极限荒野UW_专长` 等）。

## 三、断点 B：chm_toc_path 空 1348（83 doc）——organized 文件结构性缺口

### 根因

- 83 个 doc 全是 **organized 中文名文件**（`极限荒野UW_专长`/`武器大师手册_专长`…）
- MdMappingTocProvider 按 `md_mapping.json`（2141 条，CHM 转换产物）文件名查——organized 整理文件不在映射里 → toc 空
- 注意：这些文件 **book 已知**（文件名缩写/页头判定链识别，如 UW conf=65），缺的只是「目录引导」信息

### 方案：三级链路（chunk 级优先，逐级兜底）

organized 文件内有两类来源信号（均验证 100% 覆盖）：

```
信号 1（主，81/83 文件）：条目级 source 注释
  <!-- XX-source:page_325.md:敏锐射击 -->   ← 源 md 文件 + 条目标题
  源 md → md_mapping.json → toc_path（如「未整理 → 魔法战术工具箱 → 专长」）

信号 2（兜底，83/83 文件）：> 来源：行
  > 来源：恶棍志（Villain Codex）VC，页码见原书，未整理 → 反派法典VC → 专长
  直接提取「未整理 → X → Y」路径；46 文件为文件级唯一路径，37 文件为条目级
```

**三级回填**：

| 级别 | 条件 | 路径来源 | 覆盖 |
|---|---|---|---|
| ① chunk 级 | chunk title 命中条目级注释标题 | 注释源 md → md_map toc | 80/83 文件，条目级 chunk 匹配 77.4%（631/815） |
| ② 文件级兜底 | 未命中或文件级注释/无注释 | `> 来源：` 行路径（46 文件唯一；37 文件取公共前缀） | 100% 覆盖 |
| ③ 清洗规则 | 路径段含 `.md`/`page_` 前缀（MSH 一条混入 `page_667.md`）；DR 注释怪格式（`魔法技艺.md+专长9.md`） | 段丢弃或整条走 ② | 兜底 |

**验证数据**（2026-08-03）：

- `> 来源：` 行：83/83 文件全有，路径提取 83/83 成功，格式与现有 toc 完全一致（`未整理 → X → Y` 与 page_XXX 文件 toc 同形态）
- source 注释：81/83 文件有，80 个源 md 可查 md_map（98.8%）；2 文件无注释（哈罗牌手册THH/惧怖冒险HA）走 ②
- 同文件多路径（子章节不同）仅 4 个合并文件（武器大师手册/武术手册MAH/屠龙者手册/怪物召唤者手册MSH）——chunk 级匹配恰好解决，可到章节级（如「未整理 → 武器大师手册 → 武器掌握专长」）
- 唯一路径 82 个（46 文件级文件中 2 文件共享 1 路径）

### 预期

1348 chunk 全部拿到 toc，粒度 chunk 级 → 章节级 → 文件级递减；不动 text/title/metadata/chunk_id，保持 verify 不变量。
