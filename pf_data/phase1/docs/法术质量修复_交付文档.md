## 三、F2：COMP 裸标签 → 统一 IR

### 修复前实样（spell_page_1365_0093 · 炫示纹章）

```
**等级：** 术士/法师/奥能师 1、…
施放时间：标准动作          ← 裸标签，casting_time 未 parsed
**成分：** 姿势、器材 (一个纹章或武器涂层)
持续：1小时/等级            ← 裸标签，duration 未 parsed
**豁免：** 意志，通过则无效 (无害)
抗力：有 (无害)             ← 裸标签 + 值变体（有/无 而非 可/不可）
```

### 修复后

所有裸标签归一化为 `**标签：**` 标准 IR，进入统一解析管道：

```
**等级：** 术士/法师/奥能师 1、…
**施法时间：** 标准动作
**成分：** 姿势、器材 (一个纹章或武器涂层)
**持续时间：** 1小时/等级
**豁免：** 意志，通过则无效 (无害)
**法术抗力：** 有 (无害)
```

### 修复点（commit `03677f9`）

| 文件 | 改动 |
|------|------|
| `vectorizer/formats/spell.py` | `_unify_field_labels()` F2 步骤：用 `[*\s]*` 字符类兼容 `**` 包裹/空白混合前缀；裸标签锚定字段区（行首或紧跟上一字段值结束之后） |

### S4：field_status 诚实性交叉检查

```bash
python3 -c "
import json
def empty(v):
    if v is None or v=='' or v==[] or v=={}: return True
    if isinstance(v,dict): return all(empty(x) for x in v.values())
    return False
with open('vectorizer/output/法术/chunks.jsonl') as f:
    chunks = [json.loads(l) for l in f]
bad1 = bad2 = 0
for c in chunks:
    m = c.get('metadata',{})
    fs = m.get('field_status')
    if not fs: continue
    for k, st in fs.items():
        v = m.get(k)
        if st=='parsed' and empty(v): bad1 += 1
        if st=='missing' and not empty(v): bad2 += 1
print('parsed 但值为空:', bad1, ' missing 但值非空:', bad2)
"
```
