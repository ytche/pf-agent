## 2. S1 + S2（代码部分）：`_truncate_value_prose` 两个 bug

> 文件：`vectorizer/processors/spell.py:101-153`

### 2.1 根因（k3 已定位，附重放证据）

**Bug A（→ S1 的 160 回归）**：`\n` 截断分支的续行白名单 `_CONTINUATION_PREFIXES` 含 `"*"`（`processors/spell.py:89`）。KN012 拆行后字段值呈 `值\n**下一字段**` 形态，第二行以 `**` 开头被白名单当作"合法续行"放行，导致：

- `casting_time = '一个标准动作\n**语言，姿势，材料 (一株蒲公英的茎秆)**\n**近距 (25尺+5尺/2级)'`（AG-冒险者指南 ×13、MC-怪物志 ×16 等）
- `duration = '10分钟，或专注（最多1轮/等级）；见下文\n**意志过则无效 (无害)'`（duration 吞豁免块）
- `range = '120尺**区域：** 120尺长，10尺宽'`（range 吞区域块）

**Bug B（→ S2 的截断未生效）**：分支顺序错误。当前顺序：duration 终止标记 → `\n` 分支 → R5 散文信号 → `。` 分支。真实数据的 duration 值是**两行**（`专注 + 3轮（可解消）该法术的功能如同…想像。\n当你专注时…`），`\n` 分支中第二行以"当"开头（不在白名单）→ 命中 `return lines[0]`，**直接返回了含散文信号的脏第一行**，R5 分支（`_PROSE_LEAD_INS`）永远执行不到。受害：UI_0004、OA_0084、OA_0085。

重放证据（k3 已跑通）：单行输入时 R5 分支能正确截断；两行输入时 `\n` 分支提前 return 脏值。

### 2.2 修复设计（TDD：先写测试）

```
调整分支顺序 + 收窄续行白名单：

1. R5 散文信号截断（_PROSE_LEAD_INS）移到 \n 分支之前，
   对整体值检查（不只对 lines[0]）。
2. \n 分支：第二行以 ** 开头（双星号字段块）→ 视为字段边界，截断；
   单 * 开头仍放行（保留原设计意图）。
   判定建议：second.startswith("**") → 截断；
   原 "*" 白名单项收窄为不匹配 "**" 的单星号。
```

**反例保护（必须写 negative test）**：

- 合法跨行 range `近距 (25尺\n+ 5尺/2级)` → 不截断（第二行以 `+` 开头）
- 单 `*` 开头的合法续行（如存在）→ 不截断
- effect 合法单句枚举以 `。` 结尾 → 不截断（N9）
- 散文中 `**抗力**`（无冒号强调）所在的**正文**不受影响（本函数只处理字段值，N3）
