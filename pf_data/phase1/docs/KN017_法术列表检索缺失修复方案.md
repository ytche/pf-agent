## 2. 修复设计（用户已拍板）

### 2.1 解析器修复 1（核心）：Phase 1c½ 神祇后缀正则收窄为标题结构锚定

`formats/spell.py:212-217`：

```python
# 修改前（过宽：任何 ** 开头、/汉字结尾的行都剥）
text = re.sub(
    r'^(\*\*.*?)/[一-鿿]{1,12}\s*$',
    r'\1',
    text,
    flags=re.MULTILINE
)

# 修改后（标题结构锚定：**中文 (English)** 之后才允许剥神祇后缀）
text = re.sub(
    r'^(\*\*[^*]+\([^)]+\)\*\*)/[一-鿿]{1,12}\s*$',
    r'\1',
    text,
    flags=re.MULTILINE
)
```

- 字段行（`**环位：**…术士/法师 `、`**持续时间：**1分钟/等级`、`**等级：**…吟游诗人/歌者 `）含字段标签或不以 `)**` 收尾，**永不匹配**；
- FoP 真神祇标题（如 `**轻量化 (Lighten Object)**/古拉姆`）保留剥离能力；
- **实施验证点**：FoP 标题归一化后的实际形态需在 TDD 中先行固定——若存在后缀在粗体内（`**轻量化 (Lighten Object)/古拉姆**`）的形态，需补一条粗体内变体规则，以 FoP 18 个 chunk 标题无 `/神祇` 残留为验收；
- `[一-鿿]` 保持原写法（与代码库一致），注释注明等价 `[一-鿿]`。

**连带恢复效果**（不设单独指标，统一复测时核对）：419 处持续时间值恢复 `X/等级`；歌者/战斗祭司/奥能师/猎人/调查员/先知职业标记恢复。

### 2.2 解析器修复 2：parse_spell_level 无空格兜底

`formats/spell.py:1296` `parse_spell_level`，在标准 `(.+?)\s+(\d+)` 之后、纯数字分支之前，加无空格兜底：

```python
# 无空格兜底："法师2" / "德鲁伊4"（PF 中文职业名无数字结尾，安全）
m = re.match(r'^([一-鿿][一-鿿/]*?)(\d+)$', part)
if m:
    items.append({"class": m.group(1).strip(), "level": int(m.group(2))})
    continue
```

- 复合职业 `术士/法师2` 同样命中（`/` 在字符集内），F3 拆分逻辑（`processors/spell.py:455`）不变；
- 测试用例：`法师2`→法师 2；`术士/法师2`→术士 2+法师 2；`炼金术师 2`（有空格）不回归；`1分钟/等级` 类非职业串不误判（该串在环位字段不会出现，测试作为 negative case 固定）。
