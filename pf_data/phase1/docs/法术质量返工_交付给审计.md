## 三、R1 实施详情（路径 A：修代码）

### 修复内容

**问题**：5 个 chunk 的 save.effect 含同行粘连正文/标签污染（总计 3 种根因）。

**修复 3 处代码**：

1. **`formats/spell.py` — F2-inline (tight) 正则**（新增 20 行）
   - 在现有 F2-inline 正则后追加 tight 版本
   - 匹配已知豁免值尾词（`无效|有效|生效|见下|减半|通过|无`）后紧跟裸标签的模式
   - 安全约束：值限定为 `{有,无,是,否,可,不可,见下文,见文本,见后文}`，防止散文误转
   - 尾词排序：长尾词（`无效`）在短尾词（`无`）前，防止前缀吞并
   - 修复：P&P_0005/P&P_0006（`无抗力：有` 粘连）、page_702_0011（`见下抗力：无` 粘连）

2. **`processors/spell.py` — `_parse_saving_throw` 边界截断**（新增 7 行）
   - 在（见描述）/（见文本）/（见后文）标记处截断
   - 仅当标记后紧跟 CJK 字符时截断（判别正文粘连 vs 合法标点结束）
   - 修复：PA_0014/PA_0015（`通过则部分生效（见描述）<正文>` 粘连）

3. **`test_spell_metadata_v0_3.py` — 9 个新测试**
   - 3 positive：tight regex 匹配 `无效抗力：`/`见下抗力：`/`生效抗力：`
   - 3 negative：散文 `无效抗力极高`/`效果持续`/`通过抗力无` 不被误转
   - 3 `_parse_saving_throw`：见描述/见文本边界截断 + 标点后不截断

### R-S1 复测（k3 可直接跑）

```bash
python3 -c "
import json
IDS = ['spell_药剂与毒药P&P_法术_0005','spell_药剂与毒药P&P_法术_0006',
       'spell_异能选集PA_法术_0014','spell_异能选集PA_法术_0015','spell_page_702_0011']
with open('vectorizer/output/法术/chunks.jsonl') as f:
    chunks = {json.loads(l).get('chunk_id'): json.loads(l) for l in f}
dirty = 0
for cid in IDS:
    c = chunks.get(cid)
    if not c: print('  !! chunk 不存在:', cid); continue
    e = str((c['metadata'].get('saving_throw') or {}).get('effect') or '')
    polluted = '。' in e or '抗力' in e or len(e) > 45
    dirty += polluted
    print('%-36s len=%-4d polluted=%s  %r' % (cid, len(e), polluted, e[:50]))
print('污染残留:', dirty)
"
```

**预期输出**：5 行 `polluted=False`，`污染残留: 0`
