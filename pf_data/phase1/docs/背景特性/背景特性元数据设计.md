## 二、component_type 枚举（4 值，人工门决策）

| component_type | 含义 | 来源形态 | 检索端建议 |
|---|---|---|---|
| `trait` | 背景特性条目（主体） | A/B 族条目 | 正常权重 |
| `trait_intro` | 章节介绍段（无条目正文） | 基础页开篇段（page_150「基本背景被划分为四个子类…」） | 降权（专长 feat_intro 同款） |
| `trait_flaw` | 缺陷条目 | page_158 缺陷（反向背景特性） | 降权（PFS 禁用） |
| `trait_category` | 分类标题 | 章节标题 `**战斗背景（****Combat Traits****）******` | 排除或降权 |

> 决策点 1：缺陷条目独立 component_type（`trait_flaw`）而非 metadata 标记——理由：缺陷是独立规则体系（PFS 禁用 + 反向特性），检索时需可区分；且与 trait 字段集几乎相同，无需双 schema。
> 决策点 2：`trait_category` 是否产 chunk——专长先例 feat_intro 产 chunk 降权；分类标题无正文（空 text），**不产 chunk**（与种族 KN085 空 text 口径一致）。

## 三、metadata 字段表（6 个规范字段）

设计输入：字段标签八种异体（类型/分类/类别/出处/要求/效果/背景类型/前置条件）+ 三通道（字段行/标题括号/【】前置）+ 神名括号（page_157/ISG）。

### 3.1 核心字段（全条目适用）

| key | 中文规范标签 | 别名聚合（勘探实测） | 说明 |
|---|---|---|---|
| `trait_type` | 类型 | 类型 30 / 分类 / 类别 / 背景类型 / 裸文本类型行 / 标题括号（语义漂移）/【】前置 | **list**（复合值如「地区，世界之冠」拆分）；归一词表见 §四 |
| `requirement` | 需求 | 需求 69 / 要求 / 前置条件 | 字符串；值跨行合并（`Kelesh or \nQadira`）；无需求字段 → missing |
| `source` | 来源 | 出自行（`出自《…pg. N》`）/ `> 来源：` 引用块 / 【书缩写】 | 来源书引用原文（如 "Andoran, Spirit of Liberty pg. 18"）；三级：出自行 > 引用块 > 【书缩写】 |
| `deity` | 神祇 | 神名括号（ISG `（泽弗斯）`/page_157 `（神祇，EN）`后置壳） | 仅 ISG/宗教页有；其余 missing 或 not_applicable |

### 3.2 特殊字段（可选）

| key | 中文规范标签 | 说明 |
|---|---|---|
| `pfs_eligible` | PFS 标记 | 【PFS】禁用（page_158）/【PFS】前缀（坐骑背景）；bool：True=可用/False=禁用说明 |
| `flaw` | 缺陷标记 | component_type=trait_flaw 时冗余标记（便于检索过滤）；bool |

### 3.3 字段状态（field_status 三态）

| 状态 | 含义 |
|---|---|
| `parsed` | 字段成功解析，值非空 |
| `missing` | 源文本中未找到该字段 |
| `not_applicable` | 该条目不适用此字段（如非宗教背景无 deity） |

## 四、trait_type 归一词表（12+1）

**归一规则**（勘探 26 值 → 13 值）：
- 信仰/宗教/信念 → **信念**
- 地区/地区背景 → **地区**
- 社交/社会 → **社会**
- 战斗/战斗背景/战斗背景（combat） → **战斗**
- 魔法/魔法背景 → **魔法**
- 种族/种族背景 → **种族**
- 宗教背景 → **宗教**
- 基础（战斗）/基础（魔法）/基础（社会）/基本（魔法） → **并入对应类型**（基础（战斗）→战斗，2026-08-05 拍板）
- 典范/坐骑/宇宙/缺陷/装备/派系 → 保持

**词表（12 值）**：战斗/信念/魔法/社会/派系/种族/地区/宗教/装备/宇宙/典范/坐骑/缺陷（基础（X）已并入，见 §六-3）

**来源通道优先级**（同条目多通道冲突时）：字段行 > 标题括号 > 【】前置 > 文件上下文（无字段文件 ISG/BoF/BoA）。
