## 〇、一句话结论

## 二、形态摸底（2026-08-05 抽样实测）

### 形态 A：基础页星壳流式（page_150~157，战斗/信念/魔法/社会/派系/种族/地区/宗教）

```
**解剖师（****Anatomist****）【APG】**：作为一介大学医科生或是死灵师学徒，你接受过解剖学的系统训练。你知晓如何瞄准对方最致命的器官，并在重击确认的投骰中获得+1背景加值。
```

- 特征：`**中文名（EN）【书缩写】**：正文`，与专长条目形态**同构**（专长 `_split_closed_title_colon` / 星壳剥除 / 【书】来源标记均可复用）
- 章节标题：`**战斗背景（****Combat Traits****）******`——与 `_SECTION_KEYWORDS` 模式同型（背景特性分类名即章节）
- 陷阱预判：英文名跨行断词（`Basic \nTraits`、`Armor \nExpert`）——与专长/法术 elided 形态同族（`_RE_ELIDED_CN_EN_GLUE` 族可参考）

### 形态 B：来源书 H2 文件（安多安ASoL、初探内海ISP 等 50 文件）

```
## 贝里斯采蜜员（Bellis Honey Harvester）

出自《Andoran, Spirit of Liberty pg. 
18》
**类型**：地区
**需求**：贝里斯［安多安内部］（Bellis [in 
Andoran]）
你经常接触蜜蜂……你面对集群造成的伤害时获得DR 
3/-，以及对抗源于集群的毒素和扰乱心神时豁免获得+1背景加值。
```

- 特征：`## 中文名（EN）` H2 + 出自行（**页码跨行断**）+ `**类型**：` + `**需求**：` 字段行 + 正文——与种族 BotB/ISR 文件形态同构（H2 标题 + 字段行 + 来源引用块 `> 来源：`）
- 类型字段枚举（地区/信念/战斗/魔法/社会/种族/装备…）——**需全库枚举定字段词表**（KN100 教训：词表一次定全，先全库扫描定性）
- 需求字段：地区名［括号］+ 英文——与专长先决条件字段同构

### 需新设计（背景特性专属）

1. **component_type 枚举**：提案 `trait`（条目）/ `trait_intro`（章节介绍段）/ `trait_flaw`（缺陷条目）/ `trait_category`（分类标题）——人工门决策
2. **格式簇划分**：基础页流式（形态 A）/ 来源书 H2（形态 B）/ 缺陷（形态 C）/ 典范·坐骑·宇宙（形态 D）——勘探定稿
3. **类型字段词表**：地区/信念/战斗/魔法/社会/种族/装备/宗教/派系/宇宙 等全枚举——先全库扫描定性再定稿（KN100 教训）
4. **来源书缩写表注册**：50 个来源书文件的书缩写（ASoL/PotN/DEP…）——chm_toc_path → 书缩写映射表扩展（专长 1780→136 的同类工作）
5. **元数据 schema**：类型/需求/出自行三个背景特性专属字段 + field_status 三态——先画「字段 × component_type」矩阵（经验沉淀 §A10）

### 不应复用

- 种族 race_name 四级兜底链（无「归属种族」概念——背景特性归属分类，改为分类/来源书兜底）
- 专长造物字段任务链（无工艺/造物概念）

## 五、建议开工顺序（经验沉淀 §〇速查表应用）

1. **Prepare 三闸口**：`python3 -m vectorizer.prepare.{census,firstlast,phantom} --category trait`（注册语义表）
2. **k3 交接文档**（本清单 + 勘探批次设计 + 逃生舱/红线）→ 执行模型勘探 63 文件
3. **人工门 1**（格式簇判定/est 对账/去重策略/基线评估/风险核查 五件套）→ k3 独立复算
4. **TDD**：formats/trait.py + processors/trait.py（形态 A/B/C 真实样本簇）
5. **pipeline 产出** → 产出即检五合一 → verify_traits（判别器回归/召回/字段健康/行级对账）
6. **cicd verify --category trait 装配** + 闸口参数登记（book '?'/toc/空 text/>5000 各类目口径）
7. **k3 四合一验收** + 审计报告 + KN 登记 + 交付文档 + HANDOVER/CLAUDE.md 同步

## 六、风险与登记

- **类型字段形态不确定**（26 条 vs 103 H2——来源书不全有类型字段？）——勘探时逐文件定性
- **典范背景/背景特性17 未抽样**——勘探批次先行
- **缺陷条目定性**（独立 component_type vs 标记并入）——人工门决策点
- 公共层改动（如需）必须全类目回归（feat/race/spell + trait）——KN112/KN136 教训
- 源数据修改（如需）必须字节级——CRLF 约定（两次事故教训）
