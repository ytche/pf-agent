## R3 背景特性17 特殊处理（混合页）

- **原内容段**（篷车星系介绍 intro + 表格 14 + 【PFS】流式 13，共 28 条）：按 R2 → 「宇宙」
- **HH 补录段 21 条**：不采用 R2 整页默认。**用户拍板选项 B**：利用 HH 段内裸文本分类标记行（「信念背景」「地区背景」）段落级填充 → 归一后「信念/地区」；前 3 条无标记（血腥复仇/医疗特使/战争伤痕）维持空
- 识别方式：formats 层 split 遇 `<!-- HH-source:` 注释行后标记当前条目 `_hh_section: True`（HH 段在文件尾部 115~245 行，特征稳定），并跟踪最近裸文本分类标记行 → item["_trait_type_from_marker"]

## 实现链路

```
formats/trait.py split_into_items
   ├─ HH 段识别：遇 <!-- HH-source → item["_hh_section"]=True
   └─ 分类标记行跟踪：裸文本「信念背景/地区背景」行 → 后续条目 item["_trait_type_from_marker"]
processors/trait.py infer_metadata
   ├─ trait_type 归一（现有）
   ├─ 兜底 1（R2）：空且 doc 在 _PAGE_TYPE_DEFAULT → 填默认值（HH 条目跳过）
   └─ 兜底 2（R3-B）：_hh_section 且 _trait_type_from_marker 非空 → 填标记值
      （_hh_section 且无标记 → 维持 missing）
```

优先级：解析值（parsed）> R3-B 标记值 > R2 页面默认 > missing。
