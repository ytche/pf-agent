## 4. 实现方式

- 重写 `formats/trait.py` 的 `_RE_SOURCE_LINE` 分支 1：`出自/来源` 前缀后整段作为 body 捕获，不再用 lazy `(.+?)》?` 跨书名号回溯；
- `body` 只由 `_RE_SOURCE_REF`（成对书名号 / 中文后接英文 / 英文括号 / 裸英文 / 页码前后置）结构化渲染，非引用片段原样保留；
- `_RE_SOURCE_VALUE` 仅识别出处字段的 `《书》（EN）页码` 值，与出自行共用同一渲染器；半星壳出处同样调用该渲染器；
- 标准值 `中文（English）页码` 幂等直通，不做全局半角转全角、不改逗号、不截断合法页码。
