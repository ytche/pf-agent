# §16 整理后文档格式整洁性

> 详细规则文档。主文档 `未整理目录整理规则.md` 第 16 节指向本文件。
> 仅在整理完成后的验证阶段或处理格式异常时按需加载。

## 16.0 适用范围

- 每次整理完成、写入目标文件后，必须对输出文件做格式校验。
- 适用于 `pf_rules_md_organized/` 下所有新增或修改的 Markdown 文件。
- 格式异常的常见源头：
  - 直接从 CHM 转换的 Markdown 残留 HTML 标签；
  - 跨行标题未预合并；
  - 表格在复制粘贴过程中丢失分隔行；
  - 加粗/代码块标记半闭合；
  - 多条目挤在同一段。

## 16.1 段落整洁

**要求**：

- 标题独占一行，前后保留空行。
- 段落之间用空行分隔（避免两段文字紧贴）。
- 多条独立条目必须分行书写，禁止挤在同一行或同一段。
- 标题行尾、正文中不得夹杂 `![[图片]]` 等占位符。
- 来源标注 `> 来源：...` 单独成行，紧跟条目标题下一行。

**反例（禁止）**：

```markdown
## 浓缩烧瓶（Focusing Flask）> 来源：炼金术手册 AM，124页，未整理 → 炼金术手册AM → 物品
**栏位**：无；**价格**：900 gp；**重量**：—
本物品可以...
```

**正例**：

```markdown
## 浓缩烧瓶（Focusing Flask）

> 来源：炼金术手册 AM，124页，未整理 → 炼金术手册AM → 物品

**栏位**：无；**价格**：900 gp；**重量**：―
本物品可以...
```

## 16.2 表格语法

**要求**：

- 表格必须有标准的 `| --- |`（或 `|:---:|`、`|---:|`）分隔行。
- 每行的 `|` 数量必须一致（与表头列数匹配）。
- 单元格内容用 `|` 包裹。
- **禁止**出现"只有表头无分隔行"的伪表格。
- 表格内换行用 `<br/>`（Markdown 表格内不支持真实换行 `\n`）。

**反例 1（缺分隔行）**：

```markdown
| 名称 | 价格 | 重量 |
| 浓缩烧瓶 | 900 gp | ― |
```

→ 渲染器会把第二行当作段落而不识别为表格。

**正例 1**：

```markdown
| 名称 | 价格 | 重量 |
| --- | --- | --- |
| 浓缩烧瓶 | 900 gp | ― |
```

**反例 2（列数不一致）**：

```markdown
| 名称 | 价格 | 重量 |
| --- | --- | --- |
| 浓缩烧瓶 | 900 gp |
| 精控蒸馏器 | 1200 gp | ― | 灵光微弱 |
```

→ 第二行只有 2 列，第三行有 4 列，渲染异常。

**正例 2**：

```markdown
| 名称 | 价格 | 重量 | 备注 |
| --- | --- | --- | --- |
| 浓缩烧瓶 | 900 gp | ― | |
| 精控蒸馏器 | 1200 gp | ― | 灵光微弱 |
```

**表格内换行**：

```markdown
| 名称 | 描述 |
| --- | --- |
| 浓缩烧瓶 | 第一行描述<br/>第二行描述 |
```

## 16.3 加粗 / 斜体标记配对

**要求**：

- `**加粗**` 必须成对出现，**禁止**未闭合的 `**...` 残段。
- `*斜体*` 必须成对出现。
- 跨行加粗 `**xxx\nyyy**` 写入前必须预合并为单行（参考主文档 §4.5）。
- 嵌套加粗 `**xxx**yyy*zzz**www**` 会导致解析歧义，禁止使用。

**反例**：

```markdown
**浓缩烧瓶（Focusing
Flask）**：本物品可以...

浓缩烧瓶（Focusing Flask）：**栏位**：无
```

**正例**：

```markdown
**浓缩烧瓶（Focusing Flask）**：本物品可以...

浓缩烧瓶（Focusing Flask）：**栏位**：无
```

**校验方法**：

- 统计文件中 `**` 出现次数，必须为偶数。
- 用 `grep -nP '\*\*[^*\n]+$' file.md` 检查每行末尾未闭合的 `**`。

## 16.4 标题层级合理

**要求**：

- 聚合文件用 `#` 标题（如 `# 炼金术手册AM 专长`）。
- 条目用 `##` 标题（如 `## 浓缩烧瓶`）。
- 子条目用 `###` 标题。
- **禁止**跳级（如 `##` 直接到 `####`，缺少 `###`）。
- **禁止**反向嵌套（如 `###` 套在 `##` 内层级倒置）。
- 同级标题前后保留空行。
- 来源标注 `> 来源：...` **不**算标题层级，只是引用块。

**反例**：

```markdown
# 炼金术手册AM 专长

## 浓缩烧瓶

#### 浓缩烧瓶的炼金配方
```

→ 跳级（`##` → `####`）。

**正例**：

```markdown
# 炼金术手册AM 专长

## 浓缩烧瓶

### 浓缩烧瓶的炼金配方
```

## 16.5 HTML 标签清理

**要求**：

- **禁止**出现未处理的 `<P>`、`<DIV>`、`<SPAN>`、`<FONT>`、`<HR>`、`<IMG>`、`<OBJECT>`、`<PARAM>` 等 HTML 标签。
- 已转换为 Markdown 语法的标签（如 `**`、`>`）必须保持正确。
- 实体符号 `&mdash;`、`&nbsp;`、`&amp;` 等必须用 `html.unescape` 还原。
- 出现异常标签时回退 HTML 源重新解析（参考主文档 §12）。

**反例**：

```markdown
<P>这是物品描述段落。</P>
浓缩烧瓶的价格是 &mdash; 900 gp。
```

**正例**：

```markdown
这是物品描述段落。
浓缩烧瓶的价格是 — 900 gp。
```

**校验方法**：

- `grep -nE '<(P|DIV|SPAN|FONT|HR|IMG|OBJECT|PARAM)\b' file.md` 不应命中。
- `grep -nE '&(amp|nbsp|mdash|lt|gt|quot);' file.md` 不应命中。

## 16.6 列表与代码块

**要求**：

- 列表标记 `-` / `*` / `1.` 前后保留空格（如 `- 浓缩烧瓶`）。
- 代码块用三反引号 ` ``` ` 包裹，并标注语言（如 ` ```python `）。
- **禁止**未闭合的代码块或列表。
- 列表项之间不必空行；有序/无序列表不可混排同一层级。

**反例（未闭合代码块）**：

```markdown
以下是脚本示例：

```python
def foo():
    pass
```

→ 第二个 ` ``` ` 会被识别为"代码块结束"，但 Python 部分未被标记为代码块。

**正例**：

````markdown
以下是脚本示例：

```python
def foo():
    pass
```
````

**校验方法**：

- 统计文件中 ` ``` ` 出现次数，必须为偶数（`grep -c '```' file.md` % 2 == 0）。
- 检查 `- ` / `* ` / `1. ` 后是否有空格。

## 16.7 自动校验脚本示例

```python
import re
from pathlib import Path

def validate_markdown(path: Path) -> list[str]:
    text = path.read_text(encoding='utf-8')
    errors = []

    # 1. 加粗标记配对
    if text.count('**') % 2 != 0:
        errors.append(f'{path}: ** 加粗标记未配对')

    # 2. 代码块闭合
    if text.count('```') % 2 != 0:
        errors.append(f'{path}: ``` 代码块未闭合')

    # 3. HTML 残留
    html_tags = re.findall(r'<(P|DIV|SPAN|FONT|HR|IMG|OBJECT|PARAM)\b', text, re.IGNORECASE)
    if html_tags:
        errors.append(f'{path}: 残留 HTML 标签 {html_tags[:5]}')

    # 4. 实体符号
    entities = re.findall(r'&(amp|nbsp|mdash|lt|gt|quot);', text)
    if entities:
        errors.append(f'{path}: 未还原实体符号 {entities[:5]}')

    # 5. 表格分隔行（仅检查"疑似表格"的行块）
    for i, line in enumerate(text.splitlines(), 1):
        if re.match(r'^\|.+\|\s*$', line):
            next_line = text.splitlines()[i] if i < len(text.splitlines()) else ''
            if not re.match(r'^\|?[\s\-:|]+\|\s*$', next_line):
                errors.append(f'{path}:{i}: 表格缺分隔行（下一行: {next_line[:30]}）')

    # 6. 标题跳级
    prev_level = 0
    for line in text.splitlines():
        m = re.match(r'^(#+)\s', line)
        if m:
            level = len(m.group(1))
            if prev_level > 0 and level > prev_level + 1:
                errors.append(f'{path}: 标题跳级 {prev_level} -> {level}（{line[:50]}）')
            prev_level = level
        elif line.strip() == '':
            pass  # 空行不影响层级判断
        else:
            prev_level = 0  # 非标题行打断层级

    return errors
```

## 16.8 验证清单

整理完成后，对每个新增/修改的目标文件运行校验：

- [ ] 加粗 `**` 标记数量为偶数（无未闭合残段）。
- [ ] 代码块 ` ``` ` 数量为偶数（无未闭合代码块）。
- [ ] 无残留 HTML 标签（`<P>` / `<DIV>` / `<SPAN>` / `<FONT>` / `<HR>` 等）。
- [ ] 无未还原实体符号（`&mdash;` 等）。
- [ ] 表格行块都有 `| --- |` 分隔行。
- [ ] 表格每行 `|` 数量一致（与表头列数匹配）。
- [ ] 标题层级不跳级（`#` → `##` → `###` 顺序）。
- [ ] 来源标注 `> 来源：...` 位于条目标题下一行。
- [ ] 段落之间有空行分隔，无多条目挤在一段。
- [ ] 标题前后有空行，无标题紧贴正文。
