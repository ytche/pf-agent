## 3. S1 + S2 代码部分（`_truncate_value_prose` 双 bug）

### 3.1 根因（k3 第 2 轮已定位）

**Bug A → S1**：`\n` 截断分支的续行白名单 `_CONTINUATION_PREFIXES` 含 `"*"`。KN012 拆行后字段值呈 `值\n**下一字段**` 形态，第二行以 `**` 开头被白名单当作"合法续行"放行，导致 casting_time/range/duration 吞字段。

**Bug B → S2**：分支顺序错。当前顺序 `duration 终止 → \n → R5 散文信号 → 。`，两行 duration 第二行以"当"开头（不在白名单）→ 命中 `return lines[0]` **直接返回含散文信号的脏第一行**，R5 分支永远执行不到。受害：UI_0004、OA_0084、OA_0085。

### 3.2 修复设计（TDD red-green）

**S1+S2 代码修改**（`vectorizer/processors/spell.py` `_truncate_value_prose` + `_extract_school`）：

```python
# S1+2 关键改动：
# 1. R5 散文信号检查（_PROSE_LEAD_INS）前移到 \n 分支之前
# 2. \n 分支：second.startswith("**") → 视为字段边界截断
# 3. 续行白名单 "*" 收窄（不匹配 "**"）
# 4. _extract_school 扩 M3 whitelist含别名：附魔/通用系/变形系/塑能术
# 5. value.lstrip("*") 剥离前导星号
```

**S2 源数据修改**（`格拉里昂的纯洁勇士_法术.md`）：6 处 `**变化【善良】**` → `**变化【善良】系**`，让 M3 白名单 `r'^(变化|...)(系)?'` 命中。**关键**：保持 `\s*` 不匹配（`系` 非空白字符）以避免 `_strip_title_suffixes` pattern 4 误剥；保持 chunk 拆分不被 C 簇 regex 误断（10 chunk 不变）。
