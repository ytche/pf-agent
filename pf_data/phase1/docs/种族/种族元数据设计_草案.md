## 一、设计原则（沿用专长元数据设计/架构决策 29）

| 模式 | 落地 |
|---|---|
| 骨架通用字段 | `chm_toc_path` 由 FileProcessor 模板方法统一填充，类目零负担 |
| 类目特有字段 | 全部进 `Chunk.metadata` dict，不入骨架 |
| 富化 Provider | 纯富化不进来源书链（MdMappingTocProvider 模式） |
| 三钩子 | `build_chunk` / `resolve_source` / `infer_metadata`；格式层只管产出条目 dict |
| 命名风格 | snake_case、默认空串、`field(default_factory=list)` |
| 字段状态 | `field_status` 三态（parsed/missing/not_applicable，参考法术四态删 ambiguous） |

## 二、component_type 枚举（12 个）

| 值 | 语义 | 来源簇 | 检索策略 |
|---|---|---|---|
| `race_intro` | 种族主条目（页面级：描述/属性调整/体型/速度/感官/语言/种族特性总览） | A | 正常权重（主入口） |
| `race_trait` | 种族特性条目（`**特性名（EN）：**` 描述） | A | 正常 |
| `alt_trait` | 替换特性条目（哨兵行「此特性替换」/出自行） | B/E | 正常（replaces 字段辅助） |
| `fcb_entry` | 天赋职业奖励条目（`**职业名（EN）：**` +1/2 描述） | C | 正常 |
| `race_archetype` | 种族职业变体条目 | A/D | 正常 |
| `race_variant` | 种族变体/亚种条目（含 MC 杂项：模板/血统/陷阱/诅咒/巫术/领域/背景/炼金发现/秘示域/仆从模板，`entry_subtype` 细分） | A/D/E | 正常 |
| `race_feat` | 种族相关专长条目（先决条件/专长效果字段） | A/D/E | 正常 |
| `race_spell` | 种族相关法术条目（学派/等级/施法时间/法术目标） | A/D/E | 正常 |
| `race_item` | 种族相关装备/奇物/武器条目（价格/重量/灵光/施法者等级/制造条件/制造成本） | A/D | 正常 |
| `race_sidebar` | 边栏/无标题段落（BoS 全无加粗形态、PA 译者行） | E/G | 降权（KN094 同型） |
| `race_overview` | 概述页（page_10 表格行 + 简介段、page_11 年龄表行、MC 开篇） | F | 索引用途降权（对应专长 feat_index） |
| `monster_block` | 怪物数据块（AP 五段式、page_1015 卓尔贵族） | D | 正常（检索端可区分类怪条目） |

**对齐说明**：专长 `feat_index`/`feat_intro` 在种族映射为 `race_overview`（索引表格行）+ `race_sidebar`（介绍性段落降权）；`feat_type` 标签体系种族无（〔〕标记不存在），以 component_type 代替分类维度。

## 三、metadata 字段表

### 3.1 核心字段（race_intro 全量 + 条目通用）

| key | 说明 | 数据来源 |
|---|---|---|
| `race_name` | 种族中文名 | 主标题/基线表 name_zh |
| `race_name_en` | 种族英文名 | 主标题括号/基线表 name_en |
| `alternate_name` | 又译名 | page_349 又译主标题等 |
| `race_group` | 族群（核心/常见/罕见/其他/怪物法典MC/内海怪物志/来源书/概述） | 目录归属 |
| `rp_value` | RP 值（(2RP)/(1RP) 标注，可选） | 标题尾部/BoS 形态 |
| `format_cluster` | 格式簇（A~G，勘探划分） | format_cluster_hint 归一化 |
| `source_book` | 来源书缩写（未知→chm_toc_path 三级链路，复用专长方案） | 来源书链路 |
| `source` | 来源引用原文（`> 来源：` 引用块/出自行） | 源文本 |

### 3.2 结构字段（ARG 页主条目 race_intro）

| key | 说明 | 频次佐证 |
|---|---|---|
| `ability_adj` | 属性调整（+2敏捷，+2魅力，-2体质） | 基线表 37 行 + ARG 页 |
| `bio_type` | 生物类型（类人生物/异怪/…) | 基线表 |
| `size` | 体型（小型/中型/…） | 基线表 |
| `speed` | 速度（30尺/40尺…） | 基线表 |
| `senses` | 感官（昏暗视觉/黑暗视觉…） | 基线表 |
| `languages` | 语言 | ARG 页 |

### 3.3 条目级字段（按 component_type 取用）

| key | 适用 | 说明 |
|---|---|---|
