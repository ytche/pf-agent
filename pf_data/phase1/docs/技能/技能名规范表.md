中文条目以「问句」为 title（如「恐惧术对增强召唤的进阶召唤生物的影响」），英文条目 title=自身（如「Flight」）；检索端以 Q&A 形态命中，非技能名形态（不进技能名归一，进 FAQ 问答检索）。

### 3.6 Unchained 规则条目（PU，226 条）

技能解放/混职系统/背景技能等规则条目，命名随原页形态（含「技能解放：技能名」「造物与专业替换」等）；非独立技能名，不进技能名归一。

## 四、检索端使用约定

1. 术语归一：用户输入中文名/英文名 → 本表映射（26 技能 + 子类 + 扩展书新增名）；
2. 同名区分：知识/表演子类、科技变体（TG）、Unchained 规则条目均与 CRB 主条目同名——检索端以 `component_type` + `rule_version` 过滤区分；
3. 英文名检索：CRB 26 + 子类 + GIANT/OCCULT 条目带 aliases 可英文命中；PotR/TG 无英文名（源数据无），中文命中；
4. 游泳字段缺陷（KN158）已修复闭环（2026-08-07），key_ability/armor_penalty 产物与 CHM 清单一致。
