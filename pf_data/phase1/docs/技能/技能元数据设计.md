## 一、设计原则（对齐 v2.0 类目无关引擎）

| 骨架模式 | 落地 | 技能元数据影响 |
|---|---|---|
| **骨架通用字段**：`chm_toc_path` 顶层字段由 FileProcessor 模板方法统一填充 | 技能不重复设计来源路径富化 | 元数据字段表不含来源路径类字段 |
| **类目特有字段进 `metadata` dict** | 技能全部特有字段放 `Chunk.metadata`，不入骨架 | 本文档 §二 字段表全部是 metadata 键 |
| **三钩子模板方法**：`build_chunk` / `resolve_source` / `infer_metadata` | 元数据推断在 `infer_metadata` 钩子；格式解析在 format 层（`formats/skill.py`） | format 只管产出条目 dict，字段归一化在 infer_metadata |
| **字段命名风格**：snake_case、默认空串、`field(default_factory=list)` | 沿用 | — |
| **结构不变量前置**：含专项覆写的处理模块改动前不变量清单（CLAUDE.md 规则） | 技能格式簇 S1~S10 即不变量来源 | §四 component_type 与 §二 字段表 = 不变量断言清单 |

**字段标签长标签优先**：`ALL_FIELD_LABELS` 排序沿用法术 `(-len, 字母序)` 规则，防止"检定"误匹配"检定（Check）"式前缀吞并。

## 二、metadata 字段表（11 个规范字段 + task 结构）

设计输入：勘探 `field_labels_seen` 全库聚合（96 种标签、56 文件全记录）。核心字段四件套频次：动作 32 / 检定 30 / 特殊 28 / 重试 26；低频变体：未受训 5、限制 2。高频标签归一化进规范字段，低频散字段进 `extra`。

### 2.1 技能标识字段（全条目适用）

| key | 类型 | 说明 | 决策依据 |
|---|---|---|---|
| `skill_name` | str | 技能规范中文名（26 技能权威清单 + Unchained/巨人猎手/UI 扩展名） | 决策 11（CHM 目录权威）+ KN155（技能名规范表） |
| `english_name` | str | 英文名（title 内嵌，断行英文名重组后提取，KN012 类方案） | R4 实测 260 行 |
| `key_ability` | str | 关键属性：力量/敏捷/智力/感知/魅力 | 决策 11：CHM 权威清单；正文标题 `(感知)` 交叉验证 |
| `trained_only` | bool | 须受训（【训】标记） | 决策 11：CHM 权威清单；正文 `; 须受训` 后缀交叉验证 |
| `armor_penalty` | bool | 防具检定减值（【减】标记） | 同上；正文 `; 防具检定减值` 后缀交叉验证 |
| `sub_specialty` | list[str] | 泛用型技能子类：知识 10 类、表演子项等（决策 7：**每子类独立 chunk**，主条目保留列表字段供检索过滤） | S3 子项列表型 2 页 |

> 决策 11 落地口径：**【减】【训】以 CHM 26 技能权威清单为权威**（正文无方括号标记已实测）；正文标题 `; 须受训` / `; 防具检定减值` 后缀作一致性校验——不一致时以 CHM 为准并记 KN 偏差。

### 2.2 正文字段（CRB 技能页核心四件套 + 低频变体）

| key | 类型 | 说明 | 频次 |
|---|---|---|---|
| `check` | str | 检定字段正文（含行内 DC 值，如 "DC20/25/30+") | 30 |
| `action` | str | 动作（"1 个标准动作"等） | 32 |
| `retry` | str | 重试 | 26 |
| `special` | str | 特殊 | 28 |
| `untrained` | str | 未受训（仅部分技能有） | 5 |
| `restriction` | str | 限制（page_174 后置节形态实测，page_175 等） | 2 |

**动作/重试/特殊/限制/未受训位置规则（决策 4）**：**按正文实际位置归属**——字段在任务小节内（如 page_176 绳缚任务含重试）归该任务，在技能级（标题后、任务小节前）归主条目；节顺序异常 2 处（page_174 限制在【速查】后、page_178 未受训在【速查】后）按实际位置不重排。

### 2.3 来源与版本标识（R10）

| key | 类型 | 说明 |
|---|---|---|
| `source` | str | 来源书引用原文（复用专长模式；GIANT-source 注释行解析后并入） |
| `rule_version` | str | 版本标识：`crb` / `unchained` / `giant` / `potr` / `occult` / `technology` / `faq` / `ui`（Unchained 可选规则 vs CRB 冲突隔离，检索端可过滤） |

### 2.4 字段状态（field_status 三态）

每字段随值附状态，合法值三态（沿用专长，去 ambiguous）：

| 状态 | 含义 |
|---|---|
| `parsed` | 字段成功解析，值非空 |
| `missing` | 源文本中未找到该字段 |
| `not_applicable` | 该条目不适用此字段（如 UI 散文段无 trained_only） |

## 三、任务级双级结构与 DC 表（决策 1/3）

### 3.1 任务级双级切分（决策 1，建议方案）

主条目 chunk + 任务 chunk，两级独立可检索：

```json
// 主条目 chunk（component_type=skill）
{
  "skill_name": "医疗", "english_name": "Heal", "key_ability": "感知",
  "trained_only": false, "armor_penalty": false,
  "check": "你对一个生物进行急救……",
  "dc_table": [{"task": "急救", "dc": "DC 15", "desc": "稳定濒死生物"}],
  "tasks": [
    {"name": "急救", "id": "heal_first_aid", "dc": "DC 15",
     "text": "对一个濒死或正在失血的生物进行急救……",
     "action": "1 个标准动作", "retry": "", "special": ""},
    {"name": "治疗疾病", "id": "heal_treat_disease", "dc": "疾病 DC", ...}
  ]
}
```

```json
// 任务 chunk（component_type=skill_task）
{
  "skill_name": "医疗", "task_name": "急救",
  "text": "对一个濒死或正在失血的生物进行急救……",
  "dc": "DC 15", "action": "1 个标准动作"
}
```

**DC 双写（决策 3）**：主条目 chunk 保留 DC 表（保真、速查全景）；任务 chunk 内嵌对应 DC（自包含——"急救 DC 多少"单任务命中即答）。两处来源同源（同一解析结果），非重复存储。

### 3.2 任务级字段归属

任务小节内的字段（动作/重试/特殊/DC）归任务（4 处单句行内任务标记实测：page_176 绳缚/镣铐等）；任务级字段在任务 chunk 与主条目 tasks[].* 双份，主条目字段只留任务级归技能级。

### 3.3 task id 约定

`<技能英文名小写 snake>_<任务中文名>`（如 `heal_first_aid`）；知识 10 类 sub_specialty 任务的 id 为 `<skill>_<specialty>`（如 `knowledge_dungeoneering`）。

### 3.4 子类独立 chunk（决策 7 拍板）

知识【训】10 学科（page_181）、表演子项（page_184）每子类独立成 skill_task chunk（`knowledge_dungeoneering` / `perform_act` 等），子类正文按学科子项段落提取；主条目 chunk 保留（含 `sub_specialty` 列表 + 子类总述 + 检定/动作/重试/特殊字段），子类 DC/描述在子类 chunk 自包含。子类 chunk 属任务级产物，不进 26 技能主召回分母。

## 四、component_type 枚举（决策 2，建议 8 类）

| 值 | 覆盖 | 格式簇 | 检索端建议 |
|---|---|---|---|
| `skill` | CRB 26 技能主条目 + 巨人猎手 4 条目 + 河域子民 2 规则 | S1/S2/S3/S8 | 主检索目标 |
| `skill_task` | 任务小节（CRB 15 页任务型）+ **知识 10 类/表演子项每类独立 chunk**（决策 7 拍板） | S1/S3 | 任务级 QA 命中（"急救 DC 多少"）；子类 chunk 按学科名检索 |
| `skill_note` | 【速查】引用块（决策 5 已拍板） | S1（页尾） | 降权（GM 速查摘要，正文已有全量） |
| `ui_supplement` | UI 8 页散文补充（决策 6 已拍板，独立类型不挂靠单技能） | S4 | 降权（补充性质）；`skill_name` 可带多个（察觉/潜行）或空（泛用页） |
| `skill_rule` | Unchained 6 文件 + 异能 315 + 科技 760 + FAQ 837 | S7/S9 | 按 `rule_version` 过滤；FAQ 每「主题名：」锚点一条 |
| `skill_index` | 格拉利昂语言汇总 62 条 + page_1038 骨架（决策 8 已拍板） | S5 | 单独计数不进主召回；语言名检索 |
| `skill_intro` | 导言页 page_161/162（overview 角色） | S6 | 降权（章首纲要） |
| `skill_equipment` | 工具和技能工具包 24 物品条目（S10；工具包.md 已豁免决策 11） | S10 | 物品名检索；尾部整段重复解析器层去重（拍板 #9） |

> 附录 C 建议 6 类（含 skill_rule）——勘探数据驱动升级为 **8 类**：新增 `skill_intro`（导言 2 页独立标记，对齐专长 feat_intro 先例）与 `skill_equipment`（物品条目与规则条目语义异质，混入 skill_rule 会污染规则检索）。
