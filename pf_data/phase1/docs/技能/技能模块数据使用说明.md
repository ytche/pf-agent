## 二、检索端注意事项（按优先级）

### 2.1 【必做】component_type 降权（检索语义保护）

- **`skill_note`（速查块，23 条）**：CRB 技能页【速查】块内容（如「医疗：DC20/25/30+」速查表）与正文重复。检索端**降权**——正文条目（skill/skill_task）未命中时才作为补充。
- **`skill_intro`（导言，4 条）**：FAQ 2 节标题（title 空 text 豁免）+ 章节导言。**降权**——仅当无具体条目命中时作为类别概念素材；绝不可作为具体规则引用。
- **`ui_supplement`（UI 补充译文，8 条）**：非规则权威（CHM UI 翻译补充页，散文段形态）。**降权**——CRB 正文条目优先。
- **`skill_index`（语言汇总，60 条）**：语言名检索目标，不进规则问答主召回。

### 2.2 【必做】aliases 空 220 条的处理（不可拒绝条目）

- 分布：skill_rule 140（Unchained 纯中文小节/种族子节/表标题、FAQ 837 中文条目——**中文条目无英文名属设计内**，英文条目 title_en=自身）+ skill_task 76（任务级条目多数无独立英文名）+ skill_equipment 3 + skill_index 1；
- 处理：检索端以 `title`（中文名）为主键，aliases 为空**不得剔除条目**——规则问答以中文术语命中为主；
- 英文名检索：26 技能主条目 + 知识/表演子类 + FAQ 英文条目均带 aliases，英文术语→中文规则的可命中路径完整。

### 2.3 【必做】rule_version 过滤语义（Unchained 冲突隔离）

- `metadata.rule_version` 八值：`crb` / `unchained` / `giant` / `potr` / `occult` / `technology` / `faq` / `ui`；
- **Unchained 可选规则（PU，225 条）与 CRB 冲突隔离**：如「技能解放」（page_648，28 条）替代 CRB 技能效果、「混职系统」（page_649）为可选规则——检索端回答 CRB 技能问题时**不得混入** rule_version=unchained 条目，除非用户明确提及「解放/Unchained」；反之用户问 Unchained 规则时以 unchained 条目为主；
- FAQ（63 条）为 CRB 官方问答，可作为 CRB 补充权威，但回答须标注「官方 FAQ」。

### 2.4 【必做】FAQ 837 问答流形态（S9）

- 61 条 Q&A 按锚点判据切分（中文条目问号前「。」/「.」判据、英文条目首字母大写判据、【译注】块整体跳过）；
- 文本特征：`text` 含「更正：」/「注意：」后缀修正语（原文如此，不剥离）；无锚英文问题（如 When I use a magic item…）自然并入上一条目 text——检索命中时须完整展示并入内容，不得按句截断；
- 【编注】块（译者注）已在解析层整体跳过，产物 text 残留 0。

### 2.5 【建议】空 text 7 条 + 超大 chunk 1 条降权

- 空 text：skill_intro 2（FAQ 节标题，title 可检索）+ skill_index 5（语言条目，语言名在 title/aliases）——命中时正文为空，降权并只展示标题；
- **超大 chunk**：page_162「技能详述」总览页 text 5295 字符（>5000 通用护栏，对齐专长 KN095）——检索端对 text>5000 降权，防止总览页吞并具体条目命中。

### 2.6 【建议】缩写同名与译名差异（跨模块口径）

- **AA 同名缩写**：技能模块 AA=冒险者的军械库｜Adventurer's Armory，trait 模块 AA=秘术选集｜Arcane Anthology——两书官方缩写均 AA（PF 生态真实同名）。chunk 级字段按类目隔离无冲突，检索端按类目过滤后无歧义；展示层建议拼 `book_name_cn`（中文全名）而非裸缩写；
- **PotR 译名统一**：技能表 cn=「河域之民」与 trait 表一致（源文件名为「河域子民PotR」，映射表已归一）；
- 跨模块「技能名」锚点以《技能名规范表.md》为权威（KN155），检索端术语归一直接引用该表。
