## 2. 语义切分设计（核心）

### 2.1 component_type 六类草案

| 取值 | 语义 | 覆盖对象 | 检索端职责 |
|---|---|---|---|
| `skill` | 技能主条目 | 26 个 CRB 技能正文页、UI 补充页 | **主检索目标**（与专长 feat 对齐） |
| `skill_use` | **任务级切分单元**（本模块核心创新） | 任务小节（急救/长期护理/大眼瞪小眼/佯装无害…）、UI 补充规则块、巨人猎手 4 条 | 主检索目标——任务 = 独立使用场景（"急救 DC 多少"） |
| `skill_intro` | 导言/总览 | page_161/162 技能总览、属性分组页导言段 | 降权 |
| `skill_index` | 索引/清单 | 属性分组页主体、格拉利昂语言汇总（拍板点） | 检索入口/组装素材，与 skill 配对 |
| `skill_rule` | 完整可选规则页 | Unchained 背景技能/分组技能/整合技能/技能解放/造物与专业替换/混职系统、UI 替换对抗检定、科技/神秘/FAQ | 主检索目标（独立规则体系，feat 三分类无法容纳） |
| `skill_note`（候选） | 【速查】内联引用块 | 条目内嵌 `【速查】**自给自足**：` 引用块 | 独立 chunk 利于跨模块建链；或降级为主 chunk 附注字段（拍板点） |

### 2.2 任务级双级结构（决策 1，推荐方案）

- **主条目 chunk（skill）**：标题行 + 一句话描述 + 检定基础规则 + 技能级动作/重试/特殊 + **DC 表原文完整保留**（保真/溯源锚点）
- **任务 chunk（skill_use）**：每个任务小节独立成 chunk，**内嵌该任务 DC 描述**（自包含/检索友好）
- **DC 双写**：DC 表原文在主条目保真 + 任务 chunk 携带对应行；允许"主条目原文被裁行"降级预案（登记 KN）
- **结构重复处理**：治疗中毒/治疗疾病等几乎同构任务 → 切分器模板化（task_name/dc/effect 字段归一），内容不合并
- **动作/重试/特殊归属**：按正文实际位置判定——技能级标准字段归主条目、任务小节内出现的归任务 chunk（page_193 等超长条目逐条确认）
- **泛用型技能子类**（知识 10 子类/工艺/表演/专业）：`sub_specialty` 结构化字段，不拆独立 chunk；"未列出子类由 DM 裁定"保留在主条目
- **UI 补充页归属**：独立条目（source=UI）挂靠主技能（察觉与潜行 挂 察觉+隐匿 双技能），不并入 CRB 正文（保 source 溯源）
- **【减】【训】标记**：CHM 目录技能名带标记（攀爬【减】、解除装置【减/训】），正文标题行无标记（已实测）→ 标记来源固定 CHM 目录，映射进 `armor_penalty`/`trained_required`

### 2.3 metadata 字段草案（trait 6 → feat 14 → skill 演进）

| 字段 | 类型/来源 | 说明 |
|---|---|---|
| title_zh / title_en | 正文标题行 | UI/巨人猎手英文名需断行修复（已实测 3 处） |
| key_ability | 正文标题行 | 力量/敏捷/智力/感知/魅力（无体质技能） |
| trained_required / armor_penalty | **CHM 目录**【训】【减】 | 正文无标记，来源固定 CHM |
| sub_specialty | 正文 | 知识(奥秘) 等子类列表 |
| task_list / dc_table | 正文解析 | 任务名枚举 + 任务→DC 映射（JSON） |
| action / retry / special | 正文 | 按实际位置归主条目或任务 |
| source | 文件归属 | CRB/UI/巨人猎手/Unchained/河域子民/科技/神秘/FAQ |
| component_type | 设计 | 六类 |
| chm_toc_path / page_ref | CHM 映射 | 100% 目标；巨人猎手/散件无 TOC 路径（溯源缺口标注） |
| parent_chunk_id | 生成 | 任务 chunk → 主条目 |
| related_refs | 预留 | 专长名引用（跨模块字段预留，本期不解析） |
