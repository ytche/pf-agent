## 六、检索端术语归一提示

1. 本表为**跨模块权威**（与 terms.json 1075 术语、技能名规范表同层）；检索命中术语时优先展示本表锚定名称
2. 缩写词（AC/BAB/DR/DC 等）检索时双向匹配（中文名 ↔ 英文名 ↔ 缩写）
3. 「减值/罚值」同义归一（Penalty）；「掩蔽/掩体」以正文为准（Cover）
4. 状态术语 28 项为权威清单（page_9 速查页），战斗状态（擒抱/俯卧等）可跨模块引用（专长/技能模块同词形）
