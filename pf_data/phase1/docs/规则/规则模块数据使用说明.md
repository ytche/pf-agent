## 一、语义切分质量评估结论

**满足一期 Agent 调用。** 规则模块是**章节型规则文本**新形态（区别于既有 7 模块的词条型）：一节语义规则 = 1 chunk，无字段体系（不设 field_status）。

- **chunk 单元 = 语义节**，按 S1~S6 格式簇分派（heading 树 / 加粗标题 / BBS 星壳 / 纯表格页 / prose 无结构 / 超大型聚合条目级）
- **表格跟随所属节**（不独立成 chunk）；例外 = 整页纯表格页（rule_table 331）
- **超大型聚合条目级预拆**（S6 10 文件 → rule_entry 728，内容守恒由 TDD 断言 + page_299 234 块抽查保证；KN210/213/214 批次 A 修复条目边界）
- 判别器全量 286 文件 est↔got 对账零静默丢失；文件级 286 全命中越权 0
- 质量指标：空 title 19（全定性 KN204）/ 空 text 1（page_508 豁免 KN197）/ 超 5000 字符 7（全定性 KN203）/ CR 残迹 0 / 星壳 0 / **chm_toc_path 空 0**（KN205 回填）/ book '?' 188（KN195/196/203/211 登记，上限 238）/ 泛词 title 0（KN216）/ 低语义独立 chunk 0（KN218）
- **字段行并入所属节**（KN215~218 批次 C）：`**标签**：值` 行不单独成节（作祟 stat、疾病 stat、怪物能力格式行等 47 种 1172 个泛词字段行全并入），词表锚定防真标题误判（力量/步骤/健康/时间·魔法/奖励 55 保留）

**局限**（检索端须知）：
- 亚产能 125 文件（est 高估全定性，非内容丢失）——检索不感知
- 空 title 19 个 chunk 无标题锚（正文型内容），展示需首行摘要兜底
- page_508 为空文件（CHM 视觉图页图片丢失，KN197 豁免不产出，已排除出范围）
- book '?' 191（2.0%）无法单一归书（多来源混排/无来源行），检索可按 toc_group/正文溯源

## 五、后端对接速查

1. **加载**：`vectorizer/output/规则/chunks.jsonl`（7847 行，UTF-8，一行一 chunk）
2. **顶层字段**（骨架 14 字段）：chunk_id / doc_id（basename 无 .md）/ category=rule / component_type（5 枚举）/ title / text / book_abbreviation / book_name_cn / book_name_en / source_confidence（75 或 0）/ chm_toc_path（100% 非空）/ aliases / metadata / extra
3. **metadata 5 规范键**：`toc_group`（4 枚举）/ `source`（来源行原文或空）/ `rule_version`（book 小写）/ `format_cluster`（S1~S6 规范名 + none（空文件））/ `component_type`（与顶层同值）
4. **无 field_status**（章节型无字段体系）
5. **chunk_id 唯一**（7847/7847），可直接作 ES/向量库主键
6. **目录引导**：检索命中 → `chm_toc_path` 给出 CHM 目录链（如 `未整理 → 黑市指南BM → 黑市规则` 或 `规则 → HA规则 → 腐化`），前端面包屑展示 → 满足一期「可追溯信息来源」核心目标
7. **重生成**：`bash regen_rule_chunks.sh`（本地=CI 同源，产物 gitignored 不入库）
