## 二、制造字段家族归一（跨模块锚点）

技能/专长模块 craft_* 三字段先例对齐，装备归一方向（2026-08-08 全库标签聚合 97 种）：

| 规范 key | 语义 | 归一标签 |
|---|---|---|
| `craft_cost` | 制造成本（数字+币种）| 制造成本 / 制作成本 / 成本 / 花费 / 制造花费 / 制作花费 / 成本（GP）/ 制造成本与需求 / 自我值 |
| `craft_conditions` | 制造前置条件 | 制造条件 / 制作条件 / 建造条件 |
| `craft_requirements` | 制造需求（法术/专长）| 制造要求 / 制造需求 / 制作需求 / 制作要求 / 制造 / 栽培要求 |

> 「花费」归 craft_cost 的实证：ISG 条目行 `制造需求：**…**花费：**XGP**` 的「花费」= 制造成本（条目行字段链已有 `**价格：**` 零售价），归 price 会覆盖零售价。

## 五、跨模块使用口径

1. **术语表对齐**：装备名中英对照与 `terms.json` 装备类术语双向校验——产物 title 为权威中文名（源数据 CHM 转换），terms.json 缺名时以本表补录（术语关联关系二期做）。
2. **英文名形态**：大写全称（BAG OF HOLDING）与 Title Case（Bladed Scarf）并存——产物保真源数据，检索端英文匹配建议大小写不敏感归一。
3. **同物异名**：如「围巾刃/刃巾」（Bladed Scarf）斜杠并列为源数据原文保真，检索端按整串匹配。
4. **跨模块同名锚点**：技能模块 S10 装备卡 31 条（工具和技能工具包）与装备模块 gear 条目同物异源——以本表中文名为统一口径，检索端按模块降权差异回答。
