## 一、设计原则（对齐 v2.0 类目无关引擎 + 技能先例）

| 骨架模式 | 落地 | 装备元数据影响 |
|---|---|---|
| **骨架通用字段**：`chm_toc_path` 顶层字段由 FileProcessor 模板方法统一填充 | 装备不重复设计来源路径富化 | 字段表不含来源路径类字段 |
| **类目特有字段进 `metadata` dict** | 装备全部特有字段放 `Chunk.metadata` | §二 字段表全部是 metadata 键 |
| **三钩子模板方法**：`build_chunk` / `resolve_source` / `infer_metadata` | 元数据推断在 `infer_metadata`；格式解析在 format 层（`formats/equipment.py`） | format 只管产出条目 dict，字段归一化在 infer_metadata |
| **字段命名风格**：snake_case、默认空串、`field(default_factory=list)` | 沿用 | — |
| **结构不变量前置**：含专项覆写的处理模块改动前不变量清单（CLAUDE.md 规则） | 装备格式簇（§四）即不变量来源 | §四 component_type 与 §二 字段表 = 不变量断言清单 |

**字段标签长标签优先**：`ALL_FIELD_LABELS` 排序沿 `(-len, 字母序)` 规则，防止「价格」误匹配「价格调整」「装备价格调整」式前缀吞并（勘探实测存在：价格调整/装备价格调整/价格（GP）/价格（磅）等变体）。

## 二、metadata 字段表（10 规范字段 + extra 保真）

设计输入：勘探 `field_labels_seen` 全库聚合（97 种标签、297 文件全记录）。核心字段频次：价格 275 / 重量 230 / 灵光 170 / 施法者等级 96 / 制造成本 74 / 位置 68 / 栏位 67 / 制造条件 53 / 制造要求 37。高频标签归一化进规范字段，低频散字段进 `extra`。

### 2.1 物品标识字段（全条目适用）

| key | 类型 | 说明 | 决策依据 |
|---|---|---|---|
| `item_name` | str | 装备规范中文名（标题中译名） | KN167 装备名规范表（M6 交付） |
| `english_name` | str | 英文名（title 内嵌，断行英文名重组后提取，E8 成长型跨行两形态） | E7 弯撇号归一（U+2019 ↔ ASCII '） |
| `slot` | str | 奇物装备位置（**13 枚举**：腰/躯/胸/眼/脚/手/头/头饰/颈/肩/腕/戒指/无） | D5 已拍板（wondrous_item 单类 + slot 枚举字段）；CHM TOC L4 权威词表；非奇物条目 not_applicable |
| `subcategory` | str | 细分归属（刺青/艾恩石/神契/灵契/…；chm_page_刺青/艾恩石形态勘探确认） | 形态簇勘探 |

### 2.2 类目专属字段（核心九件套 + 武器扩展）

| key | 类型 | 说明 | 频次（标签归一后） |
|---|---|---|---|
| `price` | str | 价格原文（**清洗后保真**：单位归一 gp/sp 小写+空格；残缺 `+1500 G` 保留原文登记 KN） | 275 |
| `weight` | str | 重量原文（含 `—` 无重量） | 230 |
| `aura` | str | 灵光（含异体「灵氲」5 归一；CRB 字段行 `灵光：中等；施法者等级：9` 内联双字段） | 170 |
| `caster_level` | str | 施法者等级（CL 19 + 全角ＣＬ 7 + 施法者等级 96 归一） | ~122 |
| `craft_cost` | str | 制造成本（制造成本 74 + 成本 19 + 花费 6 + 价钱 4 + 制作成本 9 归一） | ~112 |
| `craft_conditions` | str | 制造条件（制造条件 53 + 制作条件 8 + 建造条件 1 归一） | ~62 |
| `craft_requirements` | str | 制造要求（制造要求 37 + 制造需求 13 + 制作需求 2 + 制作要求 1 归一） | ~53 |
| `damage` | str | 伤害（伤害 22 + 伤害（S）/伤害（M）2 归一；含表格 `| 小型伤害 |` 列） | ~24 |
| `critical` | str | 重击（重击 8 + 重击倍数 1） | 9 |

**武器/防具扩展**（武器_防具大页表格列，page_206~209 表格式条目以表格行切块，字段随行内联）：`hardness`（硬度 2）/ `hp`（生命值 2）/ `range`（射程 6）/ `armor_bonus`（护甲加值 2）/ `max_dex`（最大敏捷加值 1）/ `armor_penalty`（防具检定减值 1）/ `arcane_fail`（奥术失败机率 1）。

### 2.3 来源与版本标识

| key | 类型 | 说明 |
|---|---|---|
| `source` | str | 来源书引用原文（`> 来源：` 块 / HTML 注释 / 文件级来源行，复用专长模式） |
| `book` | str | 来源书缩写（`_EQUIP_SOURCE_OVERRIDES` 专属表短路，技能 3.1 教训；KN165） |
| `rule_version` | str | 版本标识（值域 = 书缩写全集 40+：crb/unchained/occult/mythic/ui/aa2/…，检索端可过滤） |
| `format_cluster` | str | 格式簇名（M1c 勘探 10 型 + 细化子型） |

### 2.4 字段状态（field_status 三态）

每字段随值附状态，合法值三态（沿用专长/技能，去 ambiguous）：

| 状态 | 含义 |
|---|---|
| `parsed` | 字段成功解析，值非空 |
| `missing` | 源文本中未找到该字段 |
| `not_applicable` | 该条目不适用此字段（如普通武器无 aura/caster_level；奇物 slot 无值） |

### 2.5 extra 保真（低频散字段，不设规范字段）

毒药类（发作频率/成瘾性/潜伏期/豁免DC/工艺DC/破坏DC/强韧DC/初始效果/后续效果）、栽培类（栽培要求/栽培成本/采集DC/产量）、科技类（机师组/能源/班组/容弹量/哑火/不发火率/易碎）、武器组/材质/形状/形状字段（艾恩石）等——全部进 `metadata.extra` dict 原文保真，不建 schema 约束（对齐技能「低频散字段进 extra」）。

## 三、类目专属结构

### 3.1 奇物 slot 枚举（D5 已拍板落地）

`wondrous_item` 类 chunk 的 `slot` 字段值域（13 枚举，CHM TOC L4 权威词表）：

```
腰 / 躯 / 胸 / 眼 / 脚 / 手 / 头 / 头饰 / 颈 / 肩 / 腕 / 戒指 / 无
```

- 勘探已覆盖全部 13 位置页（page_223~233）；神话冒险 page_633 另有 15 行槽位说明（含盾牌/法杖/武器，属神话能力非奇物槽位，按字段归类）
- **无槽位奇物**（艾恩石/刺青/神契等）→ `slot: "无"`
- 非 wondrous_item 条目 → `not_applicable`
- verify 侧 `EQUIP_SLOT_VALUES` 值域断言（同源 import）

### 3.2 附魔建模（enchantment + enchantment_target）

防具附魔/武器附魔（子目录 5+8 文件 + 内海系列页）独立 `enchantment` 类，附 `enchantment_target` 字段（`armor` / `shield` / `weapon` / `ammo` / `special`），按文件语义归类（防具附魔 → armor/shield，武器附魔 → weapon/ammo；混合文件逐条判定）。

### 3.3 price 形态与清洗（E13 处置）

勘探实测价格形态（M4 前置清洗归一）：

| 形态 | 示例 | 处置 |
|---|---|---|
| 标准字段 | `价格：25 gp；重量：5磅` | 直接提取 |
| 表内数值 | `\| 精金 \| 500gp \|` | 表格行切块，`gp` 归一 ` gp` |
| 独立价格行 | `**强酸(Acid) **10G 1磅**` | 价格单位归一 + 与标题同行拆行 |
| 残缺 | `价格：+1500金币` | 保留原文 + KN 登记（不做数字推断） |
| 无价格 | `—` / 缺失 | `missing` |

**不建数字结构化**（`price_gp` 数值字段不做）：价格形态 40+ 来源书各表各异，数字归一属过度设计，检索端「X 价格多少」QA 靠 price 原文命中即可。
