## 二、检索端注意事项（按优先级）

### 2.1 【必做】component_type 降权（检索语义保护）

| 类型 | 策略 | 理由 |
|---|---|---|
| `equipment_intro`（119）| **降权**（可作类别素材，不可作为具体装备引用）| 导言块/章节标题（105 空 title），检索命中只应展示为背景 |
| `gear` 空 text 表行（78/2536）| 正常参与价格检索，命中时以 title+价格作答，**不得引用为空描述** | C 形态价格表行 chunk（title+价格可检索，如「复合长弓价格」）；其余 gear 全描述 |

### 2.2 【必做】空 text 113 的处理（不可拒绝条目）

空 text 113 条 = C 形态价格表行 chunk（gear 78 + wondrous_item 26 表行）+ A 形态无描述条目（weapon 3/armor 1/cursed 1/rod 1/enchantment 1）+ equipment_package 1（page_946 无描述包）+ equipment_intro 1。这些条目 title/price 字段完整可检索（「XX 多少钱」问答可命中），检索端命中空 text 条目时以字段值作答，不得因 text 为空剔除。

### 2.3 【必做】B 类保真形态（检索端展示口径）

以下形态**登记不修**（原文合法保真，防词表腐化，同 KN185 口径），检索端命中时原样展示即可：

- **表格脚注星**：`*` 是 PF 原版脚注标记（`破坏DC*`/`34磅*`/`心灵感应水晶球*` 等 ~50 行），不是星壳污染
- **逐字粗体壳**：page_947 家族 60 条/27 doc（`恶**运**雕**像**` 型，源数据 HTML `<B>` 逐字转换缺陷）——展示时按普通文本处理，不做检索降权
- **断行斜体开壳**：5 行（`瓦里安*杰哥拉尔` 等源数据跨行缺陷），原样保真

### 2.4 【必做】slot 13 枚举（奇物位置检索）

`slot` 字段 13 枚举（CHM TOC L4 权威词形）：腰部/躯体/胸部/眼部/脚部/手部/头部/头饰/颈部/肩部/腕部/戒指/无。用户问「XX 奇物带什么位置」直接查该字段；检索端可用 slot 值做结构化过滤（如「肩部奇物」）。

**KN190 闭环后口径（2026-08-09）**：11 个位置页（page_223~233）479 条 wondrous_item 的 slot **100% 有值**——326 条纯描述条目（无「位置：」字段链）由 `BackfillSlotByPage` 后处理按 doc_id 页面归属回填（field_status 三态内 parsed，B1 拍板）；有值条目不动（源数据字段声明优先）。**例外 7 条**为源数据「位置：」自声明页内混排（`field_status=parsed`，A1 拍板保留）：复仇追踪者背心=躯体（page_225）、抒情竖琴/独角兽邪角=无（page_228）、游击头巾=头饰（page_229）、医师挎包=无（page_232）、巨魔皮革止血带/悼念之根=无（page_233）——做「无位置」奇物过滤时这 5 条会被归入「无」，符合源数据声明。非 11 位置页的 wondrous_item（聚合书文件）slot 仍以字段链解析为准（None 546 全部为非位置页条目或非 wondrous_item，位置页内无 None）。

### 2.5 【必做】rule_version 过滤语义

`rule_version == book_abbreviation.lower()` 全库成立（M2 决策 10）。装备无技能模块 Unchained 冲突隔离需求（Unchained 装备为成长型奇物等独立条目，与 CRB 同名词条不重叠）；但**同名跨书条目**（如多书都有的「XX 药剂」）存在——按 `book_abbreviation` 区分来源，回答时注明出处（见 §三 展示口径）。

### 2.6 【建议】巨型条目 21 条降权（>5000 字符）

21 条 = equipment_intro 7 + gear 6 + artifact 4 + wondrous_item 3 + intelligent_item 1（聚合表/导言块/规则段，全定性）。检索命中时语义浓度低，建议降权或截断展示（专长模块 KN095 通用护栏同款）。
