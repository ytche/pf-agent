## 一、问题背景（KN190 摘要）

11 个位置页共 479 个 `wondrous_item` 条目：

| 项 | 数量 | 说明 |
|---|---|---|
| slot 有值且与页面词形一致 | 146 | 0 错位 |
| slot 有值但为源数据自声明例外 | 7 | 页内混排（游击头巾=头饰 等），`field_status=parsed` |
| **slot=missing** | **326（约 68%）** | 条目为纯描述形态（无「位置：」字段链），位置仅隐含于 doc_id 页面归属 |

页内分布两极化：page_225/227/228 基本全覆盖；其余 8 页覆盖不足 20%。

**根因**：slot 只在源数据条目行显式含「位置：」字段链时解析；纯描述条目 → missing，位置信息不落字段。

## 二、方案设计

### 2.1 核心机制：doc_id → 位置词形映射回填

新增映射表（与 CHM TOC L4 权威词形一致，复用 `装备名规范表.md` §三 同源词表）：

```
_EQUIP_PAGE_SLOT_MAP = {
    'page_223': '腰部', 'page_224': '躯体', 'page_225': '胸部', 'page_226': '眼部',
    'page_227': '脚部', 'page_228': '手部', 'page_229': '头部', 'page_230': '头饰',
    'page_231': '颈部', 'page_232': '肩部', 'page_233': '腕部',
}
```

**回填规则**（后处理层）：
- 触发条件：`component_type == 'wondrous_item'` 且 `metadata.slot` 缺失（missing）
- 动作：按 `doc_id` 查映射表回填 slot；**有值条目一律不动**（parsed 优先，源数据字段声明 > 页面归属推导）
- 无映射的 doc_id（聚合书文件如 内海战斗ISC_戒指权杖奇物）不回填——其条目自带字段链已 parsed

### 2.2 落点：processor 后处理链（POSTPROCESSORS）内建

`processors/equipment.py` 的 POSTPROCESSORS 注册 `backfill_slot_by_page`（装备模块决策 A 同构：finalize 后处理链内建，重跑 pipeline 即自动执行，无独立脚本遗漏风险——feat 四脚本迁移教训的结构保证）。

**不做**产物级独立脚本：重跑 pipeline 后须手动重跑、遗漏即数字回退（feat 教训）。

### 2.3 不动公共层

仅新增 equipment 专属后处理函数 + 专属映射表（含专属覆写模块改动前的不变量清单，见 §四），公共层零改动（KN136 安全，spell/职业冻结不受影响）。

## 三、决策点（需用户拍板）

### 决策 A：7 条例外（自声明 ≠ 页面归属）如何处置

| 选项 | 处置 | 结果 | 利弊 |
|---|---|---|---|
| **A1（推荐）** | 保留自声明（parsed 优先，不回填覆盖） | slot 有值率 100%；「与目录对应」= 例外白名单 7 条外 100% 页面一致 | 5 条自声明「无」的位置物品（抒情竖琴/独角兽邪角/医师挎包/巨魔皮革止血带/悼念之根）保真实——问「无位置奇物」不丢；游击头巾/复仇追踪者背心保源数据原值 |
| A2 | 例外也覆盖为页面词形 | 绝对 100% 页面一致 | 5 条真实「无」位置物品失实（字段值与源数据矛盾），检索端「无位置奇物」查询漏检 5 条 |

### 决策 B：回填值的 field_status 标记（三态 schema 影响面）

| 选项 | 标记 | 影响面 |
|---|---|---|
| **B1（推荐）** | 三态内 `parsed` | slot 语义扩展为「源数据字段解析 ∪ 页面归属映射」（doc_id 是源数据固有属性，映射表为 CHM 目录权威）；文档注明口径，verify 断言可覆盖；**schema 零变更**（三态枚举/前端展示/检索端不动） |
| B2 | 新增第四态（如 `derived`/`backfilled`） | 最诚实，但 field_status 三态是全模块 schema 决策（spell 15 字段先例），四态变更波及 verify 断言、交付文档、前端展示，成本高 |
| B3 | slot 有值但 field_status 仍标 missing | 有值+missing 语义矛盾，检索端/verify 三态逻辑会被打穿，**不推荐** |
