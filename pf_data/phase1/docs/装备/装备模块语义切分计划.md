## 1. 目标与范围

**一句话目标**：将装备/魔法物品源数据按"条目语义原子"粒度切分为可检索、可溯源的 chunk（对齐专长/背景特性/技能模块的语义切分质量口径），供一期规则问答 Agent 调用。

### 1.1 语义切分口径（引用既有定义）

"语义切分"已在前几模块交付文档定义：**component_type 分类 + 字符中位证明条目级粒度 + 召回/溯源/验证三维质量评估**。

| 模块 | 切分结构 | 中位字符 | 召回 | 溯源 |
|---|---|---|---|---|
| 专长 | feat 4086 / feat_index 1871 / feat_intro 75 | 196 | 100% | chm_toc_path 100% |
| 背景特性 | trait 1092 / trait_flaw 66 / trait_intro 64 | 85 | 107.1% | chm_toc_path 100% |
| 技能 | skill/skill_use/skill_rule/… 556 | — | 判别器 est↔got 零静默丢失 | chm_toc_path 100% |

**装备模块差异声明**：装备体量为已交付模块的 10 倍（约 250 文件 / 5.5MB），且源数据存在 **4 种形态**（A 新式书聚合 / B 旧式单行内联 / C CHM 原始大页 / D 论坛散件），切分粒度**条目级（单件物品 1 chunk）**，C 形态大页需按物品切块 + 价格表行级对账。

### 1.2 数据范围（E5 硬要求口径）

**输入范围 = CHM 目录装备子树对应全部文档 ∪ `pf_rules_md_organized/` 全量的并集，不得缺失 CHM 目录对应文档**（`流程教训沉淀.md` E5）。Prepare 第 0 步必跑 `audit_chm_scope_gap.py`（**双向**，KN148 教训：organized 整理产物也是 E5 盲区），缺口逐项定性（纳入 / 索引页豁免 / 重复副本豁免）。

## 2. 语义切分设计（核心）

### 2.1 component_type 候选集（15 主类 + 3 辅助，门 2 拍板）

| 主类 | 覆盖 | subcategory / 字段 |
|---|---|---|
| `weapon` | 普通/特殊武器、特殊魔法武器 | 类型（简单/军用/异种）、弹药口径 |
| `armor` | 护甲/盾牌、特殊魔法防具、魔法护甲和盾牌 | 防具类型、盾牌 |
| `ammo` | 弹药/魔法弹药/附魔箭矢/官方弹药汇总 | 弹种 |
| `gear` | 道具/工具/坐骑/服饰/酒品/食物/纪念物/刑具/特殊物品和道具 | 货品服务全族 |
| `alchemical_item` | 炼金物品/毒药/酊剂/毒品/合剂/炼金功能材料/移植物 | 毒药豁免/频率 |
| `potion_scroll_wand` | CRB page_219 药剂/卷轴/魔杖 + 洗牌卷轴 | 合一（CRB 章节结构），检索端子类过滤 |
| `ring` / `rod` / `staff` | page_220/221/222 + 各书戒指权杖法杖 | — |
| `wondrous_item` | CRB 奇物 13 位置 + 无位置（艾恩石/寻路仪）+ 刺青魔法 + 各书奇物 | **slot 枚举**（无/腰部/躯体/胸部/眼部/脚部/手部/头部/头饰/颈部/肩部/腕部/刺青——CHM TOC L4 权威） |
| `cursed_item` / `intelligent_item` / `artifact` | page_947/948/949 + 次级/高等/超游/神话神器 | 神话神器 rule_version=mythic |
| `enchantment` | 防具附魔/武器附魔/特殊附魔 | enchantment_target（armor/weapon/special） |
| `magic_plant` | 极限荒野UW_魔法植物 + 各书魔法植物 | — |
| `equipment_package` | 预设装备包 page_946 | 装备背景关联 |
| `technology_item` | **预留**（本期不纳入） | rule_version=technology |

辅助：`equipment_intro`（导言页 213/214 概述制作，降权）/ `equipment_index`（价格表与清单页，检索入口）/ `equipment_rule`（可选，若规则件决策变更）。

### 2.2 字段草案（公共 + 类目专属，对齐 feat 14 / spell 15）

- **公共**：chunk_id / doc_id / category / component_type / title / text / source / book_abbreviation / book_name_cn / book_name_en / chm_toc_path / page_ref / format_cluster + field_status 三态 + rule_version（crb/unchained/mythic/occult/ui/aa2…，同名条目不同版本 = 来源书维度建模，检索端须 component_type+rule_version 组合过滤）
- **类目专属**（命名对齐 feat craft_* 先例）：price（数字+币种结构化或原文，勘探定）/ weight / slot（13 位置枚举）/ aura / caster_level / activation / craft_cost / craft_conditions / craft_aura / subcategory
- 边界：**物品形态归装备、法术效果归法术**——法术效果正文保持原文保真，不建链解析（登记 KN 后续批次）

### 2.3 来源书识别（高危点）

装备 40+ 来源书，多数「XX书_魔法物品.md」文件名前缀。**技能 3.1 最大教训定调：禁目录/文件名子串推导，专属表短路。**

- 主通道：`_EQUIP_SOURCE_OVERRIDES`（rel 前缀精确表 ~50 条，`processors/equipment.py` 常量）；verify 侧 `_EQUIP_SOURCE_DOC_EXPECT` **import 同源**（改一处两处生效）
- C 形态：`_EQUIP_PAGE_BOOK_MAP` 精确映射（page_206~234/946~949→CRB、627~633→MA、1126~1130→OA、636~641→PU、1006/1014/1020/1021/1590→AA2 等，勘探期逐页核验）
- A 形态 HTML 注释（conf 95）与 `> 来源：` 块（conf 50）走既有 Provider 链
- **禁行区**：providers.py **不注册**「装备_魔法物品」进 DIRECTORY_ABBR_MAP（DirectoryNameProvider 子串匹配 = 技能 557/557 系统性失实直接复现）；新增书缩写只加 SOURCE_BOOK_ABBREVIATIONS 纯新增键，不动 FILENAME_ABBR_MAP 模糊循环
- book '?' 预留参数（KN137 双顶格口径）：`--max-book-unknown` 初值 30，勘探后按 B/D 无来源行家族计数校准，顶格不预放棘轮
