## 四、风险与不变量

| 风险 | 对策 |
|---|---|
| terms.json 重跑会丢 manual_overrides_phase3.py 人工覆盖 | **不重跑 cleanup_phase3.py 流水线**，只对现有 terms.json 定向合并（脚本内白名单 7 组） |

| phase1 副本 git rm | 已跟踪，可 `git revert` 恢复，无丢失风险 |
