## 三、F1（P0）：spell_resistance.note / saving_throw.effect 吞正文

### 问题实样

```json
// chunks.jsonl · 法术免疫 (CRB) —— note 吞进了整段描述正文
"spell_resistance": {
  "applies": true,
  "note": "可 (无害)\n\n你每拥有四个等级可以使被防护的生物免疫一个特定法术的效果。…（数百字正文）"
}

// 众怒 (APG) —— effect 残留格式符和前导标点
"saving_throw": {"type": "意志", "effect": "，通过则无效 **", "harmless": true}
```

### 期望行为

| 输入文本 | 期望输出 |
|---|---|
| `**法术抗力：** 可 (无害) ⏎⏎ 你每拥有…` | `{applies: true, harmless: true, note: null}` |
| `**法术抗力：**可（无害） ⏎⏎ 你在自身…` | `{applies: true, harmless: true, note: null}` |
| `**法术抗力：** 见下文` | `{applies: null/ambiguous, note: "见下文"}` |
| `**豁免：** 意志，通过则无效 ** ⏎ (无害)` | `{type: "意志", effect: "通过则无效", harmless: true}` |

要点：

1. **值边界**：字段值在遇到 `\n\n`（空行）、下一个 `**字段标签`、或描述正文起始处截断。根因大概率在 `parse_fields` 的值捕获跨空行，或 `_parse_*` 拿到的 raw value 未截断——实施者先定位再修，修 parser，不改源数据。
2. **effect 清洗**：剥离首尾 `**`、前导中文/英文逗号与空白。
3. **无害识别**：`（无害）`/`(无害)` 出现在豁免或抗力值的任意位置（含换行后）都要识别为 `harmless: true`，且从 effect/note 中剔除。
4. **field_status 联动**：清洗后若值变为语义空（如 note 整段被截走后为空），note 置 `null` 即可，不影响字段级 status；但若 saving_throw 整体变空，status 必须降级为 `missing`——**status=parsed 的字段值必须真的干净**（审计会交叉检查）。

### 规模基线（2026-07-28 实测）

- `spell_resistance.note` 长度 > 20 字符：**1683 chunks**
- `saving_throw.effect` 含 `**` 或长度 > 15 字符：**854 chunks**

## 四、F2（P0）：COMP 裸标签 → 统一 IR

### 问题实样

COMP 来源书（1511 chunks，占语料 37%）的 page_* 源文件大量使用**无 `**` 包围的裸字段标签**，`parse_fields` 只认 `**标签：**`，导致整片漏抽：

```
// spell_page_1365_0093 · 炫示纹章
**等级：** 术士/法师/奥能师 1、…
施放时间：标准动作          ← 裸标签，casting_time 未 parsed
**成分：** 姿势、器材 (一个纹章或武器涂层)
持续：1小时/等级            ← 裸标签，duration 未 parsed
**豁免：** 意志，通过则无效 (无害)
抗力：有 (无害)             ← 裸标签 + 值变体（有/无 而非 可/不可）
```

### 期望行为

1. 在 `formats/spell.py` 的 IR 统一阶段（`_unify_field_labels` 或新增前置步骤）把字段区的裸标签规范化为 `**标签：**` 标准 IR；`施放时间`→`施法时间`、`持续`→`持续时间`、`抗力`→`法术抗力` 的标签别名收敛到 `registry.py` 的 `FIELD_LABEL_ALIASES`，**禁止在多处硬编码标签列表**（Phase 3 刚消除过一轮）。
2. **抗力值变体**：`有`→`applies: true`，`无`→`applies: false`，与 `可`/`不可` 同等处理。
3. **误伤红线**：裸标签匹配必须锚定字段语境（行首、或紧跟上一字段值结束之后），禁止把描述正文中出现的"持续：""抗力："字样转成字段。必须有 negative test：构造正文含"持续时间："字样的散文 chunk，断言其不被误转、字段不被误抽。

### 规模基线（2026-07-28 实测，统一口径 `(?<!\*)标签：`）

| 裸标签 | 全体未 parsed | 其中 COMP |
|--------|---:|---:|
| `施放时间：` | 222 | 214 |
| `持续：` | 236 | 228 |
| `抗力：` | 219 | 192 |

修复后这三个计数应归零（或逐条说明剩余原因）。COMP 整体覆盖率参考基线：`school=14% spell_level=21% casting_time=51% range=67% duration=15% saving_throw=56%`——duration 应显著上升，其余只升不降。

## 五、F3（P1）：spell_level 领域残留 + 复合职业拆分

```json
// 法术免疫 (CRB) 实测 —— domains 提取正确，但 spell_level 里残留了污染条目

  {"class": "炼金术师", "level": 4},
  {"class": "牧师/先知", "level": 4},
  {"class": "审判者 4 领域 保护领域", "level": 4},   // ❌ 应剥离为 审判者4 + 保护领域4
```
