## 一、改造目标

将法术向量化 pipeline 的元数据从 **3 个字段**（school / spell_level / descriptor）扩展到 **15 个语义字段 + field_status**，同时：

- 消除 `formats/spell.py` 中 9+ 处重复硬编码的字段标签列表
- 从"不同格式各自正则匹配"改为"统一 IR → parse_fields → 类型转换器"的管道化架构
- 不改变 chunk 切分逻辑（不变量：4138 chunks / 146 files）
- 不修改任何已有测试用例

### 3.2 `vectorizer/processors/spell.py`

**改动量**：+465 行 / -27 行（**净 +438**，核心交付，git numstat `8f3c23f^..017a924`）

#### 模块级新增函数

| 函数 | 职责 |
|------|------|
| `_is_semantically_empty(val)` | 判断值是否语义为空（含 dict 全 falsy 检测） |
| `_truncate_trailing_prose(level_str)` | 截断 spell_level 值尾部散文（修复 `$` 锚点失败） |
| `parse_fields(text)` | 统一 IR 解析器：双 regex（`**标签：**` + `**标签**：` 安全网），输出 `{canonical_key: raw_value}` |

#### SpellProcessor 新增方法

**字段提取器（9 个）**：

| 方法 | 输入 | 输出 | 关键逻辑 |
|------|------|------|----------|
| `_extract_school(raw, item)` | parse_fields 结果 + 原始 item | `str` | parse_fields 优先 → `_normalize_school_name` 归一化 → fallback `_infer_school` |
| `_extract_subschool(raw)` | parse_fields 结果 | `str\|None` | 从 school 值 `(...)` 提取 → 白名单校验（`spell_subschools.json`） |
| `_extract_descriptor(text)` | 原始文本 | `list[str]` | 委托 `SpellFormat.parse_descriptors()` |
| `_extract_spell_level(raw)` | parse_fields 结果 | `list[dict]` | `_truncate_trailing_prose` → `SpellFormat.parse_spell_level()` |
| `_extract_domains_from_level(raw)` | parse_fields 结果 | `list[dict]` | 从 spell_level 值中正则剥离 `XX领域 N` |
| `_extract_subdomains_from_level(raw)` | parse_fields 结果 | `list[dict]` | 从 spell_level 值中正则剥离 `XX子域 N` |
| `_extract_range(raw)` | parse_fields 结果 | `str` | 优先 `距离/射程` 标签 |
| `_extract_area(raw)` | parse_fields 结果 | `str\|None` | 优先 `区域` 标签 |

**类型转换器（3 个）**：

| 方法 | 输入 | 输出 | 示例 |
|------|------|------|------|
| `_parse_components(value)` | `"语言，姿势，材料 (一把沙子/法器)"` | `{verbal:True, somatic:True, material:"一把沙子", focus:None, divine_focus:True}` | 支持中文（语言/言语/姿势/材料/器材/法器）和英文缩写（V/S/M/F/DF）双解析 |
| `_parse_saving_throw(value)` | `"意志通过则无效（无害）"` | `{type:"意志", effect:"通过则无效", harmless:True}` | 拆分类型+效果，检测无害标记 |
| `_parse_spell_resistance(value)` | `"可"` / `"不可"` / `"见下文"` | `{applies:True/False, harmless:bool, note:str\|None}` | — |

**状态计算（1 个）**：

| 方法 | 说明 |
|------|------|
| `_compute_field_status(metadata)` | 遍历 15 个字段：非空→`parsed`，subschool/area/effect 为空→`not_applicable`，其余为空→`missing` |

**核心钩子重写**：

`infer_metadata()` 从原来的 3 字段输出：
```python
# 旧
{"school": ..., "spell_level": ..., "descriptor": ...}
```
改为 16 键输出：
```python
# 新（schema v0.3）
{
    "school": "咒法系",        "subschool": "创造",         "descriptor": ["acid"],
    "spell_level": [...],      "domains": [...],            "subdomains": [...],
    "casting_time": "...",     "components": {...},         "range": "...",
    "target": "...",           "area": null,                "effect": null,
    "duration": "...",         "saving_throw": {...},       "spell_resistance": {...},
    "field_status": {...}
}
```
保留 `_infer_school` / `_infer_level` / `_infer_descriptors` / `_infer_subschool_variants` 作为 fallback。

#### 保留的旧方法（未修改）

- `_infer_school(item)` — 4 种格式变体的正则匹配，作为 `_extract_school` 的 fallback
- `_infer_level(item)` — 环位推断，作为 `_extract_spell_level` 的 fallback
- `_infer_subschool_variants(item)` — ceremony 等多形态子条目检测，逻辑完全不变
- `_normalize_school_name(raw)` — 增强版：新增 `【...】`/`"..."`/`**` 剥离 + 附魔系→惑控系等别名映射
