# 法术 KN011~KN018 统一修复 — 审计要求（验收依据）

> 撰写：k3（方案设计方 + 审计方），2026-07-29  
> 配套：[法术KN011-018统一修复_交接文档.md](法术KN011-018统一修复_交接文档.md)  
> 用法：执行方复测时逐项给出数值；k3 审计时按本文逐项核对，**任何一项不过即整体不验收**

## 1. 审计方法

1. 执行方交付复测数据表（§3 各项的修复前/后值）与交付物清单；
2. k3 独立编写/运行复测脚本重算关键指标（不接受仅由执行方提供的数据）；
3. 按 §4 抽样清单人工核对 chunk 内容；
4. 按 §2 全局不变量与 §5 negative tests 逐条断言；
5. 出具审计报告：通过 / 返工项清单。

**基线重校准说明**：KN015/KN016 改变 chunk 总数与 chunk_id，本文"修复前"列的数值均以 2026-07-29 版 chunks.jsonl（4137 chunks）为基线。执行方若分步重生成，中间态数字需换算到同一基线再比对；所有比例类指标以最终重生成结果为准。
