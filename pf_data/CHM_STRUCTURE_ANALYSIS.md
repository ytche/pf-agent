## 关键发现

### 1. L1 项（第一层）定义
- **根 `<UL>` 下的直接 `<LI>` 项**
- 在代码中表现为：`ul_depth == 1` 时的 `<LI><OBJECT>` 项

### 2. 层级计算规则
```
<UL>                    ← 根UL（depth=0→1）
  <LI><OBJECT>          ← L1项（depth=1）
    <UL>                ← 子UL（depth=1→2）
      <LI><OBJECT>      ← L2项（depth=2）
        <UL>            ← 子UL（depth=2→3）
          <LI><OBJECT>  ← L3项（depth=3）
```

### 3. 关键模式识别
- `</UL><LI><OBJECT>` - 结束一个UL，同级新项开始
- `</UL></UL><LI><OBJECT>` - 结束两个UL，回到上层级

### 4. 目录项特征
- `Local=""` 或 `ImageNumber="1"` 表示目录项（无实际页面）
- 例如：常用速查、种族、核心种族 都是目录项

## 规律总结

### 判断 L1 项的正确方法
1. 找到根 `<UL>` 的位置（line 15）
2. 遍历文件，跟踪 `<UL>` 和 `</UL>` 的数量
3. 计算当前 `ul_depth`
4. 当 `ul_depth == 1` 且遇到 `<LI><OBJECT>` 时，即为 L1 项

### 判断子项层级的方法
- 当前 `ul_depth` 值 = 项的层级（L1=1, L2=2, L3=3...）
- 每个 `<UL>` 使 depth +1
- 每个 `</UL>` 使 depth -1

## 脚本实现规则

### 必须严格遵守的规则
1. **必须从根 `<UL>` 开始计算深度**
   - 不能从局部位置开始计算
   - 根 `<UL>` 通常在文件开头（如 line 15）
   - 初始深度为 0

2. **深度值 = 层级值**
   - L1 项：`ul_depth == 1`
   - L2 项：`ul_depth == 2`
   - L3 项：`ul_depth == 3`
   - 以此类推

3. **计算方式**
   - 每个 `<UL>` 使 depth +1
   - 每个 `</UL>` 使 depth -1
   - 同一行内同时有 `<UL>` 和 `</UL>` 时，先计算 opens，再计算 closes

### 错误示例（不要这样做）
```python
# ❌ 错误：从局部位置开始计算
ul_depth = 0
for i in range(target_line, len(lines)):  # 从职业项开始
    ...
```

### 正确示例（必须这样做）
```python
# ✅ 正确：从根UL开始计算
root_ul_start = 14  # line 15，根 <UL> 的位置

ul_depth = 0
for i in range(root_ul_start, len(lines)):
    ul_opens = lines[i].count('<UL>')
    ul_closes = lines[i].count('</UL>')
    ul_depth += ul_opens - ul_closes
    
    # 只处理目标范围内的项
    if i < target_line:
        continue
    
    # 检查是否超出范围（遇到下一个L1项）
    if i > target_line and ul_depth == 1 and '<LI><OBJECT' in lines[i]:
        break
    
    # L2项：ul_depth == 2
    if ul_depth == 2 and '<LI><OBJECT' in lines[i]:
        # 提取项...
```

### 必须严格遵守的规则
1. **必须从根 `<UL>` 开始计算深度**
   - 不能从局部位置开始计算

   - 每个 `</UL>` 使 depth -1
   - 同一行内同时有 `<UL>` 和 `</UL>` 时，先计算 opens，再计算 closes

4. **范围计算规则**
   - 用**下一个同级项**的开始位置作为当前项的结束位置
   - 不能用 `</UL>` 匹配来结束范围（因为多个 `</UL>` 可能连续出现）

### 错误示例（不要这样做）
```python

ul_depth = 0
for i in range(target_line, len(lines)):  # 从职业项开始
    ...

# ❌ 错误：用</UL>匹配范围
if ul_depth == 0 and ul_closes > 0:
    break
```

### 正确示例（必须这样做）

# ✅ 正确：从根UL开始计算
root_ul_start = 14  # line 15，根 <UL> 的位置

### 常见错误模式
| 错误现象 | 可能原因 | 检查点 |
|---------|---------|--------|
| 父项包含过多子项 | 范围计算错误，用了</UL>匹配 | 检查范围计算 |
| 父项没有子项 | 深度计算错误 | 检查深度计算 |
| 子项数量与截图不符 | 深度或范围计算错误 | 检查截图对比（如有） |
| 分组结果混乱 | 没有用下一个同级项定位 | 检查范围计算 |

### 无截图时的验证方法
- **逻辑验证**：检查父项是否只包含直接子项，不包含后续同级项
- **数量验证**：检查各分组数量之和是否等于总数
- **深度验证**：检查子项的depth是否等于父项depth+1
- **范围验证**：检查子项行号是否在父项的起止范围内
